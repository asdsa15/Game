# 问道长生 · 网页实现体

《问道长生》设定下的**可运行网页版**：纯静态前端，分层源码（数据／规则／表现／扩展），双击即玩。
手机端已适配，可装 PWA 或打包成 APK；桌面端可打 Electron。

> **功能版本 v11（P0 / P1 / P2 全部落地）** ｜ **存档格式 10.2（自 v10.2 未变）** ｜ **桌面包 11.0.0（2026-11-26 已重打）**
>
> **文档已于 2026-11-26 整体重整**：活跃目录只留当前版本与常青参考，v10 系方案与记录全部迁入
> `docs/99_归档/`，41 篇移动明细见 `docs/99_归档/README.md`；整体结论见
> `docs/01_审查与诊断/项目整体审查报告_20261126.md`。
>
> 功能批次至 v9.0 M4 + v10.1 三梯队 + v10.2 界面 + v10.3 P0/P1 + v10.4 P0/P1/P2
> + v10.5 P0/P1/P2 + v10.6 叙事素材 + v10.7 三阶段 + v10.8 P0/P1/P2（战斗页三栏 / 中栏四页 / 批量执行器）
> + **v11 P0 杀招·奇遇分档·神通变体·果位经营 · P1 道书重读·五洲内容·人情三用 · P2 势·符箓境界乘区·坐到此境满**。
> 测试基线 **2034 项断言全绿**（39 个测试文件实跑 0 失败），静态检查与冒烟（动作 / 时间 / 成就 / 内容 / 图标 / 经济）全部通过。
> 源码分层：`data`（116 张表）→ `rules`（33 个纯函数 + `SAVE_VER`）→ `game`（薄缝）→ 14 个功能扩展 + 1 个模板。

## 六、维护约定

0. **每一次改动都必须同步更新 `docs/00_项目地图.md`**（行数、体量、测试基线、新增接缝与入口）。
   项目地图是「先读它、别通读源码」的唯一入口，它一旦落后，下一次排查就会按旧行号走错路。
   规矩是硬的：**代码改了、数据改了、产物重建了，地图没改完，这次改动就不算完成。**
