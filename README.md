# 问道长生 · 网页实现体

《问道长生》设定下的**可运行网页版**：纯静态前端，双层源码（数据／规则／表现），双击即玩。
手机端已适配，可装 PWA 或打包成 APK；桌面端可打 Electron。

> **当前版本 v10.1**（源码 `VER = '8.0'`；功能批次至 v9.0 M2 + v10.1 第一梯队 + **v10.1 第二梯队**）。
> 测试基线 **589 项断言全绿**，静态检查三项通过。
> 源码分层：`data`（107 张表）→ `rules`（33 个纯函数）→ `game`（薄缝）→ 七个扩展。
> 新玩法写在 `wxcs3-ext-*.js`，`build.py` 自动收集，不再往 `game.js` 里堆。
