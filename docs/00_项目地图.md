## 二、加载顺序（改代码前必须知道）

```
wxcs3-data.js  →  wxcs3-art.js  →  wxcs3-rules.js  →  wxcs3-game.js  →  wxcs3-ext-*.js
```

`rules.js` 必须早于 `game.js`：后者在文件开头把 `RULES.*` 绑成同名局部常量，
缺了会直接 `throw`（不让数值静默变成 `undefined`）。

`ext-*.js` 由 `mobile/build.py` 自动扫描并按文件名排序插入，HTML 里没有它们的 `<script>` 标签。

## 三、每层放什么

| 层 | 文件 | 判据 |
|---|---|---|
| 数据 | `wxcs3-data.js` | 纯表：数值、文案、词库 |
| 规则 | `wxcs3-rules.js` | **不碰 DOM、不写 `S`、不产 HTML** |
| 表现 | `wxcs3-game.js` | 状态、渲染、ACT |
| 扩展 | `wxcs3-ext-<名字>.js` | 新玩法一律放这里 |

判断某函数能否搬进 `rules.js`：**不看它自己写了什么，看它调用链上还有谁在读 `S`。**
