# 问道长生 v10.1 · 项目地图

> 目的：**先读这张表，不要先读 1.6 万行源码。**
> 定位到函数后，只取那一段（20~120 行）。「通读一遍再动手」在本项目里是错的。

**本表全部为 2026-11-18 实测**（v10.1 第二梯队落地之后），不是估算。
六层源码合计 **16,832 行**。

> **v10.1 第二梯队新增的接缝**（改这两块前必看）：
> - 功法差异：`WXCS3_EXT.gongfaCastInfo / gongfaSpellStatus / gongfaHeal / gongfaEscape / gongfaWard / gongfaLifeBonus / gongfaLifeStop / gongfaMpCap / gongfaFate / gongfaXianghuo / gongfaGapUp / gongfaEffectText`
> - 灵根差异：`WXCS3_EXT.rootPowerMul / rootConcentration / bestKe / subEls / xianghuoCapMul / rootInfo / rootSummary`
> - 主文件缝口只有 6 处：`computePower`(灵根乘区)、`sub==='cast'`(功法乘区+状态)、`maxXianghuo`(五档)、`monthlyHeal`(疗伤统一)、`sub==='flee'`(遁速)、状态栏与功法面板(展示)。
> - **注意**：`tools/test_econ.js` 会把 `maxXianghuo` 等函数单独抽出来跑，往这些函数里加东西**不能依赖外层闭包变量**，要用 `typeof` 保护。

## 二、加载顺序（改代码前必须知道）

```
wxcs3-data.js → wxcs3-art.js → wxcs3-icons.js → wxcs3-rules.js
  → wxcs3-game.js → wxcs3-ext-*.js（按文件名排序：10→20→30→40→50→60→70）
```

- `rules.js` 必须早于 `game.js`：后者开头把 `RULES.*` 绑成同名局部常量，缺了直接 `throw`。
- `ext-*.js` 由 `build.py` 自动扫描，HTML 里没有它们的 `<script>` 标签。
- 数字前缀控制扩展顺序：`10-` 命格要先于 `20-` 天劫（天劫读命格）。

## 三、每层放什么

| 层 | 文件 | 判据 |
|---|---|---|
| 数据 | `wxcs3-data.js` | 纯表：数值、文案、词库 |
| 规则 | `wxcs3-rules.js` | **不碰 DOM、不写 `S`、不产 HTML** |
| 表现 | `wxcs3-game.js` | 状态、渲染、ACT |
| 扩展 | `wxcs3-ext-<名字>.js` | 新玩法一律放这里 |

判断某函数能否搬进 `rules.js`：**不看它自己写了什么，看它调用链上还有谁在读 `S`。**
