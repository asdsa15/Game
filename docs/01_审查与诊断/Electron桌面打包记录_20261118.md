## 二、做法

1. **不碰原工程**：新建独立 `desktop/` 目录，游戏逻辑一行没改。页面仍来自 `mobile/dist/index.html`。
2. **壳只做四件事**：开窗口、单实例、快捷键、本地加载。`nodeIntegration` 关、`contextIsolation` 开、渲染进程 sandbox 开；外链交给系统浏览器，页内跳转与 `window.open` 一律拦掉。
3. **同步而非引用**：`scripts/sync-app.js` 把 `mobile/dist` 的 `index.html` 与 `icons/` 搬进 `desktop/app/`，并对页面补一条 CSP（`script-src 'self' 'unsafe-inline'`，不含 `unsafe-eval`），消灭 Electron 的控制台安全警告。PWA 的 `sw.js` / `manifest` 不搬——`file://` 下用不上。
4. **打包器选 @electron/packager**：产出免安装目录，不依赖 NSIS/7z 那套安装器工具链，也不会去动系统注册表。代价是没有"安装/卸载"、没有桌面快捷方式，需要的话得换 electron-builder 的 nsis 目标。
5. **图标**：用 `mobile/icons/icon-512.png` 由 PIL 生成多尺寸 `assets/icon.ico`（16/24/32/48/64/128/256）。

## 四、限制与注意

1. **未签名**：Windows 首次运行会弹 SmartScreen「未知发布者」。要消掉需代码签名证书，本轮没有。
2. **只有 Windows x64**：mac/linux 需在对应平台另跑一次（`--platform=darwin` 之类），跨平台交叉打包 Electron 不推荐。
3. **不是安装器**：解压即用，没有开始菜单项与卸载项。
4. **本沙箱环境需要 `--no-sandbox`**：Chromium 进程沙箱在受限环境里起不来（退出码 3），加参数才能跑。正常桌面环境不需要这个参数；它降低隔离强度，只在必要时用。
5. **存档位置**：`%APPDATA%\问道长生\Local Storage\`。删掉即清档；覆盖升级不影响。
6. **页面更新要重出包**：`python mobile/build.py` → `npm run pack`（pack 内含 sync）。忘了前者，打的还是旧页面。
