## 二、P1 四项

### P1-1 道统气质（方案 S2）

| 项 | 内容 |
|---|---|
| 问题 | 道统此前只决定「道统池里抽哪些神通名」。抽到之后，所有术类神通长得一模一样——名字不同、用起来相同。玩家创角时选的「离火」与「坎水」，在战斗里毫无区别 |
| 改法 | `wxcs3-data.js` 新增 `DAOTONG_TEMPER`：49 个道统 → 7 支气质（刚烈/幽微/转换/生养/润下/炎上/虚空）；`shenTongSpec` 读 `S.daotong` 派生气质，对 `mul` 做 **加法** ±0.10、`cost` ±5 的微调，并返回 `temper` 字段；`do_cbt` 神通分支按 `temper` 追加一个附加效果 |
| 覆盖校验 | 49 个道统**全部**有归属，无遗漏无多余（有断言守住） |
| 零迁移 | `S.daotong` 缺省时 `daotongTemper()` 返回 null，行为与本轮之前完全一致 |

七支气质的具体效果（幅度刻意压小，护栏见方案第六章）：

| 气质 | 道统数 | 倍率 | 耗灵 | 附加效果 |
|---|---|---|---|---|
| 刚烈 | 6（太阳/少阳/明阳/玄雷/霄雷/神雷） | +0.10 | +5 | — |
| 幽微 | 3（太阴/少阴/厥阴） | −0.05 | 0 | 破绽额外 +1 回合 |
| 转换 | 5（兑金/逍金/齐金/库金/庚金） | 0 | 0 | 命中后回流 18% 灵力 |
| 生养 | 5（正木/保木/集木/角木/更木） | −0.05 | −5 | 额外回血 4% |
| 润下 | 5（坎水/府水/合水/牝水/渌水） | 0 | 0 | 敌方气势 −1 档 |
| 炎上 | 5（离火/真火/并火/牡火/灴火） | +0.05 | +3 | 点燃灼烧 2 回合 |
| 虚空 | 20（土行 6 + 十二炁 12 + 孤独 2） | 0 | 0 | 本场位格压制减轻一档 |

**实测差异**（同一道「位从罗」，只换道统）：刚烈 45 灵、幽微 40 灵、润下 40 灵；伤害 2.54e15 / 2.31e15 / 2.39e15。

### P1-2 功法倾向进修炼公式（方案 3.2）

| 项 | 内容 |
|---|---|
| 问题 | `monthXiuwei` 的 `gf` 只读品阶（黄 1.0 → 仙 3.0），45 本功法同品阶收益完全一样 |
| 改法 | 新增 `xiuweiGongfaMul(zt)`，从既有 `EFFECT` 派生，不新造字段 |
| `heal` 类 | 伤势惩罚减免：`1 + heal × (1−zt) × 1.6`。带伤修炼时最明显 |
| `ward` 类 | 闭关时收获 `+ward×0.5` |
| 关键取舍 | **不是所有功法都该加快修炼**。`all`/`dims` 这类纯战力功法一律不加，否则「换功法」就退化成「换一个更大的数字」 |

**实测（同为玄阶，排除品阶干扰）**：

| 功法 | 满血 | 重伤（hp 30%） |
|---|---|---|
| 碧海功（无 heal） | 10.8 | 4.3 |
| 月湖映秋诀（heal 0.10） | 10.8 | 4.7 |
| 长春功（heal 0.25） | 10.8 | 5.4 |
| 续脉决（heal 0.30） | 10.8 | 5.6 |

满血时三者相同、重伤时按 heal 单调递增——这正是「疗伤本钱」该有的样子。
闭关时：金光咒（ward 0.10）17.5 vs 聚气诀 16.6。

**与方案的偏差**：方案写「`ward` 类 → 闭关时降低走火概率」，但本项目闭关**没有走火判定**
（走火只挂在「借来的运」这条 debuff 上）。与其新造一个风险，不如兑现成「闭关收获 +ward/2」——
同一句「稳」，不新增系统。已在偏差表中登记。

### P1-3 四艺按功法门类（方案 3.3）

| 项 | 内容 |
|---|---|
| 问题 | 采集、炼丹、炼器、制符、阵法、买卖、社交、赶路、洞府——9 个系统里只有「每月回血」读功法。玩家花大价钱买《造化丹经》，炼丹成功率与《聚气诀》一模一样 |
| 改法一 | `EFFECT.craft` 从「一个数字」扩展为 `craftArts: { dan/qi/fu/zhen }`，兼容旧数字（视为四艺全生效）；`craftRateOf(art, recipe)` 挂一次，四艺同时生效 |
| 改法二 | `dispatch` 新增 `runActionHooks(act)`：所有 `do;` 动作结算后调用一次；`enc:` 分支单独挂一处（它不经过 `do;`） |
| 六本专精功法 | 造化丹经→炼丹 +25%；剑君谈玄执金秘章→炼器 +20%；玄元剑经→炼器 +12%；梅花易→制符 +18%；玄光赶山经→阵法 +18%；白首叩庭经→阵法 +10% |
| 串门类校验 | 造化丹经不炼器/不制符/不布阵，梅花易不炼丹（均有断言） |

**注意一处签名纠正**：方案写 `craftRateOf(kind, recipe)`，实际第一个参数是**门类** `art`（dan/qi/fu/zhen），
不是配方。按实际签名实现，否则会写出一个永远命中不了的判断。

`onActionHooks` 的三条纪律（写在代码注释里，避免后人误用）：
① 只读 `act` 与 `S`，不许在钩子里再 `dispatch`（会无限递归）；
② 不许改变动作结果，只做「顺带」的事；
③ `tx:`/`act:` 前缀不经过 `do;`，`enc:` 已单独挂。

### P1-4 神通入场态势（方案 S4）

| 项 | 内容 |
|---|---|
| 问题 | `computePower` 只读 `S.shenTong.length`，每道 +5%。五道同类与四类各一道收益完全相同——玩家没有理由凑多样性 |
| 改法一 | 战力从「数数量」改为「数量 × 类别多样性」：基础 `0.8+0.05×道数`，再乘类别系数（四类 1.20 / 三类 1.12 / 两类 1.05 / 一类 1.00） |
| 改法二 | 战斗开局按类别构成给一个「态势」，本场改写规则；战前弹窗可切换（只给已达成的） |
| 改法三 | 面板显示「势 · 四象归元」，否则态势就是藏在公式里的隐形加成 |

四种态势：

| 态势 | 条件 | 效果 |
|---|---|---|
| 四象归元 | 四类齐全 | 本场首次神通不耗灵力 |
| 先声夺人 | 命+目 ≥2 | 首回合破绽额外 +1 档 |
| 守中带攻 | 术+身 ≥2 | 本场首次受击减伤 30% |
| 偏执 | 单类 ≥3 且非四类齐 | 该类伤害 ×1.2，**其他类本场禁用** |

**实测**：四道四类战力 108 vs 五道单类 95 —— 多样性第一次比堆数量更划算。

**偏执必须有代价**：单类 ≥3 若只给 +20% 而无惩罚，堆同类就成了纯收益。
所以「其他类本场禁用」是硬约束，且菜单必须写明「偏执之势：本场禁用（只容术类）」，
不能静默失败——否则玩家会以为界面坏了。

## 三、过程中修掉的一个老 bug（P0 遗留，非 P1 引入）

### 目类神通自己造破绽、自己吃加成

**症状**：目类神通 `mul` 只有 1.30，实测却接近 1.625 —— 比 1.85 的命神通还稳。

**根因**：`do_cbt` 的目类分支会置 `c.foeMark = 2`，而总伤害结算在**命中之后**检查
`if (hit && dmg > 0 && c.foeMark > 0) dmg *= 1.25`。同一击先造破绽、再吃破绽。

**证据**：修复前「目 1.30 vs 命 1.85」的伤害比是 1.138（理论应为 1.423）；修复后精确 1.423。

**修法**：出手前快照 `_markBefore`，只有「出手瞬间已存在的破绽」才给 ×1.25。
本击新造的破绽留给下一击——这才是「看破」的本意。

**为什么 P0 没发现**：P0 的验收集中在「双属」「灼烧」「7 个钩子」，没有单独测「四类神通的相对强度」。
P1 做道统气质时需要「同神通换道统」的对照，才把这个偏差暴露出来。

### 战前文案的三处自相矛盾

加了态势区块后，战前弹窗原有的三句文案全部失真，已一并修掉：

| 旧文案 | 为什么错 | 改成 |
|---|---|---|
| 「开打之前，还能做一件事。」 | 现在除了用物，还能定势 | 「还有两件事：用物、定势。」（无神通时仍是「一件事」） |
| 「身上没有任何可用之物——那就这么上吧。」 | 紧接着就给出了两个态势选项，读起来像自我否定 | 「身上没有可用的符与丹。好在势还在——下面可定。」 |
| 「战前只会耗一次，进入战斗后无法再补。」 | 换态势免费，这条会造成误导 | 「符与丹每场只耗一次……态势可免费改，改了当场面生效。」 |

## 七、风险与后续

1. **气质幅度是拍的**：`±0.10 / ±5` 来自方案护栏，但「刚烈打法与润下打法手感差多少」要真玩几场才知道。七支气质的效果都集中在一个 `if/else if` 链里，调整成本低。
2. **虚空 20 个道统占 41%**：土行 6 + 十二炁 12 + 孤独 2。若实测发现「虚空太多、其他气质太稀」，宁可拆成「厚土」与「清虚」两支，也不要把土行硬塞进别的气质。
3. **守中带攻的 30% 是一次性的**：用完即失效。若觉得偏弱，可改为「前两回合各减 15%」，但不要再加总量——首击减三成已经能救一次绝境。
4. **破绽修正是行为改变**：目类神通从此不再自我加成，实际变弱约 20%。这会让「目」从「隐藏最强」回到「辅助位」。若玩家反馈目类太弱，正确做法是调 `SHENTONG_SPEC['目'].mul`，不要把双重结算改回去。
5. **P2 起点**：神通×功法五条联动。P1 已把 `sp.parts` 与 `sp.temper` 都准备好，联动时不必再动分类与气质逻辑。
