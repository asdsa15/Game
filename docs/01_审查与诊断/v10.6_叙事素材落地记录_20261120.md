## 三、事件：一条真的因果链

七则事件全部走 `eff` 数据驱动，不再往 `applyEvent` 的 switch 里加 case（那条 switch 是 v8.0 之前的遗留写法）。

其中一条不是孤立事件，而是 **因果链**：

```
火塘不认（eff.flag: ancestor_reject）
        ↓  when: { flag: 'ancestor_reject' }
阴亲之议（eff.flag: yin_qin_proposed）
        ↓
三炷香（奇遇，三选一：允 / 拒 / 追问「我是谁」）
```

祖宗不认 → 才有人提阴亲 → 才有三炷香的抉择。事件本身给不了选项，
但把「议」与「决」拆成事件与奇遇两段，玩家就会觉得这件事是自己一步步走进去的。

`when.flag` 这个条件字段 v9.0 M0 就写好了，但**此前没有任何地方写 `S.flags`**——
写了条件没人写值，等于死字段。本次补上 `eff.flag`，链路才真的通。

### 为「事件也能落物」新增两条 eff 键

| 键 | 作用 | 为什么必须有 |
|---|---|---|
| `eff.art` | 事件直接给法宝（`ARTIFACT_EXT` id） | §8.5「不告而别」的果是「得旧物」。旧版事件只能给材料，写「得旧物」就成了空话 |
| `eff.flag` | 写叙事标记，供后续事件 `when.flag` 判定 | 见上 |

### 4.1 五处奇遇 · 十五个分支

每处三选一，十五个分支在 `do_enc` 里各有一段真实结算。**没有一条是「稳赚」**：

| 奇遇 | 选项 | 真实代价 / 收益 |
|---|---|---|
| 石液观机 | 观洞府 | 机缘 +2，下次破境 +3% |
| | 观旧债 | 落 `hook_old_debt`（八年后到期） |
| | 封瓶不观 | 机缘 +1，得未启之液一瓶 |
| 三关·荡魂 | 闯荡魂山 | 业力 > 20 者道心 **−3**，否则 +2 |

| 命灯之问 | 点亮己灯 | 业力 +3，得万炼血（滴血入灯） |
| | 吹灭将熄之灯 | 机缘 +1，业力 +3，落 `hook_lamp_out` |
| | 转身走 | 道心 +2，此路关闭 |
| 伪箓之问 | 指出其伪 | 制符熟练 +15；已识老道则好感 +8 |

「绕谷而行」是这批里唯一会**动已有存档关系**的选项：它真的把某位故人的好感清零，
并在日志里点名是谁。素材原文写「忘了一人的名字」，这一条如果不落到好感上，就只是句好听话。

### 4.2 道书四读：新增两种表达力

四部道书各四读，沿用「故事 → 技法 → 秘闻 → 真意」。为了让素材里写的门槛与真意能被表达，补了两处：

- **`need.or`**：原来 `need` 只能「全要」，写不出「悟性 ≥14 **或** 道心 ≥15」。
  《残心经》第三读正是这个门槛。现在写成 `need: { or: [{insight:14},{heart:15}] }`。
- **`layer.fx`**：原来 `gain` 只认「道心/悟性/资质/寿元/修为/阅历」六种正则。
  《残心经》第四读的真意是「绝境中希望类心法 +2%」，落成 `fx: { breakBonus: 0.02 }`，
  并在读后弹窗里明写「下次破境 +2%」——账上有，字上也有。

新增四部：`canxin`《残心经》1100 / `mingtu`《命途残章》900 / `mingdeng`《命灯录》1500 / `guancai`《棺材庙记》1000（后者限仙道架）。

## 五、三处改编取舍（与素材原文不同，据实记录）

### 5.1 奇物未另开库存系统

素材里「得【命牌】/【伪箓】/【阴亲契】/【未启石液】/【逆流痕】」共五种奇物。
本项目**没有**奇物表，只有丹药/材料/符箓/法宝/阵盘五类。

两条路：新开一张 `ODDITIES` 表 + `S.oddities` + 面板 + 存档迁移；或落到已有系统。
选后者，原因写在项目维护约定里——**不上系统就别上字段**，否则就是一个不会被读的死表。
具体映射：

| 素材奇物 | 落地 | 理由 |
|---|---|---|
| 【未启石液】 | 材料「玉华宝鱼汁」×1 | 同为封存灵液，且四艺真会用到 |
| 【命牌】 | 材料「万炼血」×1 | 「滴血入灯」与血炼主材同源 |
| 【伪箓】 | 业力 +2、悟道 +1、`flags.falseRegister` | 收下假符的代价是「说不清」，不是战力 |
| 【阴亲契】 | 信众 +40、虔诚 +0.1 | 祠堂多一炷香，落成信众最实在 |
| 【逆流痕】 | `S.breakBonus += 0.03` | 「破境 +1」在现有系统里就是破境加成 |

### 5.2《残心经》二读的「辨伪之眼」改为「悟性 +1」

素材写「坊市淘残卷时稀有残卷辨识率 +1」。本项目坊市没有「辨识率」这一维
（残卷是随机池，不是可鉴定的物件）。硬造一个辨识率，就得多一张表、一套判定、
一个只在这一处生效的数值。改为悟性 +1，正文照样写「识破华美者未必可用」。

### 5.3 §6 宿命台词进文案库，不进代码

「万物有生就有死」「面对困境，就把心交给希望」「世界有一条光阴之河」三句，
用途标的是「坐化结局的收束句」。但十二个结局的收束句已由 `VERSES.ending` 一句定一局
（五言四句，各有韵脚），再插三句白话判词会把韵打散。

按素材自己的「落地字段」提示（`10_提示词与仪式文案.md`），归入文案库备选，
待日后做「寿元耗尽特写」或「时间类神通描述」时取用。
