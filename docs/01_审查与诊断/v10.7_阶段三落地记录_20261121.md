| 敌方路数 | 新增 `FOE_STYLES`（剑修/法修/体修/诡修，各 4 行动）；性格保留为数值倾向 | `wxcs3-data.js` |
| 意图时序 | `pickFoeIntent` 选意图存 `S.combat.foeIntent`（存档字段）；`foeTurn` 执行已保存意图，禁止临时重摇；执行后选下一意图 | `startCombat` / `foeTurn` / `pickFoeIntent` |
| 蓄力跨回合 | `charge` 当回合只蓄势无伤，`foeCharging` 记下回合强制 `burst` 释放；玩家有真实反制窗口 | `pickFoeIntent` / `foeTurn` |
| 定神防连控 | 硬控后 `foeCalm=3`（递减后 2 回合），定神期内硬控转压制 | `applyCombatEffect:stun` |

| 破甲/护体/反击 | 破甲 `foeShred` 增伤 20%；敌方护体 `foeGuard` 一次性减伤；体修反击架势 `foeCounter` 反噬普攻 | `do_cbt:attack/skill/tal` / `foeTurn` |
| 战利品接四艺 | `combatLoot`：按路数掉材料（普通 45%、寻仇必掉）+ 基础丹符（12%）；材料不进月账灵石收入 | `settleCombatWin` / `combatLoot` |
| 败北唯一出口 | `combatLose` 收成函数，敌方 DoT 致死与直接致死共用 | `combatLose()` |

**首批兑现的术法**（均走真实 `openSkills → do;cbt:skill` 路径）：

| 术法 | 效果 |
|---|---|
| 焚山掌 | 伤害 + 灼烧 2 回合（burnFresh 点火当回合不落伤） |
| 缠木根 | 伤害 + 压制 1 回合（出手 ×0.7） |
| 毒火丝 | 较低直伤 + 中毒 3 回合（poisonFresh，每回合真伤） |
| 镇压八方 | 打断蓄力；非蓄力时硬控 1 回合（定神期转压制） |
| 流转剑罡 | 伤害 + 本次守势 |
| 落石诀 | 伤害 + 破甲 2 回合（受创 +20%） |
| 白骨飞剑 | 高倍率 + 耗气血一成 + 本命器损 +4（文案改，不再「命中偏难」） |
| 惊雷引 / 神霄御剑 | 必中、半无视卸力、打断蓄力、雷火引爆 |

**状态回合数统一语义**：玩家施加的敌方状态记 `turns+1`，当回合末（敌方行动后）递减一次，面板显示 `turns`，效果恰好覆盖接下来 `turns` 次敌方行动/玩家攻击——与增益符 `talBuffTurns` 同一口径，杜绝「写 2 回合实际只生效 1 次」。灼烧/中毒在 `foeStart` 结算（fresh 保护当回合），不在 roundEnd 递减。

## 四、遗留项与注意事项

1. **守势流击杀率偏低**（胎息境 0%）：极端防御构筑在低境无额外输出，接近普攻基线。属构筑定位（稳而非快），非引擎缺陷；若产品上要求守势流有保底输出，需另调护脉/守势反击数值，本轮未动。
2. **符丹流高境击杀率回落**（53%→18%）：符箓固定倍率被高境血厚稀释，符合比例制设计；地阶雷火符未上市，高境符丹流依赖自炼/寻仇掉落。
3. **五行只做底色**：本命五行仍未接相生相克加成（阶段二遗留），本轮调数未引入，保持身份语义。
4. **`mobile/dist` / `desktop/app` 在 `.gitignore` 内**，不入库；桌面 Electron 安装包仍未重打包（`desktop/release_v10.3_final/` 仍是 v10.3 产物），发布前需 `npm run pack`。
5. **状态回合数语义**：玩家施加敌方状态记 turns+1、当回合末递减后面板显示 turns。后续新增状态务必走 `applyCombatEffect`，不要直接赋值字段，否则口径会再次漂移。
6. **`cast` 自由施法路径保留**：仍无玩家可见入口（测试用），其状态写入已改走统一入口。若后续要下线 cast，需先迁移 test_p0_v104/test_tier2 的 cast 断言。
