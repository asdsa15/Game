## 一、本阶段做了什么（一句话）

**把破境手续改成真正可续接的 FIFO，把本命从「普通法器认主」改成「首次筑基亲手铸一件」，并让旧档里那件认过主的法器按物映射迁移成独立本命。**

本阶段**动了存档结构与本命语义**（三阶段计划标为中高风险），但没有改战斗引擎、没有新增符丹、没有重做视觉。

## 二、改动清单

### 2.1 破境手续：可靠 FIFO（`wxcs3-game.js`）

| 改动 | 做法 | 位置 |
|---|---|---|
| 队列逐项推进 | `do_afterbreak` 改成 **peek 队头**：打开某一步时**不摘**，完成才摘。旧版一次取出整队再逐条 `filter`，任何一步不回调就断链 | `do_afterbreak()` |
| 统一完成出口 | 新增 `afterBreakPop(step)` / `afterBreakDone(step)` 与 `ACT.do_afterbreak_done:<step>`；`afterBreakStepDone()` 仍供扩展续接 | 同文件 |
| 修 `do_yin` 断链 | 选完道印 → `afterBreakDone('daoyin')`（旧版 `closeModal(); advanceXun(1); render()` 就结束） | `ACT.do_yin` |
| 修 `do_st` 断链 | 得神通后立刻 `afterBreakPop('shentong')`，得物窗带「继续」按钮回队列；旧版只弹窗、不续接 | `ACT.do_st` / `openGain` |
| 择痕续接 | `fate_pick` / 无候选分支改 `do;afterbreak_done:fate`（ext-10） | `wxcs3-ext-10-fate.js` |
| 插入锻造步骤 | 筑基成功（`nr.idx === 2`）且无本命、非纯神道 → 队列推入 `forge`，顺序 **仙基 → 锻造 → 道印 → 神通 → 命格** | `resolveXianBreak()` |
| 读档续接 | 三个读档入口（槽位 / 自动 / 导入）成功后调 `resumeAfterBreak()`：队列非空就直接打开当前一步 | `loadFromSlot` / `do_load` / `do_imp` |

**为什么队列要「完成才摘」**：`S.afterBreak` 是存档字段。若打开面板时就 `shift()`，玩家在面板期间存档再读，那一步已经不在队列里——这一步就永久丢了。现在「未完成」与「读档继续」是同一件事。

**顺带修掉的真实缺陷**：`openShentongPick()` 原来没有返回值。队列若按返回值判断「是否打开」，会把神通步骤静默跳过。现在返回 `true` / `false`。

### 2.2 本命独立化（`wxcs3-data.js` / `wxcs3-ext-40-benming.js`）

**新增静态表 `NATAL_FORMS`（五器形）**：

| 器形 | 认主被动 | 通灵法技 | 结算实现 |
|---|---|---|---|
| 本命飞剑 | 剑系术法伤害 +12% | 剑魄斩：单体高伤，对已有破绽追加收益 | `natalDamageMul` + 法技分支 |
| 本命法印 | 所施加的压制延长 1 回合 | 镇岳印：小额伤害 + 压制 2 回合 | 同上 |
| 本命宝镜 | 开战即照见破绽 | 照影：看破 + 破绽 2 回合 | `natalOnCombatStart` + 法技分支 |
| 本命神钟 | 常驻减伤 6% | 钟鸣护体：获得一次护体（减伤 30%） | `natalIncomingMul` + 法技分支 |
| 本命魂幡 | 对灼烧之敌伤害 +15% | 摄魂幡：施加灼烧 2 回合 | `natalDamageMul` + 法技分支 |

**状态结构改为 `ver:2`**：

```text
S.benming = { ver:2, form, el, name, tier, xp, dmg, quality, forgedRealm, skillsUsed, legacyArtId? }
```

- 不再有 `artId` 真值，不再要求「这件法器还在 `S.arts` 里」；**清空普通法器不会契断**。
- 不进 `S.arts`、不占 `atk/body/move` 装备槽、不可出售（法宝面板只列 `S.arts`）。
- 四阶职责不变：认主（被动）→ 通灵（法技）→ 共命（出鞘挡击）→ 合道（命格共鸣、物锚之稳）。

**筑基锻造仪式（`openNatalForge`）**：择器形 → 择主五行 → 正名与预览 → 铸成。

- 只由破境队列在「首次晋入筑基」时进入；也可由本命面板的「补铸」进入。
- **不查炼器等级、不额外占旬、不掷成功率**：玩家已经通过筑基判定，不能因未学炼器卡死。
- 五行候选取 `rootEls`，并允许追加主修功法同属的一项；**不改灵根**。
- 正名默认「器形 + 五行」（如「宝镜·水」），可改；不能跳过器形选择。
- 重复点「铸成」有 `S.benming` 守卫，不生成第二件。

## 四、遗留项与注意事项

1. **本命被动只在三个缝口生效**：`natalDamageMul`（伤害）、`natalIncomingMul`（受击）、`natalOnCombatStart`（开战）。**蓄力打断、状态生命周期、敌方意图属阶段三**——法印「对蓄力更稳」在阶段三接入真实蓄力后再补一段结算，本轮先以「压制 2 回合」体现控制差异。
2. **五行只做底色，未接五行相生相克加成**。方案只要求「器形 + 五行 + 名称」构成身份，未要求本命参与克制公式；阶段三调数值时再决定。
3. **旧档迁移不会自动补铸**。筑基以上、从未有本命的旧档需要玩家在本命面板点一次「补铸」——这是有意设计（不伪造一次破境），不是漏迁移。
4. **纯神道旧档若曾通过旧机制认主**，迁移仍会生成一件本命（保留玩家已有培养），但仪式不会再进入；面板写明神道不铸仙道本命。若产品上要求「神道不保留本命」，需用户明确后再改。
5. **`mobile/dist` / `desktop/app` 在 `.gitignore` 内**，不入库；桌面 Electron 安装包本身仍未重打包（`desktop/release_v10.3_final/` 仍是 v10.3 产物）。
6. 阶段三（战斗决策层 + 丹符扩充）尚未开始；本阶段未改战斗引擎、未合并符箓库存、未加敌方意图。
