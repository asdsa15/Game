## 二、恩义·钩子：实现形态

### 2.1 数据（`data.js`）

```js
HOOK_DEBUFF  // 5 条：因果缠身 / 人情压身 / 借来的运 / 被人惦记 / 神魂暗契
HOOKS        // 8 条：每种「期」都有覆盖
```

八条钩子与它们的「期」：

| id | 施恩者 | 给的东西 | 期 | 索 |
|---|---|---|---|---|
| `hook_umbrella` | 柳姓散修 | 地阶功法 | 金丹 | 三成修为 |
| `hook_sword` | 雪中留剑（无名） | 天阶剑意 | 杀够 3 人 | 替他杀一个人 |
| `hook_voice` | 洞天深处的念诵声 | 天阶功法 | 道胎 | 你的身体（道化） |
| `hook_tablet` | 残碑下的那个人 | 地阶功法 | **30 年后** | 两成寿元 |
| `hook_pill` | 路过的丹师 | 救命丹 | 你重伤时 | 一滴心头血 |
| `hook_sect_feed` | 宗门 | 丹药·功法·庇护 | **你证位时** | 你的果位 |
| `hook_clan_raise` | 族老会 | 族运倾斜 | 筑基 | 一个继承道统的后代 |
| `hook_dowry` | 联姻之家 | 资源与人情 | 10 年后 | 履行婚约 |

明钩 5 条、暗钩 3 条。**每一条都有 `hint`（破绽）**——暗钩没破绽就是不公平，不是伏笔。

### 2.2 状态（`game.js`）

```js
hooks: [],        // 你欠别人的
hooksGiven: [],   // 别人欠你的
hookPending: null,// 正在被索（挡住奇遇，别把面板顶掉）
hookSeen: 0       // 被窥视次数
```

`applyState` 全部兜底。**`hookPending` 必须显式清空**——这和 `pendingEnc` / `pendingTx` 是同一个坑：面板开着时存档，字段残留会让 `maybeEvent` 永久短路。

### 2.3 到期节奏

```
到期当月   → 只给一句：「「柳姓散修」那边，好像有信要来了。」
            （暗钩给的是 hint 原文，不揭底）
宽限三月   → 不上门
第四月起   → 开「人情 · 柳姓散修」面板，三选一
```

### 2.4 三选一

| 选项 | 后果 |
|---|---|
| **还** | 按 `claim.effect` 结算（修为 / 寿元 / 气血 / 功德 / 果位 / 当场道化） |
| **赖** | 业力 + 气血重创，**但账不清**——钩子继续挂着，debuff 常驻 |
| **斩** | 道心 −3、气血 −50%，一次性两清；道心 < 5 时不可选 |

「赖」刻意不清账：这不是"拒绝就完事"，是"从此身上多一层东西"。

### 2.5 上限 3 条

超出时最旧一笔被「有人替你平了账」——**给叙事理由，不静默丢弃**。这一点和成就系统的"前世残留"是同一条原则：任何丢弃都要有话说。

### 2.6 反向：你也可以是债主

两个入口：

| 入口 | 记下什么 |
|---|---|
| 濒死的修士 · 施药救人 | 救命之恩（情分 3） |
| 崖边老者 · 递半块饼 | 半块饼（情分 1，`power: 0` 表示"不知道他有多强"） |

讨债判定：

```js
if (对方战力 > 我 × 2.2)  → 他不还，你也不能怎样
else if (rnd100() <= 30 + 好感/2) → 还：灵石 200、声望 +6、好感 +5
else → 推说改日：好感 −10，人情淡了
```

**「对方远超你时可以不还」是这套系统的骨气**，不是漏洞。

### 2.7 五条 debuff 的实际接线

| debuff | 接在哪 | 真实效果 |
|---|---|---|
| `karma_tangle` | `xianBreakRate` / `posRate` / `pillarRate` / `tryEncounter` | 破境 −8%（三套都减）；奇遇概率 18→24% |
| `debt_weight` | `do_ia` / `advanceMonth` 跨年 | 好感 −30%；每年道心 −1 |
| `borrowed_luck` | `monthXiuwei` / `do_xbreak` | 修炼 **+20%**；破境成功时 15% 走火（气血 −30%、修为退回两成） |
| `marked_rich` | `startCombat` / `tryEncounter` | 来者战力 ×1.15；遇袭概率 +4% |
| `soul_lien` | `tickHooks` 每月 | 10% 被窥视（只出文案，不扣数值） |

`borrowed_luck` 是全篇唯一**先给好处**的 debuff：+20% 是现在的事，走火是四十年后的事。这就是「贪」的机制化。

### 2.8 状态卡只写征兆

```
人情 欠 2 ｜ 人欠 1
夜里总觉得有人在数你的呼吸　气海里有一缕不属你的气，很听话
```

**不写「破境 −8%」。** 公式藏在「人情账」面板里，玩家想看才看。

## 三、位阶换算修复：死档根因

### 3.1 根因

```js
// 旧
function positionRank() { return S.xRealm * 4 + S.xStage; }
```

**假设每境四阶。但实际是：**

| 境界 | 阶数 | 旧 rank 区间 |
|---|---|---|
| 胎息 | 6 | 0~5 |
| 练气 | **9** | **4~12** |
| 筑基 | 4 | 8~11 |
| 紫府 | 3 | 12~14 |
| 金丹 | 1 | 16 |
| 道胎 | 1 | 20 |

练气九层算出 rank **12**，与紫府一关同号。接着：

```js
// 旧 startCombat
const foeR = myR + (Math.random() < 0.3 ? 1 : 0) + (isCounter ? 2 : 0);
foePower = D.XIAN_REALMS[clamp(Math.floor(foeR / 4), 0, 5)].power;
```

`floor(12/4) = 3` → **紫府，战力 350**，而练气玩家战力 25。

`R = 25/350 = 0.071`，两回合必死。**因为机缘是随机触发的，这不是难度，是死档。**

### 3.2 修法

```js
rankBaseXian()   // 按各境真实阶数累加 → [0,6,15,19,22,23,24]
positionRank()   // 查表 + 阶内偏移
realmIdxRank()   // rank → 境界索引（反查，可逆）
stageIdxRank()   // rank → 该境内第几阶
myRealmIdx()     // 我当前境界索引（仙=境界序号，神=柱序）
realmGap(rank)   // 大境差：唯一用于文案与减伤的尺度
```

全项目 `Math.floor(rank / 4)` 的残留全部清掉（4 处：`startCombat` / `deathBySame` / 越境成就 / `posText`）。

### 3.3 敌人生成改为「以玩家为锚」

```js
// 境界：常规 +0~1，仇家固定 +1。永不通跨两境。
// 战力：常规 0.55~1.55 倍，仇家 1.25~2.0 倍。
// 上限取「该境界的名义战力」而不是玩家倍数。
```

为什么上限取名义战力：高你一个大境的人名义上强 3~4 倍，但**刚破境/带伤的散修打不出那个数**。这样 R 落在 0.5~0.8（下风，能打能逃），既残酷又不死档。

战力远低于名义值时，敌卡副标题会写「（气息不稳，像是刚破境或带伤）」——把不一致变成设定。

### 3.4 实测分布（10,000 次/场景）

| 玩家 | 场景 | R 区间 | 最大跨境 | 绝境占比 |
|---|---|---|---|---|
| 胎息 | 机缘 | 0.67 ~ 2.00 | +1 | **0%** |
| 胎息 | 仇家 | 0.50 ~ 0.80 | +1 | **0%** |
| 练气九层 | 机缘 | 0.64 ~ 1.79 | +1 | **0%** |
| 练气九层 | 仇家 | 0.50 ~ 0.81 | +1 | **0%** |
| 筑基 / 紫府 / 金丹 | 机缘 | 0.65 ~ 1.82 | +1 | **0%** |
| 筑基 / 紫府 / 金丹 | 仇家 | 0.50 ~ 0.80 | +1 | **0%** |

对照旧算法（练气九层）：

```
机缘：foeR=12 → 紫府 战力 350，R=0.071 ← 必死
仇家：foeR=14 → 紫府 战力 350，R=0.071 ← 必死
```

### 3.5 连带修的三处

| 问题 | 原状 | 现状 |
|---|---|---|
| 胜算档不上色 | `tier` 取值「绝境/下风/压制」，比较却用「必死/劣势/优势」→ 除碾压外全灰 | 改用 `['绝境','下风'].indexOf()` |
| 越境成就误判 | 练气九层被算成紫府，杀谁都算「越境」 | 用 `realmIdxRank` |
| 地图危险门槛 | `positionRank() >= danger*2`，练气九层（旧 12）能进北原 | 改为 `myRealmIdx() >= danger` |

## 五、偏离设计稿的地方（有意为之）

| 设计稿 | 实现 | 原因 |
|---|---|---|
| 12 个钩子 | **8 个** | 五种「期」已全覆盖；宁少而准，不为凑数加水货 |
| `S.debt` 计数 | 改为 `S.hooks[]` 数组 | 玩家需要看见一张账单，不是一个数字；旧字段保留做兼容 |
| 赖账 = 清账 | **赖账不清账** | 拒绝不该是"说完就没事"，而是"从此身上多一层东西" |
| 暗契「不可在洞天过夜」 | 未做硬拦截 | 洞天进出是 `do_gate`，硬拦会让玩家卡在界门；改为每月 10% 被窥视的叙事压力 |
| debuff 明示数值 | **只写征兆** | 写公式会把状态卡变成仪表盘，毁气氛 |
