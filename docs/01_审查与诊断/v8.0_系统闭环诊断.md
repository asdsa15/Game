# 系统闭环诊断：为什么这套东西「看着全、玩着假」

> 日期：2026-11-17
> 触发：玩家反馈「框架不完整，逻辑无法闭环」
> 方法：字段读写扫描 + 逐系统追「谁产出、谁消费」+ 对照《太吾绘卷》《了不起的修仙模拟器》的公开机制

---

## 一、结论

项目里不缺系统，缺的是**反馈边**。

绝大多数系统是「A 产出 → B 消费」的单向链，缺了「B 消费之后反过来改变 A 的产出条件」那第二条边。
于是玩家一旦找到最优解（打坐攒修为、攒灵石买功法），其它二十几个系统就退化成装饰——
它们不参与决策，只参与展示。

这就是「假」的来源：**不是数值不对，是决策空间只有一条路。**

### 2.2 曾经断掉的环（本轮已接上）

**① 业力：只值 −6% 破境率**

`grep S.karma` 全项目只有五处消费，其中三处是显示。
杀十个人和一个人没杀，区别小到看不见。这等于「因果」这个词只是文案。

> **已接**：业力 ≥ 30 时破境前强制触发**心魔劫**（三选一：认／抗／借）。
> 「借」成功率 +35%，代价是业力 +15——恶行真的会滚雪球。

**② `S.enemy`（仇家）：写一次，读一次**

夺祀成功时置 `S.enemy = true`，写一句「从此多了一门死仇」，然后就再没有任何代码读过它。
玩家被告知结了死仇，实际上什么也不会发生。

> **已接**：业力 ≥ 50 有概率招来仇家；仇家每月有概率**上门寻仇**（迎战／破财／闭门）。
> 打赢才清账，打输重伤——这条链现在从「你做过的事」一直通到「有人来要」。

**③ `S.enemySect`（叛门追杀）：写一次，零次读取**

叛门面板上写着「立过的誓会咬人」，代码里 `S.enemySect` 出现一次就再没有下文。
叛门＝免费跳槽。

> **已接**：叛门后每月 3% 概率**宗门执法**上门，强度比普通仇家高 15%，打赢才了结。

**④ 道途四印：算出来存在变量里，没人读**

`checkDaoyin()` 认真算了「2 干 2 支且至少一对同阴阳」，存进 `S.daoyinOk`，
然后全项目再没有任何代码读过它。四印配不配成对，对游戏没有任何影响——
而面板上一直写着「四印未配成对——证位时 −15」，这个 −15 从来没实现过。

> **已接**：四印成对 → 破境率 +6%；未成对 → 金丹证位 −15%（兑现面板上的承诺）。

**⑤ 金性：金丹的核心设定，只是一个布尔值**

`S.jinxing = true` 写在结丹那一刻，之后再无读取。
「煅出金性」是金丹与紫府的分野，代码里它等于没写。

> **已接**：金性在，破境失败只散 12% 修为（原 30%）；不在，照旧。

**⑥ 金丹证位：白送**

`GUOWEI_RANK` 里明明有 `rate`（闰位 60／余位 40／正统 20／至尊 5），
从来没有被读过。证位流程没有任何判定——点一下就得到一个果位。
整个仙道最重的门槛，也是唯一不设关卡的地方。

> **已接**：按果位 `rate` 掷骰，四印成对 +15／未成对 −15，道心与功德业力加减。
> 失败则修为散尽、气血去三成，得重新攒。

## 三、对照真实项目：它们怎么闭合

### 《太吾绘卷》

- **内功相生相克**：练相悖的功法会内息紊乱、走火入魔 → 「多练」不是无脑最优，「练什么」才是决策
- **正练／逆练**：同一部功法两种练法，各有利弊 → 不是升级，是取舍
- **寿元与脚程是硬资源**：去哪都要花几天到几个月 → 时间有价格
- **NPC 有独立生命周期**：生老病死、爱恨仇杀，一句话被永久记录 → 世界不等你

### 《了不起的修仙模拟器》

- **瓶颈**：修为满了会卡住，必须突破；困太久掉心情 → 满级不是终点
- **天谴值**：杀凡人、用邪法累积，渡劫时灵气翻倍 → 恶行有数学后果
- **心境**：独立状态，需要「调心」，情绪好调心快 → 情绪是资源
- **五行匹配**：所处地点的五行决定修炼速度（生我＝五个加号）→ **地点有意义**
- **渡劫公式**（公开数据）：
  `灵气 = 基础值 ×(1.2−机缘×0.04)×(1+0.125×五行系数)×(1+天谴系数)×难度×2^渡劫次数`
  → 准备（机缘、地点、天谴、次数）全都进公式，不是掷骰子

### 共同点

它们都把「代价」写进了**公式与流程**，而不是写在文案里。
我们的问题是：代价大多只写在文案里（「从此多了一门死仇」），公式里没有。

## 四、框架层面的四个空洞

### 空洞一：没有「准备」这回事

破境只有「修为满了 → 掷骰子 → 成功／失败」。
没有材料、没有地点、没有时机、没有护法。
《修仙模拟器》的渡劫公式里有五六个可干预项，我们只有一个 `rate`。

**影响**：修为是唯一进度条，玩家只能等。

### 空洞二：地点是背景板

`lingqi` 是「洞府升级档」，不是地点属性。
在青岳和在西漠打坐，速度一样。地图上五个区域只有危险度和战力门槛的区别。

**影响**：地图没有意义，玩家不会为了修为换地方。

### 空洞三：没有外部压力

除了神道的香火反噬和锚崩解，世界不会主动为难你。
`S.enemy` 是唯一的对抗源，刚接上；`S.collapse`（崩解期）只在锚系统里。

**影响**：变强没有代价，世界不会因为你变强而变难。

### 空洞四：目标是数值达标，不是做成事

12 个结局的判定基本是「境界 ≥ X 且 某数值 ≥ Y」。
玩家不知道为什么要破境——除了数字变大。

**影响**：没有目的层，沙盒退化成点击器。

## 五、建议的实施顺序

按「改动小 / 感知强」排序：

1. **地点进公式**（半天）：`PLACES` 增加 `qi` 与 `el` 两个字段，接进 `monthXiuwei` 与 `xianBreakRate`。
   换地方修炼有实质差别，地图立刻活了。
2. **破境准备**（一天）：把破境拆成「开坛 → 择地 → 备药 → 护法 → 过关」，每一项影响成功率。
   让掷骰子变成布置。
3. **功德闭环**（半天）：功德高时，破境可「借一缕人气」抵一次失败；或引来护道者。
4. **声望闭环**（一天）：声望高会被投靠／被挑战，声望低会被劫／被轻视。
5. **目标层**（较大）：每个大境界绑定一件「必须做成的事」，做完才解锁下一境。
6. **清理**（半天）：`SHIXIU` `RENCAI` 要么补完，要么删表；留着不实现的数据只会让下一个人误判完成度。

## 七、一句话

之前的问题是：**「代价」写在文案里，没写进公式里。**
闭环的意思不是「A 能换成 B」，而是「你选了 A，就再也回不去不选 A 的那条路」。

## 八、对标其他项目：还缺什么（2026-11-17 查验）

### 8.1 破境准备已落地

之前破境只有「修为满 → 点一下 → 掷骰子」。现在面板是一张准备清单：

| 准备 | 加成 | 代价 |
|---|---|---|
| **择地** · 洞府内 | `3% + 灵气档×1.5%` | 无（但要先把洞府升上去） |
| **择地** · 宗门禁地 | +5% | 需入宗门 |
| **择地** · 荒野 | 0 | 省事 |
| **备药** · 小破障／筑基／大破障／凝婴 | +12%／+15%／+28%／+35% | 吃了就没 |
| **护法** · 交情 ≥60 的人 | +8% | 好感 −15（欠一次人情） |
| 心魔劫（业力 ≥30） | −15% ~ +35% | 见 2.2 |

三样准备都不是免费的，所以「准备到什么程度」本身成了决策：
是把最后一颗大破障丹留给紫府三关，还是现在就用掉？
护法那 15 点好感，是留给破境，还是留给别的？

**这一改让四套原本悬空的系统同时有了用途**：丹药（消耗品终于有消耗场景）、
洞府灵气（不再只是数字）、NPC 好感（可以兑换成成功率）、宗门（禁地是身份红利）。

### 8.4 建议的下一步（按「补上之后能救活多少系统」排序）

1. **瓶颈** —— 让修为满之后还要满足一个「悟」的条件（悟性／道心／看过某部道书／经历过某件事）。
   它能把**道书、悟道、闲事、NPC 论道**四套系统一起接进主线。
2. **师徒** —— 收一个弟子，教他功法，他会成长、会替你办事、也可能背叛。
   它能救活：宗门线、人锚（现在缺一环）、「逆徒」「杀师」两条归档成就、家族的后辈。
3. **五行进修炼** —— 灵根属性 × 所在地五行 × 功法属性，三者相生相克影响月修为。
   它能让**地图、灵根、功法**三样产生真正的取舍（现在灵根只是个倍率）。
4. **门派经营** —— 宗门有职位没产业；补上产业后，贡献不再是唯一的宗门货币。
5. **心境** —— 独立于气血的情绪状态，影响修炼与破境；能接上「走火入魔」「心魔」。
