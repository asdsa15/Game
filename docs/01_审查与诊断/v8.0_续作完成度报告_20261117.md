## 三、修掉的两个真缺陷

### 3.1 战斗不是战斗，是单向掷骰子

原实现的命中判定是**不对称**的：

- 玩家普攻掷 `Math.random() < 0.72`（遇「老练」敌人降为 0.60），掷不中就 0 伤害，日志只写「未中」
- 敌方回合 `foeTurn()` **完全没有命中判定**，每一击都实打实结算

于是玩家体感必然是「我一直在空挥，他一刀不落」。面板上还直接写着「72%」，等于承认这就是个概率闸门。

**改法**：把「命中／未中」的二值赌博换成连续的**卸力**（`deflectOf`）。

- 每一击必定造成伤害，由受击方按比例卸掉一部分，最低保留 5%
- 卸力由位格差、护体法宝、性格决定，全部可预期：老练之敌卸力高（+10%），莽夫门户大开（−8%）
- 玩家也有卸力，护体法器与位格优势终于看得见
- 「看破破绽」从「下回合必中」改为「下一击无视卸力并增伤六成」——从补救概率变成真正的战术选择
- 太阴宝鉴的「命中 +10」改为按一半抵扣对方卸力，语义不变但不再依赖骰子

顺带修掉一个同源问题：位格差 2 档以上时伤害被压成 **1 点**，日志写「只在对方衣袍上留下浅痕」——这和「未中」是同一种失败体验。现在改为 `mult = 0.15` 并明确提示「位格差得太远」。

**验收**：`tools/sim_combat.js` 跑 120 场，空挥 **0** 次；`test_v80.js` 新增第 10 节，断言「普攻不出现未中」「每次出手都有伤害或明确的卸力/压制说明」。

普攻到底的击杀率仍在 18~30%，这是有意保留的——不用招式、符、丹、守势，本来就该打得很吃力。

### 3.2 信众曲线在后期是死的

这是上份报告标了「逻辑已改、数值验收未完成」的那一项，验出来的结果比预期严重：

- 传教收益是常数（约 115 人/月），信众流失是百分比（1%/月）
- 两者相抵，信众必然在 **1.15 万人**处饱和，与柱位无关
- 而四柱上限是 9,487、五柱 3 万、六柱 9.5 万、七柱 30 万
- 五柱之后单月香火只能吃到需求上限的 34% / 9% / 2%
- 纯传教跑完八柱要约 **220 年**

**修法**：新增 `followerScale() = max(1, 信众上限 / 3450)`，传教与显圣的收益都乘这个系数，让「拉信众」的耗时稳定在一两年。

修完后：八柱全程约 **24 年**，每柱 14~59 月，单月香火至少能吃到上限需求的一半。

**代价（要记住）**：信众现在总能顶到上限，因此「铜香炉」那类只抬香火速率的庙产，在中后期会变成摆设。若之后想让庙产重新有意义，方向是让它抬「香火上限」或「信众上限」，而不是抬速率。
