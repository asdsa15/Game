# v9.0 M4 落地记录 · 探索与轮回

> 日期：2026-11-18
> 范围：上古遗迹（`wxcs3-ext-94-ruin.js`）＋ 百世道果（`wxcs3-ext-95-fruit.js`）
> 原则：新玩法全部放扩展层；`game.js` 只加状态、迁移与一次性接缝。

---

## 一、为什么是这两个

M1~M3 把「修行、外物、人」补完之后，M4 补的是**游戏的两端**：

- **一局之内**：修行不能只有打坐。需要一段有节点、有取舍、有退路的短程探索。
- **两世之间**：百世书不能只继承数值。来世应该继承「世界记得你做过什么」，而不是更大的数字。

遗迹给「这一世」以过程，道果给「下一世」以信息。两者都不新增硬性战力门槛。

## 二、上古遗迹（94）

### 2.1 入口

四条线索，各自只给一次：

| 来源 | 条件 | 频率 |
|---|---|---|
| 道书二读 | 读到第 2 层及以上 | 每局一次（`S.bookRuinClue`） |
| 故人 | 好感 ≥ 60 | 每人一次（`rec.ruinClue`） |
| 拍卖 | 拍得舆图类拍品 | 每件一次 |
| 寻访 | 历练面板「访古」 | 占一旬；总有结果 |

寻访不会空手：优先给未发现、当前境界可进、当前区域可去的遗址；若都已发现，则给 120 灵石 + 悟性经验。

### 2.3 路线与时间

```
entry → trap → lore → fork → trade → guard → relic
```

按深度取子序列：

- 深度 5：`entry trap fork guard relic`
- 深度 6：`entry trap lore fork guard relic`
- 深度 7：完整七节点

| 行为 | 时间 |
|---|---|
| 入洞 | 1 旬 |
| 每走一个节点 | 1 旬 |
| 守关「绕远路」 | 额外 1 旬 |
| 入口处退出 | 0 |
| 深处撤退 | 1 旬 |
| 终点取物 | 0（结算） |

### 2.4 节点选择

| 节点 | 过法 | 代价/收益 |
|---|---|---|
| 机关 `trap` | 遁速 / 神识 / 本命 / 灵兽 | 遁速失败气血 −15%；神识失败灵力 −30%；本命受器损 +8；灵兽掉亲密 −2 |
| 叙事 `lore` | 读纹 / 拓印 / 调息 | 读纹悟性 +1、悟性经验 +2；拓印得 80~200 灵石；调息回灵力 20% |
| 岔路 `fork` | 左：抄近路 / 右：绕行 | 左：跳过下一节点、气血 −5%；右：悟性经验 +2 |
| 交易 `trade` | 让陶俑疗伤 / 绕过 | 花灵石回气血与灵力各 35%；不买则直接过 |
| 守关 `guard` | 斗 / 弟子 / 说理 / 买路 / 绕远 | 斗有伤与缴获；弟子代战掉亲密；说理看悟性；买路按门槛扣石；绕远多一旬 |
| 终点 `relic` | 三选一 | 遗物 / 功法断篇 / 道书或下一条线索 |

### 2.5 三选一与遗物

七件遗物各只加一处，统一走 `EXT.registerMul(kind, fn)`，与命格共用 `fateMul` 读数口：

| 遗物 | 效果 |
|---|---|
| 药王残炉 | 丹药效果 +6% |
| 剑冢残锋 | 剑系招式伤害 +6% |
| 归墟水镜 | 显圣所得 +5% |
| 天机残盘 | 打坐修为 +3% |
| 雷渊骨钉 | 斗法伤害 +5% |
| 血河孤灯 | 斗法缴获 +8% |
| 太虚残印 | 符箓之力 +8% |

功法断篇走 `addGongfa`；已有则折为悟性经验 +6 与 150 灵石。
道书已有则改给下一条未发现遗址方位；再无则给 200 灵石。

### 2.6 旧仇尾随

入洞时若业力 ≥ 60，35% 概率标记 `S.ruin.tail`。取宝结算时一次收走：

```
80 + 遗址门槛 × 60 + 随机 0~60 灵石
气血 −8% 上限
```

尾随写进本趟状态，读档不改判。

## 三、百世道果（95）

### 3.1 计分

| 道果 | 主导经历 | 计分要点 |
|---|---|---|
| 丹火余温 `craft` | 四艺 | 四艺熟练 + 配方 + 制作计数 |
| 门墙旧信 `school` | 道统/师徒 | 道统声望、出师人数、门下弟子 |
| 残香旧庙 `shen` | 神道功德 | 功德、信众、神道/双修 |
| 血途旧怨 `blood` | 魔道血债 | 业力、击杀、血祭、血债 |
| 古径残图 `relic` | 遗迹道书 | 遗物、遗迹计数、道书与阅读层数、奇遇 |
| 无牵无挂 `free` | 都不突出 | 最高分 < 18 |

### 3.2 来世兑现

| 道果 | 兑现 |
|---|---|
| 丹火余温 | 一张当前主修对应的一阶起步配方（避免给了做不出的高阶配方） |
| 门墙旧信 | 一位旧部以 35 好感开局，并留一封 `S.oldLetter` |
| 残香旧庙 | 功德少量保留；神道/双修额外 +60 信众 +60 香火；每月香火 −15 |
| 血途旧怨 | 业力少量保留；一位早期仇家以 −45 好感开局；命格必出「血债」 |
| 古径残图 | 一条遗迹方位；若上一世遗物数为奇数，改给一页《玄景残卷》 |
| 无牵无挂 | 命格候选由 3 条变 4 条，不附带组织与旧债 |

旧庙是唯一带月账的一项；仙道不带庙时不产生香火支出。

### 3.3 生命周期

```
本世结束（do_legacy / do_rebor）
  → fruitSnapshot() 取快照，写 S.daoFruit
  → newGame() 清空本世
  → 创角第一屏 fruitBanner() 展示
  → finishCreate() 调 applyFruit()，applied=true
```

`applied` 防重复兑现；空手投胎（`do_rebor`）同样保留道果。
