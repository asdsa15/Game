## 二、缺陷详述

### B1 ·「战前准备」按钮断链（P1）

**证据**

```js
// wxcs3-game.js:2980 附近，战斗面板里的按钮
optRow('8', '战前准备', {...}, '符箓/丹药', false, 'act:openPreFight')
```

```js
// 2838 行，函数是普通函数，没有挂到 ACT 上
function openPreFight() { ... }
```

`dispatch()` 的 `act:` 分支只会查 `ACT[k]`：

```js
if (act.startsWith('act:')) { const k = act.slice(4); if (ACT[k]) ACT[k](); return; }
```

`ACT.openPreFight` 不存在 → 落空。

**现有表现**：因为上一轮加了兜底 toast，现在点它会弹「此选项暂不可用：act:openPreFight」，**不会卡死，但功能不可用**。

**修法**（一行）：

```js
ACT.openPreFight = openPreFight;   // 挂在函数定义之后
```

或用现有的审计方式一次性查全：`python check_actions.py` 只查了 data.js 的 act，**没查 game.js 里 optRow 的 act**——这也是它没报出来的原因。建议把脚本的扫描范围扩到 `optRow(...)` 的最后一个参数。

### B2 · 旧存档一学功法就崩（P1）

**证据链**

`ownedGongfa` 是新加的字段，**只在创角时初始化**：

```js
// 3587，finishCreate 内
if (!S.ownedGongfa) S.ownedGongfa = ['juqi'];
```

但存档反序列化（1830~1850 那段 `out.xxx = ...` 兜底）**没有它**。于是旧档载入后 `S.ownedGongfa === undefined`。

而三处"获得功法"的操作是**裸 push**：

```js
// 1536  坊市购买
S.ownedGongfa.push(g.id);

// 2708  传法
S.ownedGongfa.push(g.id);

// 2925  奇遇「无名古洞 · 抄录法诀」
S.ownedGongfa.push(g.id);
```

**复现**：载入「该字段加入之前」的存档（本次更新前生成的档）→ 去坊市买一本功法 → `TypeError: Cannot read properties of undefined (reading 'push')` → `render()` 抛错 → **界面冻结**（和昨天机缘卡死同一个病症）。

**为什么现在没暴露**：如果你一直在玩新创的档（17:56 之后创建的），字段存在，一切正常。只有导入旧档或换设备才会踩到。

**修法**（存档兜底加一行，与其它字段保持一致）：

```js
if (!Array.isArray(out.ownedGongfa) || !out.ownedGongfa.length) out.ownedGongfa = ['juqi'];
```

### B3 · 同系加成永远不生效（P2，但影响设计）

**证据**

```js
// 2859 skillMulByName
const g = getGongfa();
if (g && D.ELEMENTS[g.el] && sk.kind && D.ELEMENTS[g.el].name === sk.kind) m *= 1.15;
```

而数据结构是：

```js
// data.js:219
fire:  { name: '火', color: '#C05F55', ke: 'metal' },   // name 是中文
// SKILLS
{ id: 'liehuo', name: '焚山掌', kind: 'fire', ... }      // kind 是英文
```

`'火' === 'fire'` → **永远 false**。

**后果**：这是"修炼功法"与"对战招式"之间**唯一的一条数值纽带**，而它是断的。所以玩家无论用什么功法，招式伤害完全一样——这也正是你觉得"功法应该和战斗有关联"的底层原因。

**修法**：改成比较英文键 `g.el === sk.kind`。

> 顺带一提，这和之前 `keMul` 那个 bug 一模一样：拿中文名去比英文键。这类错误静态检查抓不到，只能靠"看数据结构定义"。

### B4 · 12 张数据表闲置（P2）

`data.js` 定义了 60 个常量，以下 12 个在 `game.js` 里**引用次数为 0**（且代码里没有 `D[...]` 动态访问，确认不是误判）：

```
XIANJI          仙基表
ZODIAC_CLASH    生肖六冲（龙狗/蛇猪…）
PIETY           虔诚
QIHE            契合
ANCHOR_STATES   锚状态
DAOTONG         道统          ← 设定核心
SHIXIU          释修
RENCAI          人材（魔门）
UNLOCK_XIAN     仙道解锁表
UNLOCK_SHEN     神道解锁表
SHOP_CATS       商店分类
ENDINGS         结局表        ← 12 个结局
```

其中两个最刺眼：

- **`DAOTONG`**：道统是《玄鉴》体系的核心（36 个道统、决定仙基与神通池），表建好了、界面没接
- **`ENDINGS`**：12 个结局（飞升/逍遥/一代仙尊/魔道至尊/坐化/陨落/轮回/证得果位/道化/世尊/血债满盈…），没有引用 → 现在的结局判定要么硬编码，要么只有 1~2 个

**建议**：这不是"补 bug"，而是"补完成度"。下一步要么把这两张表接进流程，要么把它们从 data 里删掉，别让设定与实现越差越远。

## 三、优化一：修炼功法 / 对战功法 分家

### 3.1 现状诊断：不是混用，是"两头都浅"

我把当前和功法有关的代码全过了一遍，实际情况是：

| 环节 | 现在怎么算 | 问题 |
|---|---|---|
| **修炼速度** | `monthXiuwei()` 里 `D.GONGFA_TIERS[g.tier].mul` | **只看品阶**。同为黄阶的《聚气诀》和《御风术》修炼速度完全一样 |
| **境界上限** | 无限制 | 黄阶功法也能一路修到金丹。魔门设定里"七品以下无缘筑基"的硬门槛，这里没有 |
| **战斗招式** | `knownSkills()` 按 `S.xRealm` 自动解锁 | **与功法无关**。境界到了就全会，玩家没有养成感 |
| **功法↔招式联动** | `skillMulByName` 同系 +15% | **B3 已证明它永远不触发** |
| **战斗里的功法名** | `do_cbt` 施法时 `note = 施展《${g.name}》` | 只是文案，没有实际作用 |

**一句话**：功法现在只是"一张按品阶给速度的卡"，战斗只是"按境界给的招式表"，两者之间**没有任何有效连接**。

### 3.2 设计方案：双槽 + 上限 + 同源共鸣

#### 槽位

| 槽 | 名称 | 作用 | 数量 |
|---|---|---|---|
| **道基功法** | 主修（内功） | 修炼速度、**境界上限**、仙基品阶 | 1 本，可换（有代价） |
| **杀伐神通** | 斗法（外功） | 可用招式池、招式威力、克制关系 | 3~5 道，可装配 |

数据上就是把现在的 `S.gongfa: []` 拆成：

```js
S.daogong = 'juqi';       // 道基功法 id
S.shentong = ['liehuo'];  // 已习神通 id 数组
S.equip = ['liehuo', ...]; // 战斗装配的 3~5 道
S.ownedGongfa = [...]      // 保留：已收藏的功法书（可阅读、可赠人）
```

#### 数值表（可直接落地）

**道基功法决定境界上限**——这是最能让"功法选择"有重量的一条：

| 品阶 | 修炼系数 | 境界上限 | 说明 |
|---|---|---|---|
| 黄阶 | ×1.0 | **练气圆满** | 散修烂大街的引气法，修到头就是练气 |
| 玄阶 | ×1.3 | **筑基圆满** | 小宗门外门水平 |
| 地阶 | ×1.6 | **紫府三关** | 大宗门内门/真传 |
| 天阶 | ×2.0 | **金丹** | 峰主级、世家嫡系 |
| 仙阶 | ×2.4 | **道胎** | 传说，只在秘境 |

与现有代码的接口：`monthXiuwei()` 里乘 `D.GONGFA_TIERS[g.tier].mul` 保持不变，**新增**一个破境前的检查：

```js
// 破境时
const cap = {huang:1, xuan:2, di:3, tian:4, xian:5}[getDaogong().tier];
if (S.xRealm >= cap) { /* 卡住：提示"功法所限，需换更高阶道基功法" */ }
```

这一条会立刻改变玩法：**黄阶开局的玩家必须先去弄一本玄阶功法，否则永远停在练气圆满**——而不是像现在"随便修，反正都能到金丹"。

**杀伐神通决定战斗风格**：

| 属性 | 作用 |
|---|---|
| `kind`（剑/火/水/雷…） | 克制关系（配合 B3 修好后，与道基功法同系 +20%） |
| `mul`（1.0~1.8） | 伤害倍率 |
| `cost` | 灵力消耗 |
| 稀有度 | 外门层（黄）、内门层（玄）、真传层（地/天） |

#### 同源共鸣（分家的"粘合剂"）

分家不是让两者彻底无关，而是**让"同系"成为一种要主动经营的搭配**：

| 道基功法系别 | 装配神通 | 效果 |
|---|---|---|
| 同系 | 火系道基 + 火系神通 | 威力 **+20%**、消耗 **−10%** |
| 相生 | 木系道基 + 火系神通 | 威力 +10% |
| 相克 | 水系道基 + 火系神通 | 威力 **−15%**，但可触发"逆用"特殊效果 |
| 无关 | 无属性道基 | 无增减 |

数值上就修 B3 那一行，再加一张 `SHENG`（相生）表即可。

#### 来源分流（这是"分家"最有味道的地方）

| 功法类型 | 主要来源 | 门槛 |
|---|---|---|
| 道基功法 | 宗门藏经阁、家族传承、坊市 | 品阶对应身份（外门只能借黄阶） |
| 杀伐神通 | **真传才有资格**、秘境、师承 | 魔门设定："真正厉害的神通都在圣火崖上，非真传不可学" |

**这条直接来自《魔门》原文**：

> "真正厉害的神通都在圣火崖上呢，非真传不可学！"
> "我们这些炼气初期和中期的弟子，那就是圣宗的牛马，怎么可能得授厉害神通？"

所以 3.3 的宗门系统不是可选项——**神通的获取路径必须挂在宗门身份上**，两件事是一件事。

### 3.3 与三本书的对应

| 设计点 | 出处 | 原文依据 |
|---|---|---|
| 道基功法决定境界上限 | 魔门 | "真气法诀至关重要，品阶分为九品三十六阶，**七品以下无缘筑基，三品以下无缘金丹**" |
| 神通与功法分列 | 玄鉴 | 全书"神通"出现 **6,310 次**、"功法"1,394 次，两者从不同层描述战力 |
| 真传才授上乘神通 | 魔门 | 见上引 |
| 同源共鸣 | 玄鉴 | "族中宗中，皆以这玄景灵誓来秘传功法"，功法带道统属性 |
| 换功法的代价 | 玄鉴 | 玄景灵誓："违誓者玄景破碎，一身修为如同流水一般倾泻而出，一时三刻便退为凡人" |

## 四、优化二：家族与宗门势力

三本书刚好各给一半素材：**玄鉴写家族，魔门写宗门**。建议做成两套**互斥或并行的出身系统**，玩家选一条主、另一条可挂靠。

### 4.1 家族（取自《玄鉴仙族》）

**核心事实**（原文采样）：

> "父亲可是要学那书上的宗族法度，**立祠堂，开族府**，读书出仕，习武将兵。"
> "李木田作为李氏最年长的**嫡系**，自然是高高的坐在院中的首位。"
> "**四千二百八十人**，每户三个青壮，怎么也能凑出一两个身具灵窍者。"
> "叶氏诸位**族老**昨夜上门拜访……希望能**恢复祖姓**。"

玄鉴的家族是**实业**：有人口、有祠堂、有族产、有族老会，还要"收拢旁姓、恢复祖姓"来扩张。

**游戏化设计**

| 要素 | 规则 |
|---|---|
| **立族条件** | 筑基期 ＋ 灵石 5,000 ＋ 有洞府 |
| **人口** | 族人数（凡人为主），每月按族人生成"灵窍筛查"，有概率出可修行的苗子 |
| **祠堂** | 家族核心建筑。等级决定：族人上限、族运上限、可传授功法品阶 |
| **族运** | 类似香火的家族资源。族人修行、族中出人才、庇佑乡里都可涨；族灭则清零 |
| **身份** | 嫡系（血脉，可继任族长）／旁支（同姓不同房）／客卿（外姓供奉，可"恢复祖姓"入族） |
| **族老会** | 3 位族老，各有立场（保守/激进/贪利），重大决策需过半 |
| **族规** | 开局自定 3 条（如"不得杀凡人""须护族人""不得入魔道"），违者族运暴跌 |
| **产出** | 每月族人供奉（灵石）、灵田产出、血脉天赋（后代灵根更好） |
| **代价** | 族人被杀你不出头 → 族运崩；你结仇太多 → 仇家上门灭族 |

**与现有系统的接口**：族运可以**双向兑换**——仙道玩家把族运转成修炼加成（"族人供奉香火助你闭关"），神道玩家把族运转成信众（"一族即一庙之基"）。这刚好接上你已有的两套体系。

### 4.2 宗门（取自《魔门》）

**核心事实**（原文采样，这套结构非常完整）：

> "我圣宗弟子，有**内外之分，外门四殿**：炼宝、炼丹、御兽、合欢，就是你们这些记名弟子的去处。"
> "只有通过了**外门四殿的考验，才能进入内门，得授真传**，成为正式弟子。"
> "内门四峰之一，**补天峰峰主**的儿子！失踪的**真传**！"
> "咱们这藏书阁只是补天峰的分阁，**功法神通威能都有限**。"

**游戏化设计**

| 层级 | 门槛 | 待遇 | 限制 |
|---|---|---|---|
| **记名弟子** | 通过外门一殿考验 | 黄阶功法、每日杂役 | 无月俸，任务繁重 |
| **外门弟子** | 贡献 500 ＋ 练气中期 | 月俸、玄阶功法 | 需上供 |
| **内门弟子** | 贡献 2,000 ＋ 筑基 | 地阶功法、独立洞府 | 需听调 |
| **真传** | 峰主亲收（需大比夺魁/特殊机缘） | **可学上乘神通**、藏经阁全开 | 需站队，卷入峰争 |
| **峰主/长老** | 元婴 ＋ 一峰之功 | 收徒、分配资源 | 需护山，被挑战 |

**三个关键机制**（都能直接落地）：

1. **藏经阁分级**：外门层只有黄/玄功法，内门层有地阶，**神通层只有真传能进**。这直接实现 3.2 的"来源分流"。
2. **贡献点**：任务（采药/巡逻/猎妖/镇守/炼丹）给贡献，贡献换功法/丹药/洞府。比现在的"宗门任务+2~5 声望"具体得多。
3. **叛门代价**——这条最有戏，取自玄鉴的"玄景灵誓"：
   > "违誓者玄景破碎，一身修为如同流水一般倾泻而出，一时三刻便退为凡人，且气衰神竭，应誓而死。"

   游戏里：入宗时立誓 → 叛门则**修为跌落一个大境 + 道心永久 −3**，且原宗门追杀。这让"跳槽"变成真正的抉择，而不是换个门派继续玩。

### 4.3 家族 vs 宗门：怎么共存

| 路线 | 适合 | 核心矛盾 |
|---|---|---|
| **家族为主** | 想"养"的玩家 | 家族要人、要地、要时间，与"一个人闭关百年"冲突 |
| **宗门为主** | 想"爬"的玩家 | 宗门要贡献、要站队，与"逍遥自在"冲突 |
| **两头挂** | 高风险 | 家族子弟入宗门＝质子；宗门弟子立族＝被视为分裂，两边都降好感 |

`cultivation: 'both'`（双修）现在只是个减益标记，**家族/宗门正好可以给它一个真正的玩法**：一族一宗，两头经营。

### 4.4 与现有系统的衔接

| 现有系统 | 家族怎么接 | 宗门怎么接 |
|---|---|---|
| **八柱（神道）** | 一族即一庙，族运↔香火 | 宗门即"上级城隍"，可借祀 |
| **道统（玄鉴）** | 家族血脉决定道统倾向 | 宗门决定你能接触到哪些道统 |
| **果位（魔门）** | 家族可世代争同一个果位 | 宗门替你抢位（也可能替别人抢你的） |
| **仙基** | 家族传承仙基（可继承） | 宗门分配仙基（需贡献） |

## 五、优化三：中间栏境界字号

### 5.1 现状

中间栏的面板标题是 `'庙中 · ' + timeLine()`，境界作为副标题挂在右上角：

```css
/* 问道长生v6.html:73 */
.panel .ph .sub{ margin-left:auto; font-size:11px; font-weight:400; opacity:.92; }
```

**境界只有 11px、常规字重、还带 92% 透明度**，而且挤在青玉色标题栏的右端。而它旁边 `.scene`（场景文字）是 13px。

也就是说：**最重要的状态信息，比正文还小、还淡。**

## 六、参考三本书的其他可借鉴点

按"能不能直接做进游戏"筛过一遍，只留可落地的：

| # | 机制 | 出处 | 原文/依据 | 怎么做 |
|---|---|---|---|---|
| 1 | **果位唯一性** | 魔门 | "玉枢剑阁竟有真人先行一步，证了「壁上土」的果位，**瞬间就绝了**听幽祖师的道途" | 每个果位全服唯一。NPC 先证了，你的路就断了，必须另开创法（听幽祖师就是这样开创【阎魔殿】） |
| 2 | **庙规与忌讳** | 俗主 | "河神不吃昨年祭""山神庙下不歇脚""土地公前不问路" | 每座神庙 3 条忌讳，触犯则香火暴跌／神位贬谪。神道线立刻有了"信仰的规矩" |
| 3 | **四梁八柱** | 俗主 | "请五路兵马，**入四梁八柱**" | 你已经有八柱，可以补"四梁"作为八柱之前的准备层（庙基/庙产/庙规/庙祝） |
| 4 | **玄景灵誓** | 玄鉴 | "违誓者玄景破碎，一身修为如同流水一般倾泻而出" | 入宗/入族立誓，叛则修为倾泻。比"扣声望"重得多 |
| 5 | **神通法体** | 玄鉴 | "那凶人练成了神通法体，血肉筋骨皆为天材地宝，故而被三宗七门撕得四分五裂" | 高阶修士陨落 → 尸身成为可争夺的天材地宝。**残酷感**拉满，也解释了"为什么高手死了有人抢" |
| 6 | **祖姓与收族** | 玄鉴 | "叶氏诸位族老……希望能恢复祖姓" | 家族扩张的具体动作：收旁姓、赐祖姓、记族谱 |
| 7 | **道途四步** | 魔门 | "凑齐一个，筑基中期。凑齐三个，筑基后期。凑齐四个，筑基圆满" | 你已有道途四印，可对齐成"每凑一印升一小阶"，比现在"四印齐了才算"更有进度感 |
| 8 | **法仪即授权** | 魔门 | "设下法仪，取来符节和斧钺……**假节钺，使人代行权位**" | 法仪不只是证位仪式，还可以是"授权他人代行"，做成"托付"机制的仪式版 |

第 1、5 条我最想推荐——它们能立刻制造"这个世界的规则会咬人"的感觉，而这正是你这套设定的灵魂。
