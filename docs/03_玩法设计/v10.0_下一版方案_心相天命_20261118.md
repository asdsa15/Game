# 问道长生 v10.0「心相天命」下一版方案

> 日期：2026-11-18
> 性质：方案稿，**未修改任何游戏代码**。
> 前提：v9.0 的 M0~M5（命格、天劫、本命法器、灵兽、师徒道统、固定开销、时限事件、属性分档、遗迹、道果、发布）**均按既有计划实现**，本方案不重复其中任何一项。
> 定位：v9.0 解决「不同玩家走出不同一生」；v10.0 解决「**这一生为什么会有命运感，以及死得有意义**」。
> 方法：只取同类游戏的公开机制，对照本项目 `docs/99_归档/v6-v8_历史版本记录/v8.0_对标研究_12个样本.md` 中「已指出但尚未落地」的空白。

---

## 一、为什么是这六项：v9.0 的真空区

v9.0 把「系统能不能用」和「玩家能不能走出不同流派」都解决了，但对标研究里点名的四个空白，它一个都没碰：

| 对标空白（v8.0 已指出） | 现状证据 | v10.0 对应 |
|---|---|---|
| 心境不存在 | `grep 心境` = 1（说明文字）；六维属性只进数值不进心理 | **心相系统**（F1） |
| 天命盘「可见判定＋可重骰」 | 破境是「准备＋掷骰」，但补正不展示、没有重骰口子 | **命运盘＋改命点**（F2） |
| 恶名/名声的消费端弱 | 名声只影响传教倍率、交涉、一个结局 | **声望双面消费**（F5） |
| 对象槽 Verb＋Card | 意图引擎仍是「输入采药→系统定结果」 | **对象槽**（F4） |

另加两项 v9.0 完全没有、但对「命运感」最关键的：

| 空白 | 现状 | v10.0 对应 |
|---|---|---|
| 寿元形同虚设 | 寿元 120~700 年，升境仅 1.5~42 年，从没有「寿终」这个有分量的结局 | **生死簿 / 死法即叙事**（F3） |
| 瓶颈不存在 | 修为满就能破，道书/论道/闲事四套系统没接进主线门槛 | **悟道瓶颈**（F6） |

## 二、真实对标（2026-11-18 核实，只列直接用到的）

| 项目 | 核实到的机制 | 本方案怎么用 |
|---|---|---|
| 《活侠传》 | **心相值**：心情是独立于属性的模糊状态，为零也能行动，但影响关键事件**解锁选项**与判定；**天命盘**：事件分歧时显示骰点区间与补正项，玩家「尽人事」，另有命运点可重骰；**生死簿**：99 种死法各有专属达成条件与叙事；四轴五档属性让同一剧情出不同文本 | F1 心相、F2 命运盘、F3 死法、F6 属性文本 |
| 《鬼谷八荒》 | 先天气运在创角定方向；逆天改命在破境时做永久构筑；奇遇触发受**声望/道德/地域/季节**影响；血祭类选项「实力暴增但减寿、引来仇家」 | F2 改命点、F5 声望消费、F3 寿元代价 |
| 《Cultist Simulator》 | **Verb＋Card**：同一动词放不同卡，结果完全不同；**恶名**招来猎手与对手，是失败的自然后果而非惩罚弹窗 | F4 对象槽、F5 恶名招祸 |
| 《Fallen London》 | **Storylet**（前置条件＋分支＋结果）与 **quality parsimony**（状态变量越少越好）；项目 92 字段撑 45 动作是**倒挂**的 | F4 回复用现有字段、不新增状态 |
| 《觅长生》 | 心魔劫在选项里埋必死答案；**寿元硬限**是真约束 | F1 心相低时心魔、F3 寿元 |
| 《了不起的修仙模拟器》 | 瓶颈不是单一概率，含历练/道心/天谴；心境需「调心」维护 | F6 悟道瓶颈、F1 心相维护 |

## 三、六项新版功能（每项含入口／结算／反馈／测试）

### F1 · 心相：一条会波动的心理轴（全新系统，非第七属性）
- **定位**：心相是**状态**（0~100，五档：澄明/平和/浮动/郁结/魔动），不是属性。属性是「你是什么人」，心相是「你现在怎么样」。
- **入口**：不新增常驻按钮。心相值显示在现有资源条，点开「调心」页（静坐/论道/饮酒/游历/做梦/服清心丹）。
- **结算**：
  - 杀伐、背叛、欠费、旧仇上门 → 心相下降；济世、论道、护法、读完道书 → 回升。
  - 心相**每月自然漂移**（受固定开销与洞府环境影响），要花旬维护，形成持续成本。
  - 高心相解锁「问心」「顿悟」类选项；低心相（魔动档）解锁「走火入魔」「自暴自弃」类选项，并提高心魔事件权重。
- **与 M1 的边界**：M1 天劫是**破境瞬间**的判定；F1 是**常驻状态**，贯穿所有月份。二者通过「雷劫心魔读当前心相」联动，不重复。
- **测试**：六档转换、月度漂移、调心各手段、低心相触发心魔、旧档补默认心相。

### F2 · 命运盘与改命点：看得见的判定，和不甘心时的一个口子
- **入口**：所有重大判定（破境、关键奇遇、论道、生死对决）统一用一块「命运盘」面板。
- **展示**：骰点区间、每一项补正（功法/丹药/心相/命格/准备/洞府）**逐条列数值与来源**、最终成功率构成。玩家第一次能看清「我做了哪些准备、各值多少」。
- **改命点**：跨世积累的稀缺资源（与 M4 道果不同——道果改**下一世起点**，改命点改**这一次判定**）。消耗 1 点对已掷判定重骰一次，重骰前可见、不可无限刷。
- **来源**：每世按「重大选择达成」给少量，不按时间刷；死法（F3）也产出一点，鼓励「认真活完」。
- **测试**：补正逐条正确、改命点扣减与跨世继承、重骰不可重复刷、同种子可复现（复用 M0 的 RNG）。

### F3 · 生死簿：把死亡从「游戏结束」变成叙事内容
- **入口**：死亡结算页从「你死了」升级为「**死因卷**」——写明死法、触发链、年谱记录、对道统/弟子/道果的影响。
- **死法**（首批 12 种，按现有系统就能达成）：寿终正寝、坐化、兵解、心魔自焚、走火入魔、破境陨落、丹毒、本命反噬、仇家寻仇、为护弟子/道侣而死、香火断绝（神道）、坐困洞府。死法是**达成条件的自然结果**，不是掷骰标签。
- **寿元落地**：寿元成为真倒计时（配合 F6 瓶颈，升境不再无限快），「寿终」是有分量的正常结局，不再是数值溢出。
- **跨世**：每种死法给下一世一句残忆 + 改命点（F2），接 M4 道果但不重复其内容。
- **测试**：12 种死法各自可达、死因文本与数值一致、年谱写入、跨世继承、寿元到点不卡死。

### F4 · 对象槽：把意图从「做什么」升级为「拿什么去做什么」
- **入口**：自由行动意图输入后，多一步「选择对象」（对象来自**现有**地点/设施/人物/物品表）。
- **改造**：30 类意图 × 3~5 类对象。例：
  - 采药 × 洞府后院 / 后山 / 妖兽巢边（风险、产出、心相影响不同）
  - 送礼 × 灵石 / 自炼丹 / 自制符 / 家传物（好感与后续钩子不同）
  - 炼丹 × 蓝幽草 / 妖丹 / 旧丹（成品与丹毒风险不同）
- **状态节俭**：只复用现有字段，**不新增状态变量**——这是把 92 字段撑 45 动作的倒挂比例往上扳的关键一步。
- **测试**：30 类 × 对象组合全部可结算、无空文本、不新增未读字段、意图分档表同步。

### F5 · 声望的双面消费：名声招来什么，恶名招来什么
- **入口**：不新开面板，在现有「人情 / 钩子」页加一页「**江湖传闻**」，列出当前声望等级会招来的正面与负面事件。
- **结算**：
  - 高声望 → 访客投奔、拍卖好价、论道对手上门、遗迹线索主动出现。
  - 高恶名 → 仇家提前、坊市拒卖、官方注意、心魔权重上升（与 F1 联动）。
  - 声望来自「做过的事」（济世/论道/出师/破境），不靠买；恶名来自「杀伐/背信/血祭」。
- **对标落点**：这正是 Cultist Simulator「恶名招猎手」的成熟做法——后果是**世界反应**，不是惩罚弹窗。
- **测试**：声望/恶名各档事件池命中、钩子系统正确消费、不出现「声望涨了没人读」的死字段。

### F6 · 悟道瓶颈：修为满之后，还差一个「悟」
- **入口**：破境面板在「修为满」之外，多显示一条「**悟**」的进度与缺口的来源提示。
- **结算**：悟通过四条现有路径积累——道书读到某层、论道问答、特定闲事、NPC 指点。每条路径只给一部分，逼玩家「做功课」而不是干等修为。
- **效果**：卡境变成叙事（「你读到了那句话，却还差一步」），而不是进度条停住；道书/论道/闲事四套现存系统第一次接进主线门槛。
- **测试**：四路径各自贡献、悟未满时破境被正确拦截、提示文本与实际缺口一致。

## 四、优化路线（三阶段，可与 v9.0 的 M2~M5 并行开发，不冲突文件）

| 阶段 | 内容 | 与 v9.0 的关系 | 完成标准 |
|---|---|---|---|
| **N1 判定层** | F2 命运盘＋改命点、F1 心相 | 在 M1 乘区注册表上扩展；复用破境面板，不新增常驻按钮 | 判定补正逐条可见；改命点跨世继承；心相六档与月度漂移可测 |
| **N2 叙事层** | F4 对象槽、F6 悟道瓶颈、F5 声望消费 | 不改 v9.0 的剧情系统，只给意图/破境/钩子加一层 | 30 类意图对象全可结算且不新增状态；悟的四路径可测；声望各档有事件 |
| **N3 终局层** | F3 生死簿＋寿元落地 | 接 M4 道果、M1 心魔，但内容独立 | 12 死法可达、寿终成为正常结局、跨世残忆与改命点正确继承 |

### 四条并行护栏（贯穿三阶段）

1. **不新增常驻入口**：常驻区已 18 项是已知痛点。F1~F5 全部挂进现有面板（资源条、破境、人情、意图输入），只在 M5 统一做一次指令坞重排。
2. **状态节俭**：每加一个字段先答「谁读？」——F4 明确零新增字段；其余功能优先复用 `HEART`/`FAVOR`/`HOOKS`/`SHIXIU` 等既有表。
3. **架构不变**：所有新逻辑写 `wxcs3-ext-*.js`，`game.js` 只留薄缝，沿用 M1 的乘区注册表；不把 1 万行文件再加厚。
4. **发版收口**：N3 完成后与 v9.0 的 M5 合并做一次全量校准，断言从 650+ 提到 **800+**，390px 面板复测，PWA/APK/Electron 同步。

## 五、MVP 建议

若只做一版先验证「命运感」是否成立，最小范围是：

> **F1 心相 ＋ F2 命运盘 ＋ F3 生死簿（先做 4 种死法）**

理由：三者共用一条因果链——行动改变心相 → 心相进命运盘补正 → 判定失手导向具体死法 → 死法写成有分量的结局并反馈到下一世。它不需要等 F4/F5/F6 完成，就能验证「这一生有没有命运感」这个核心命题。

## 六、风险与边界

| 风险 | 对策 |
|---|---|
| 心相变成第七个「又得刷」的属性 | 定位为**会漂移的状态**，维护要花旬，且低档不是纯惩罚——也解锁特殊路线 |
| 改命点破坏稀缺性、变成无限重骰 | 每世固定少量来源、单次判定限一次重骰、同种子可复现可审计 |
| 死法做成「掷骰贴标签」 | 死法必须有**达成条件链**，文本解释数值；写不进年谱的死法不算数 |
| 对象槽让意图表爆炸 | 复用现有字段，先做 8 类高频意图试点，过了再铺 30 类 |
| 与 v9.0 抢文件 | F1~F6 全部在扩展文件实现；指令坞重排统一推迟到 M5 |
| 与 M1 心魔/M4 道果重复 | 明确分工：M1=破境瞬间，M4=跨世起点，v10=常驻状态与终局叙事 |

## 七、一句话结论

> v9.0 让玩家「选择成为什么样的人」；v10.0 让这个选择**有重量**——心相记录你走过的心情，命运盘让你看清赌注，生死簿让每一次结束都成为一段能写进年谱的故事。
