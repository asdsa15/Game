# v9.0「道承百世」下一版方案

> 日期：2026-11-18  
> 性质：**方案稿，未修改任何代码**  
> 方法：对照六款真实项目的公开机制，结合本项目现有旬制、破境、四艺、NPC、经营和文本系统，提出下一版优化方向与功能。  
> 核心判断：当前版本已经基本解决「系统能不能用」，下一版应解决「不同玩家能不能走出不同的一生」。

---

## 一、下一版的核心定位

### 一句话

> **每一次破境都改变打法，每一件外物都能成长，每一个人都记得选择，每一世都留下道统。**

v9.0 不再以「再增加多少个面板」为目标，而以四件事为目标：

1. **流派构筑**：同样是金丹，丹修、剑修、神祀、魔途应明显不同。
2. **成长陪伴**：法器与灵兽不是一次性商品，而是能陪玩家走到后期。
3. **世界反馈**：NPC 不只提供好感数值，还会记仇、报恩、传承和改变命运。
4. **跨世意义**：上一世的选择不只给一个数值礼包，还应改变下一世的起点与可选道路。

### 保留的产品边界

- 单机、纯文字、轻量前端；
- 一月三旬，每个重要行动都有机会成本；
- 仙道为主、神道为辅，四艺是手段而非职业；
- 叙事有代价，不做无条件奖励机；
- AI 只能作为可选增强，不能成为运行依赖。

## 二、真实项目对照与可借鉴方向

以下只借鉴机制，不照搬题材、数值和体量。

| 真实项目 | 已查到的核心机制 | 对本项目的启示 | v9.0 对应设计 |
|---|---|---|---|
| 《太吾绘卷》 | 功法存在正逆练等不同取舍；NPC 有关系、经历、生老病死；功力可传给下一代 | 功法不能只是倍率，人物与传承要共同形成流派 | 道痕命格、NPC 长期目标、师徒与道果 |
| 《了不起的修仙模拟器》 | 修炼受地点五行、心境、瓶颈、食物与门派管理影响；瓶颈不只有概率，还包括历练、道心、雷劫 | 修炼要受环境与状态约束，突破应是准备过程 | 五类天劫、洞府环境、固定开销、状态化突破 |
| 《鬼谷八荒》 | 突破时出现逆天改命候选，永久改变构筑，同系列可进阶替换；宗门有宗风与禁忌 | 每个大境界都应留下一个构筑选择，而非只增加战力 | 道痕命格、道统门规 |
| 《活侠传》 | 上中下旬共享行动点；部分事件只在特定时间出现；性格和隐藏参数影响剧情与选项 | 行动预算要服务事件选择，而不是只服务资源效率 | 时限事件、属性分档选项、日程化 NPC |
| 《一念逍遥》 | 本命法宝可自定义方向、名称并持续祭灵成长；灵兽通过内丹共鸣提供战斗辅助 | 外物应可培养并进入战斗，而不是买完即结束 | 本命法器、灵兽共鸣、第四战斗位 |
| 《想不想修真》 | 洞府经营、肉身、门派和境界解锁构成长期成长线 | 后期目标不能只靠境界数字，需要长期经营与解锁 | 洞府岗位、固定开销、阶段目标与道统 |

### 明确不照搬

- 不做多人宗门战、跨服和交易行；
- 不做全网格风水与完整殖民地模拟；
- 不做抽卡、氪金随机古宝；
- 不默认开放离线秒涨修为；
- 不用无限增加境界来制造后期内容；
- 不照搬实时动作战斗，继续保持文字策略。

## 四、v9.0 新版功能

## 4.1 道痕命格：突破后的永久构筑选择

### 玩家体验

每次跨大境界时，在破境结算后从三道「道痕」中选一道。选择永久生效，同一系列后续可进阶替换，而不是无限叠加。

示例：

| 系列 | 初阶效果 | 明确代价 | 后续方向 |
|---|---|---|---|
| 丹火养命 | 自炼/自用丹药效果提高 | 非四艺行动的修炼收益略降 | 丹炉共鸣、药性专精、活死人丹 |
| 负薪问道 | 读书、闲事、论道额外获得悟道 | 每月固定开销增加 | 凡尘问道、道心瓶颈减免 |
| 一剑破法 | 剑系招式增强 | 符箓与权柄效果下降 | 剑意、剑心、本命飞剑联动 |
| 万家香火 | 显圣与愿物收益提高 | 个人斗法能力下降 | 庙祝、神祀、众生愿 |
| 血债偿心 | 杀伐收益提高 | 仇家与心魔来得更快 | 血祭、逆练、魔门道果 |
| 守拙藏锋 | 遁走、守势、卸力增强 | 主动进攻收益下降 | 苟道、洞府防御、临终一线 |

### 设计约束

- 每道命格都必须同时有收益与代价，不能只选最高倍率。
- 候选受玩家本世行为影响：炼丹多者更容易见丹道，杀人多者更容易见魔途。
- 提供一次有限的重悟机会，需消耗时间、道书或修为，不能随时免费换流派。
- 不增加新的职业栏，不破坏「四艺是手段」的既有原则。

## 4.2 五类天劫：把破境变成一场可准备的考试

沿用已有破境准备，不另做一套重复面板。

| 劫类 | 主要考察 | 有效准备 | 失败后果建议 |
|---|---|---|---|
| 三问雷 | 道心、问心记录、近期选择 | 道心、问心类闲事、清心丹 | 道心受挫、额外心魔事件 |
| 倒天河 | 灵力容量、调息与水系准备 | 水系/吞纳功法、回灵丹、洞府灵气 | 灵力受损、修为散一部分 |
| 无灯焰 | 外物与护具 | 任一法器或神器、护体符、淬体 | 法器受损、气血下降 |
| 折骨风 | 肉身与疗伤 | 淬体、体质、疗伤药、静养 | 重伤、三旬行动受限 |
| 故人关 | 恩义、人情与旧仇 | 清还钩子、护法、故人来信 | 生成新恩义或旧仇后续 |

### 关键修正

- 不再按主修五行硬映射劫类，避免雷/风没有对应五行的问题。
- 劫类由「近期行为权重＋境界固定池」产生，保证每条路线都有克法。
- 无灯焰必须允许仙道法器参与，不能只认神道神器。
- 突破面板必须显示：劫类、已有克法、缺口、失败代价、预计成功率。
- 不再以一次纯随机判定决定全部结果；准备决定主要结果，随机只保留少量波动。

## 4.3 本命法器与灵兽：一器一兽，陪走一生

### 本命法器

只允许一件本命，分四阶：

1. **认主**：选定已有法器，获得基础联动；
2. **通灵**：解锁一条法技，产生维护需求；
3. **共命**：进入战前准备，可提供主动技能；法器受损会反噬主人；
4. **合道**：与一种道痕或道统联动，并成为物锚的稳定来源。

玩家可自定义名称和方向，重铸保留大部分培养，但消耗时间与材料。

### 灵兽

- 来源复用妖物认亲、猎妖、遗迹与拍卖，不新增抽卡。
- 两轴成长：**亲密**与**妖力**。
- 亲密决定护主、听令与叛逃；妖力决定伤害、卸力和化形。
- 战斗中作为第四位，有独立气血与行动，不直接加进玩家战力数字。
- 高亲密可挡击、救主；低亲密可能不听令甚至反噬。
- 神道可封兽官，消耗香火俸禄换取庙宇能力。

### 数量边界

- 一件本命法器；
- 一只主战灵兽，兽栏按洞府等级扩容；
- 不做无限宠物栏和纯数值收集。

---

## 4.4 师徒与道统：从个人修行到「有人接着走」

### 师徒

首版最多两名弟子，独立新建 `DISCIPLE_LIMIT`，不复用信众上限。

弟子有四种长期出路：

- **出师**：可以护法、经营、入遗迹或继承担任人锚；
- **留山**：提供洞府/宗门岗位，但占用供奉；
- **叛师**：与门规、待遇、玩家行为有关，不是纯随机；
- **先亡**：形成葬礼、年谱和跨世残忆。

师徒与现情缘 NPC 可以共享人物身份，但师徒关系和恋慕关系必须分开记录，避免一套好感承担全部语义。

### 道统

不是完整组织 AI，而是轻量经营：

- 立道号、选一条门规、设一处山门；
- 门规影响收徒、月课、供奉和叛徒率；
- 每月有固定开销与供奉结算；
- 道统声望来自弟子出师、济世、论道和遗迹，而非单纯买资源；
- 道统结局与「开宗」「逆徒」「杀师」等归档成就重新接通。

## 4.5 洞府环境与固定开销：让「不动」也有代价

### 简化环境五行

不做网格风水，只保留三层：

1. 地点属性：青岳木、赤炎火、流沙土、寒渊水、天阙金等；
2. 洞府设施：蒲团、丹房、炼器房、阵眼、灵田；
3. 季节与功法：相生小增益、相克小惩罚，避免极端倍率。

影响范围：

- 打坐修炼；
- 四艺成功率；
- 天劫准备；
- 灵兽与药圃产出。

### 固定开销

统一进入现有月度账本：

- 洞府设施与阵盘维护；
- 家族口粮与药圃维护；
- 宗门月课或最低贡献；
- 庙宇香烛、守庙人与法器维护；
- 弟子供奉、灵兽口粮、本命维护。

欠费不应直接死档，按「停用 → 降级 → 离心/离散」逐级处理，并给出至少一个月预警。

## 4.6 时限事件与属性分档：属性决定能看到什么

### 时限事件

- 在特定年、月、旬出现的短事件，不再全部随机等概率。
- 例如：拍卖前一月预告、故人生辰、宗门大比、遗迹开启、旧仇约期。
- 错过不会卡主线，但会改变后续关系与资源。

### 属性分档

六维不只进成功率，还进入文本与选项：

- 高悟性：看见道书隐层与劫类提示；
- 高神识：识破幻术、隐藏拍品和 NPC 来意；
- 高道心：出现额外问心选项；
- 高仙缘：看见特殊路线，但不直接保证好结果；
- 高遁速：增加撤退与赶路方案；
- 高资质：提高同旬修炼产出，但不扩大事件选项。

每个属性只承担 2~3 类稳定职责，避免所有事件都变成六维轮番判定。

## 4.7 上古遗迹：5~7 节点短程探索

### 结构

每处遗迹由 5~7 个节点组成：

```text
入口 → 路况/机关 → 人物或叙事 → 岔路 → 守宝/交易 → 遗物 → 出口
```

玩家每走一个节点消耗一旬，可在多数节点选择撤退。  
奖励不是直接发天阶物品，而是三选一：遗物、功法断篇、道书/地图线索。

### 与现有系统联动

- 道书三读、NPC 告知、拍卖地图、宗门任务提供入口；
- 灵兽可嗅出危险，本命法器可克制机关；
- 旧仇可能尾随，弟子可以同行；
- 遗物可成为本命胚胎、物锚或下一世道果。

## 4.8 百世道果：上一世改变下一世

在现有百世书与残忆之上，新增「道果」而不是再加一套永久数值叠加。

| 上世主要经历 | 下一世变化 |
|---|---|
| 丹道/四艺突出 | 开局多一张配方或一处采集线索 |
| 道统/师徒突出 | 开局收到一封旧部来信，不直接送满级弟子 |
| 神道功德突出 | 一处旧庙仍有残香，但有对应责任 |
| 魔道/血债突出 | 早期仇家与特殊魔途命格出现，兼具风险 |
| 遗迹/道书突出 | 得到一条遗迹方位或道书残页 |
| 逍遥/无功而过 | 开局命格候选更自由，不附带组织负担 |

原则：道果主要改变**信息、候选与初始关系**，不直接给大额战力，避免多周目滚雪球。

## 五、现有系统的优化方向

### 1. 从「功能面板」改成「构筑面板」

新增一页即可查看：

- 当前命格与代价；
- 本命法器与主战灵兽；
- 常用招式、法器、神通搭配；
- 洞府环境对当前功法的影响；
- 当前劫类与缺失准备；
- 弟子、道统与人锚状态。

目的不是增加展示，而是让玩家知道「我现在是什么流派」。

### 2. 行动预览统一

所有重要行动在执行前显示：

- 消耗几旬；
- 灵石、香火、材料、好感等成本；
- 可能获得的资源；
- 对固定开销、心魔、旧仇和命格的影响。

减少「点完才发现少了一旬」的挫败。

### 3. 事件结构数据化

新增事件逐步统一为：

```text
条件 when → 成本 cost → 选项 options → 效果 effect → 文本 log → 后续 next
```

避免继续增加只写不读的死字段和无法触发的结局。

### 4. 可复现随机数

增加存档内随机种子或统一 RNG 包装：

- 同一测试存档可以复现天劫、拍卖、NPC 来访和遗迹结果；
- 不改变正常玩家的随机体验；
- 主要用于自动化测试、平衡模拟和缺陷复现。

### 建议的 v9.0 MVP

若希望先发布一个可玩的中间版本，最小范围建议为：

> **M0＋M1＋本命法器**。

它能先形成「破境—命格—本命」的新核心循环，不必等师徒、遗迹全部完成才验证手感。

## 七、数值与内容边界

1. 一月三旬保持不变，不通过增加行动点制造养成膨胀。
2. 命格收益原则上不超过同级系统的一档强度，且必须有实际代价。
3. 环境五行只做小增益/小惩罚，不制造绝对最优地点。
4. 本命与灵兽都有维护成本，避免免费永久外挂。
5. 遗迹以 5~7 节点为限，不做无限刷层。
6. 道果不直接叠加大额永久战力。
7. NPC 数量以叙事能维护为限，不做千人组织模拟。
8. 新功能必须同时有入口、结算、反馈和测试，不能只写数据表。

- 命格互斥、进阶替换、行为影响候选和重悟成本；
- 本命与灵兽成长、反噬、死亡、旧档迁移；
- 弟子出师、叛师、留山、先亡与相关成就；
- 遗迹撤退、节点消耗、奖励唯一性；
- 道果跨世信息与候选变化；
- 同一随机种子下结果可复现；
- 三种样板流派：丹器散修、神祀道统、杀伐魔途。

### 体验验收

- 390px 手机端构筑面板和破境面板无横向溢出；
- 任一新功能可在三次点击内从常驻区到达；
- 所有高代价操作执行前可见成本；
- 不出现「文案说一套、数值记一套」；
- PWA 更新后不会停留在旧缓存。

---

## 九、暂不作为 v9.0 目标的内容

以下内容可以保留到 v9.x 或无限期后置：

- 完整 LLM NPC/动态叙事依赖；
- 多人在线、宗门战和玩家交易；
- 全网格风水与完整门派殖民模拟；
- 无限遗迹、抽卡和离线挂机收益；
- 单纯增加更多大境界和战力数量级；
- 为了「有 AI」而把关键存档或文本放到服务器。

---

## 十、最终方案摘要

v9.0 的主循环应收束为：

```text
日常旬制取舍
  ↓
修炼/经营/人情积累
  ↓
准备并渡过特定天劫
  ↓
选择永久道痕命格
  ↓
培养本命与灵兽、形成个人流派
  ↓
收徒立规、探索遗迹、处理旧账
  ↓
以本世经历凝结道果
  ↓
下一世获得不同起点、候选与关系
```

它比单纯增加系统更重要的地方在于：

> **玩家不再只是把所有功能点一遍，而是在有限时间里，选择自己要成为什么样的人，并承担这条路的后果。**
