## 一、定位：四艺是手段，不是身份

### 1.1 先纠正一个错误方向

曾经设计过「丹修／器修／符修／阵修」四条修炼路线。这是把 **工具当成了职业**。

在修仙世界里，一个筑基修士白天炼丹、晚上打坐、遇到仇家贴张符就跑——**他不会自称"丹修"**。四艺是他的活命手段，随时可学、可弃、可几样都会。

做成路线会带来三个副作用：身份锁死、系统翻倍、削弱自由（而这个游戏的灵魂就是高自由）。

### 1.2 正确的定位

```
境界（修到哪）─┐
道统（走哪条）─┼─ 都是"你是谁"
四艺（会什么）─┘  ← 这是"你会什么手艺"，不是"你是什么人"
```

规则：**不设职业、不设互斥，谁都能学，学几样都行**。唯一的限制是"会不会"和"精不精"，不是"能不能"。

### 1.3 现状：三个断点

| 断点 | 事实（实测） | 后果 |
|---|---|---|
| **没有制作** | 炼丹/炼器各出现 1 次（文案），制符 0、阵法 0 | 材料表、丹药表、法宝表都齐了，但连不起来 |
| **没有出口** | `SHOP` 由三表 concat 而成，全项目搜不到 `sell` | 做出来卖不掉 |
| **价格倒挂** | 材料中位 **660** > 丹药中位 **480** | 做一次亏一次 |
| **收入全被动** | 9 条灵石来源全是年俸/拾取/事件/打劫 | 没有"靠自己挣"的路 |

## 二、四艺怎么用

### 2.1 学：技艺书 + 九品

| 项 | 规则 |
|---|---|
| 入门 | 需要技艺书（《青囊丹经》之类），坊市有黄阶，宗门/家族有高阶 |
| 门槛 | 悟性 ≥8（炼丹/阵法）、神识 ≥8（制符）、资质 ≥8（炼器） |
| 学费 | 200~2,000 灵石（按品阶） |
| 耗时 | 学会 1 月 |
| 不限 | **四艺可全学**，没有互斥 |

### 2.2 练：九品 + 境界门槛

沿用《玄鉴》"功法分九品"：

| 品 | 熟练度 | 可做配方 | 境界门槛 |
|---|---|---|---|
| 一~三品 | 0~300 | 黄阶 | 练气 |
| 四~六品 | 300~1,200 | 玄阶 | 筑基 |
| 七~八品 | 1,200~3,000 | 地阶 | 紫府 |
| 九品 | 3,000+ | 天阶 | 金丹 |

> 境界门槛限制的是"能不能碰高阶材料"，不是"能不能学"。

### 2.3 用：三条价值线

| 艺 | 自用（省钱） | 外卖（赚钱） | 战斗（手段） |
|---|---|---|---|
| 炼丹 | 省下药钱（长期最大开支） | 中高，需求刚性 | 嗑药不占回合（高熟练度时） |
| 炼器 | 省下法宝钱（一次性大额） | 高，单笔最贵 | 法宝词条更强、可自修 |
| 制符 | 战斗爆发（越阶手段） | 中，周转最快 | 一次性大伤害/保命 |
| 阵法 | 洞府防御、聚灵 | 低（多为服务费） | 战场布置，改变胜负 |

**三条线同时成立**，所以四艺对任何玩家都有用：不爱做生意的自用（**省钱也是赚钱**）、想赚钱的外卖、爱打架的当手段。

### 2.4 料：四种来源

| 来源 | 成本 | 说明 |
|---|---|---|
| 采集 | 时间 + 风险 | 历练时采药/挖矿/猎兽（已有 `explore`） |
| 收购 | 灵石 | 坊市直接买 |
| 战利品 | 业力 | 杀人夺宝、妖兽掉落 |
| 自产 | 前期投入 | 洞府灵田、家族灵田 |

四条都要有，否则玩家会被"买不到材料"卡死。

### 2.5 时：占一个月（唯一的硬约束）

**每次制作占 1 个月**，与"打坐采气"互斥。

这条比任何数值平衡都关键：不占时间玩家会无限刷，经济立刻崩；占了时间，玩家就必须在"修炼"和"赚钱"之间做选择——**这才是修仙者真实的困境**。

## 三、四艺各自的流程

### 3.1 统一骨架

四艺共用一套流程，只在参数上不同：

```
① 选配方 → ② 备料 → ③ 操作（3 次判定）→ ④ 成器判定（品相）→ ⑤ 处置
```

**四要素**：材料（决定品相上限）、器具（基础成功率）、技艺（成功率与可做阶）、状态（灵力/神识/伤势）。

**品相五档**（四艺共用）：

| 品相 | 售价倍率 | 概率（一品） | 说明 |
|---|---|---|---|
| 废 | 0 | 15% | 材料全损，回收 20% 残料 |
| 下品 | ×0.7 | 35% | 能用，效果打折 |
| 中品 | ×1.0 | 35% | 标准 |
| 上品 | ×1.6 | 12% | 效果 +20% |
| 极品 | ×3.0 | 3% | 效果 +50%，额外词条 |
| **期望** | **0.877** | | |

### 3.2 炼丹 —— 一把梭

**核心：三次火候判定**，每轮三选一：

| 选择 | 成功率 | 品相 | 风险 |
|---|---|---|---|
| 文火慢炼 | +15% | ±0 | 多耗 1 月 |
| 武火猛攻 | −10% | **+1 档** | 炸炉概率 ×2 |
| 稳守中火 | ±0 | ±0 | 无 |

**炸炉**（失败且命中炸炉区间）：材料全损、气血 −20%、道心 −1（持续 3 月）、丹房损坏需修理。

**成丹数**：中品以上 1~2 枚；极品 1 枚 + 丹方心得（该丹永久 +1% 成功率）。

> 参考《我师兄》："第一炉就能走到成丹这一步，节省了自己准备的**其他八份材料**"——失败是常态。

### 3.3 炼器 —— 慢慢磨

**三阶段，可逆性递减**：

| 阶段 | 失败后果 |
|---|---|
| 器胚 | 材料损毁（回收 30%） |
| 刻阵 | **可重刻**（耗灵石，不毁器胚） |
| 淬炼 | 品相下降，但不归零 |

产出法宝带**词条**（减伤/遁速/灵力上限/克制某系），词条数由品相决定。

> 炼丹是"一把梭"，炼器是"慢慢磨"——两种手感，都要保留。

### 3.4 制符 —— 薄利多销

**三件套**：符纸（承载，消耗）+ 符墨（定属性，消耗）+ 符笔（决定品相上限，会磨损）。

一炉出 3 张，判定三次。**这是四艺里链条最短、周转最快的一条**。

| 符种 | 效果 | 用法 |
|---|---|---|
| 攻击符 | 一次性伤害（相当于免费大招） | 战斗「器」 |
| 防御符 | 抵挡一次攻击 | 战前 |
| 遁符 | 必逃 | 战斗「遁」 |
| 增益符 | 下三回合伤害 +30% | 战前 |

### 3.5 阵法 —— 资产而非消耗品

**阵盘 = 材料组合**（沿用《我师兄》设定）：

| 阵 | 所需材料 | 效果 |
|---|---|---|
| 聚灵阵 | 4 份同系灵材 | 洞府灵气 +1 档 |
| 迷踪阵 | 3 份幻属材料 + 1 阵旗 | 洞府不被窥探 |
| 五行轮杀阵 | 五行各 1 份（品质相同） | 洞府防御，可伤来犯者 |
| 锁灵阵 | 2 份禁锢类 + 阵盘 | 战斗中限制敌人遁走 |

布下后持续生效，但需**灵石维持**（每月扣），断了失效。接洞府/庙宇系统。

## 四、经济系统

### 4.1 目标循环

```
        ┌─────────────────────────────────────┐
        │                                     │
   灵石 ──▶ 材料 ──▶ 四艺（占1月）──▶ 成品 ──┤
        ▲                              │      │
        │                              ├─▶ 自用（省下的=赚的）
        │                              └─▶ 卖出 ──▶ 灵石（+20%）
        │                                     │
        └────────── 修为进度 ─────────────────┘
                （制作占月，修炼变慢 = 机会成本）
```

三个特征：**有正反馈**（净赚 20%）、**有机会成本**（占月）、**有两条出路**（自用或外卖）。

### 4.2 价格链（必须先改）

```
成品基准售价 = 材料成本 × 2.2
```

推导：品相期望 0.877 × 成功率 0.85 ≈ 0.745 → 1/0.745 ≈ 1.34 → 再留 25% 毛利与波动。

| 成品 | 材料成本 | 建议售价 | 现价 |
|---|---|---|---|
| 回春丹 | 80 | **180** | 50 |
| 生肌续骨丹 | 150 | **340** | 140 |
| 玉华灵水 | 300 | **660** | — |
| 火符（3 张/炉） | 50 | **110**/张 | — |
| 器胚·青叶舟 | 400 | **880** | 400 |

> 也可以反过来把材料价砍半，但那样"采药卖钱"就没意义了。倾向提成品价——同时给"采药"和"制作"两条活路。

### 4.3 五类收入

| 类型 | 具体 | 性质 | 量级（炼气期） |
|---|---|---|---|
| **手艺** | 卖丹药/符箓/法宝 | 主动，可复制 | 每月 100~400 |
| **采集** | 采药卖原料 | 主动，低门槛 | 每次 30~120 |
| **悬赏** | 宗门/坊市任务 | 半主动，需战力 | 每单 80~300 |
| **供奉** | 宗门年俸、家族月例 | 被动，看身份 | 每年 200~2,000 |
| **倒卖** | 低买高卖 | 主动，看行情 | 浮动 |

**目标**：让"手艺"成为炼气期主要现金流——这时战力低接不了悬赏，只能靠手艺。

### 4.4 四类支出（制造压力）

只有收入没有支出，钱会通胀。必须让玩家"永远缺钱"：

| 支出 | 频率 | 量级 | 说明 |
|---|---|---|---|
| 修炼消耗 | 每月 | 10~50 | 丹药、灵材（不嗑药修炼慢一半） |
| 洞府维持 | 每月 | 30~100 | 租金/禁制/聚灵阵 |
| 器具维修 | 每 6 月 | 100~500 | 丹炉裂、符笔秃、阵盘损 |
| 人情往来 | 事件 | 50~500 | 送礼、随礼、还人情 |

炼气期固定支出约 **90 灵石/月**，收入 100~400——**稍有闪失就入不敷出**，这正是修真的真实状态。

### 4.5 月度收支表（关键 UX）

每月结算时，在左栏「纪事」顶部加一块：

```
┌─ 本月收支 ─────────────────┐
│ 卖出 回春丹 ×3      +540   │
│ 购 补气草 ×4        −240   │
│ 洞府维持            −40    │
│ 修炼用丹            −50    │
├────────────────────────────┤
│ 净入 +210   余 1,340       │
└────────────────────────────┘
```

现在玩家不知道自己为什么穷。有了这张表，他会主动想"我该多炼点丹"——**经济就从数值变成了目标**。

### 4.6 四档变现渠道

| 渠道 | 收购价 | 门槛 | 代价 |
|---|---|---|---|
| 宗门收购 | 市价 ×70% | 需宗门身份 | 稳定、量大、可换贡献 |
| 坊市摆摊 | ×100% | 摊位费 | 每月限件数 |
| 拍卖会 | ×120~180% | 三年一次 | 抽成 10%，可能流拍 |
| 黑市 | ×140% | 无 | 业力 +，被盯上 |

> 《蛊真人》提醒过"拍卖并不盛行"——所以拍卖做成稀罕事，不做主渠道。

### 4.7 行情波动

每月 ±10%，事件放大：

| 事件 | 影响 |
|---|---|
| 大旱 | 药材 +40%、回春类 +30% |
| 妖潮 | 法器 +50%、符箓 +30% |
| 宗门大比 | 丹药/符箓 +25% |
| 战乱 | 战斗物资 +40% |

直接接上已有的 `EVENTS` 表——事件不只惩罚，还改变物价，玩家可"看天吃饭"。

## 五、宗门与家族联动

### 5.1 现成接口盘点

**不用新增系统，现有结构几乎是为它准备的**：

| 已有 | 位置 | 与四艺的关系 |
|---|---|---|
| 四殿：炼宝／炼丹／御兽／合欢 | `D.SECT.halls` | **炼宝殿=炼器、炼丹殿=炼丹** |
| 任务：采药／守炉／巡山／猎妖／镇守 | `D.SECT.tasks` | **采药=材料来源、守炉=炼丹练习** |
| 藏经阁三层 `wai/nei/zhen` | `D.SECT.ranks[].lvl` | 加一层"技艺"即可 |
| 祠堂 5 级（家祠→世家） | `D.CLAN.hallRanks` | 可扩成"技艺传承" |
| 族人产出 `stonePerPop: 0.35` | `D.CLAN.income` | 可改成产材料/做工 |
| **族规 `noTrade`：不得经商牟利** | `D.CLAN.rules` | ⚠️ **这条已经在管你卖东西了** |

### 5.2 宗门：学、料、卖、台阶

**① 学**：藏经阁加「技艺」页签，按身份解锁品阶（复用 `lvl` 分层，一行数据结构都不用加）。

**② 料**：任务从"只给贡献"改成"给贡献 + 材料"

| 任务 | 现在 | 改成 |
|---|---|---|
| 采药（30） | 只给贡献 | + 药材 ×3（约 180 灵石） |
| 守炉（60） | 只给贡献 | + 炼丹熟练度 +5 |
| 巡山（90） | 贡献+风险 | + 妖兽材料 |
| 猎妖（200） | 贡献+风险 | + 妖丹（炼丹主材） |
| 镇守（400） | 贡献+风险 | + 阵材 |

**③ 卖**：新增"交成品换贡献"

| 交付 | 贡献 |
|---|---|
| 3 枚回春丹 | 90 |
| 5 张火符 | 120 |
| 1 件玄阶法宝 | 600 |
| 1 座聚灵阵盘 | 400 |

**这条最关键**：给四艺一个稳定、无风险、不用摆摊的出口。不做生意的玩家做完直接交宗门换身份——**手艺变地位**。

**④ 台阶**：技艺等级进晋升条件

| 晋升 | 贡献 | 新增条件 |
|---|---|---|
| 内门弟子 | 2,000 | 任一技艺 ≥ 三品 |
| 真传 | 8,000 | 任一技艺 ≥ 五品 或 战力达标 |
| 长老 | 30,000 | 任一技艺 ≥ 七品 或 一峰之功 |

这改变"只有能打的才升得上去"的现状——宗门本来就需要炼丹师。

### 5.3 家族：传承、产能、销路、规矩

**① 传承**：祠堂 `gongfa` 品阶旁加"技艺传承"

| 祠堂 | 可传技艺 |
|---|---|
| 家祠 | 黄阶技艺书 |
| 族府 | 玄阶 |
| 宗祠 | 地阶 |
| 世家 | 天阶 + **祖传独门配方** |

**祖传配方是家族最独特的东西**：同一味丹，别人做中品，你家做能出上品（+1 品相）。花钱买不到。

**② 产能**：族人从"凭空产灵石"变成"做产业"

| 分配 | 产出 |
|---|---|
| 种药 | 每月 2~6 份药材 |
| 帮工 | 制作产量 +1、成功率 +5%（抽成 20%） |
| 跑商 | 灵石（略低于现在） |
| 修行 | 族运（长期投资） |

**③ 销路**：家族八折收货（不用出门），但抽成。

**④ 规矩**：族老立场影响经营

| 族老 | 对开作坊的态度 | 效果 |
|---|---|---|
| 守旧 | 反对（"与商贾为伍"） | 族运 −100，族人忠诚 + |
| 进取 | 支持扩张 | 产能 +20% |
| 贪利 | 支持但抽成 | 抽成 20%→35%，族运 + |

**⑤ 族运 → 作坊上限**

| 族运 | 可开作坊 |
|---|---|
| 100 | 1 间 |
| 400 | 2 间 |
| 1,200 | 3 间 |
| 3,600 | 5 间 |

### 5.4 双身份博弈

同时是家族子弟 + 宗门弟子，会有三类冲突：

| 冲突 | 场景 | 抉择 |
|---|---|---|
| 任务撞车 | 宗门派你守炉，家族要你祭祖 | 选一边，另一边掉好感/贡献 |
| 技术外流 | 宗门要祖传丹方，家族不外传 | 交=重赏+族运暴跌；不交=宗门疑你 |
| 生意之争 | 家族丹药与宗门自产竞争 | 帮谁都被另一边记恨 |

**两边都是**的收益是材料便宜 + 销路稳定，代价是**夹在中间，两边都防你**。

### 5.5 完整闭环

```
        ┌────────────── 家族 ──────────────┐
        │  灵田（种药）→ 药材               │
        │  作坊（帮工）→ 产量/成功率         │
        │  祠堂（传承）→ 技艺书/祖传方       │
        └───────────────┬──────────────────┘
                        │ 材料（抽成 20%）
                        ▼
        ┌───────────────────────────────────┐
        │           你（四艺：手段）          │
        └───────┬───────────────────┬───────┘
                │ 成品              │ 成品
                ▼                   ▼
        ┌───────────────┐   ┌───────────────┐
        │ 宗门（贡献）   │   │ 坊市（灵石）   │
        │ 70%，可换身份  │   │ 100%，受族规   │
        └───────┬───────┘   └───────┬───────┘
                └──── 灵石/地位 ──────┘
```

## 六、战斗逻辑优化

### 6.1 现状诊断

先肯定：战斗已相当完整——双栏、相克、法宝加成、神通装配、同源共鸣、符箓 `preBuff` 都有。

但有五个结构问题：

| # | 问题 | 证据 | 后果 |
|---|---|---|---|
| 1 | **10 个选项** | `renderCombat` 里 10 个 `optRow` | 手机上挤成一片，每次都要重读 |
| 2 | **"战前准备"在回合里** | 战斗中随时可点 | **"战前"概念不存在了**，等于无限补给 |
| 3 | 两个"施法"入口 | 选项 2「选招式」、3「本命」 | 玩家分不清 |
| 4 | **敌人只会打你** | `foeTurn` 只有扣血 | 没有对局感 |
| 5 | **阵法缺席** | 全项目 `阵法` 0 次 | 四艺只进来三样 |

另外两个小的：观察/防御/说话收益低（算过账就没人用）；没有回合压力（可以"防御→嗑药"无限拖）。

### 6.2 阶段化

```
① 遭遇 ──▶ ② 战前 ──▶ ③ 交手 ──▶ ④ 收尾
 情报      布阵/贴符    3~6 回合    追击/放走/搜身
 打/谈/走   换宝/嗑药
```

| 阶段 | 玩家做什么 | 关键 |
|---|---|---|
| ① 遭遇 | 看敌情，选 打/谈/走 | 给"不打"的选项，符合残酷修仙 |
| ② 战前 | 布阵、贴符、换法宝、嗑药 | **只能做一次，且只在这一段** |
| ③ 交手 | 每回合 6 个动作 | 四艺在此生效 |
| ④ 收尾 | 追杀/放走/搜身/疗伤 | "杀不杀"变成有分量的选择 |

### 6.3 选项 10 → 6

| 现 | 新 | 合并内容 |
|---|---|---|
| 1 攻击 | **攻** | 普通/全力 |
| 2 选招式 + 3 本命 | **术** | 统一入口 |
| 5 防御 + 法宝 | **御** | 防御/激发法宝 |
| 8 战前准备 + 9 用丹 | **器** | 符/阵/丹/宝二级菜单 |
| 6 遁走 | **遁** | 保留 |
| 7 观察 + 0 说话 | **谋** | 观察/交涉/虚张声势 |

六个刚好手机一屏两列三行。

### 6.4 四艺在战斗里

| 艺 | 位置 | 效果 | 消耗 |
|---|---|---|---|
| 符 | 「器」→ 贴符 | 一次性爆发/必中/减伤/遁 | 1 张 |
| 阵 | **仅②战前** | 限制敌遁/我方增伤/每回合削敌 | 阵盘耐久 |
| 器 | 「御」→ 激发 | 主动激发法宝特效 | 灵力 |
| 丹 | 「器」→ 嗑药 | 回血/回灵/临时加成 | 1 颗 |

**关键**：四艺在战斗里都是**消耗品**，不是技能。这让"会不会做"变成"舍不舍得用"——自己会制符的人敢甩三张，不会的人买来要省着用。

**这就是手段与身份的区别：不是能不能用，是用不用得起。**

### 6.5 胜算档统一

现在玩家看到 `R=0.42` 和"高你半境"，不知道哪个算数。合并成五档：

| 档 | 条件 | 表现 |
|---|---|---|
| 碾压 | 战力 ≥ 敌×3 且位格不低 | 一击定胜负 |
| 压制 | 战力 ≥ 敌×1.5 | 2~3 回合可胜 |
| 相持 | 0.8~1.5 | 看手段与运气 |
| 下风 | 0.4~0.8 | 能逃就逃 |
| 绝境 | <0.4 或位格低一大境 | 只能靠外物 |

并且在面板上写明**什么能改变这一档**：

```
胜算：下风（0.42）
  → 用「五雷符」可提到 相持
  → 布「锁灵阵」可断其遁走
```

**这一句提示就是"手段"存在的意义。**

### 6.6 敌人也要动

| 敌人类型 | 行为 |
|---|---|
| 莽夫 | 全力攻击，不防御 |
| 老练 | 血量 <30% 会防御/嗑药 |
| 滑头 | 血量 <50% 尝试遁走 |
| 邪修 | 用人质/毒/血祭 |
| 高阶 | 会用符/阵/法宝，跟你一样 |

### 6.7 回合压力

每 3 回合敌方气势 +1：

| 气势 | 效果 |
|---|---|
| 1 | 伤害 +10% |
| 2 | 伤害 +20%，我方遁速 −10 |
| 3 | 伤害 +35%，触发杀招 |

有了气势，"拖"本身变成风险，逼玩家在"稳"和"险"之间选。

### 6.8 一场战斗的样例

```
【遭遇】游方邪修 · 紫府·一关 · 战力 420
胜算：下风（R=0.23）→ 用五雷符可提到相持；布锁灵阵可断其遁走
[A 战] [B 谈] [C 走]

【战前】选 A：
  布锁灵阵（阵盘 −1 耐久）
  贴五雷符（−1 张，下回合必中+雷伤）
  嗑回灵丹（+40 灵力）

【交手】
回合1  你：术·惊雷引（-40，必中 ×1.75）→ 敌 400→330
       敌：普攻 → 你 100→85
回合2  你：器·贴符（雷伤 +120）→ 敌 330→210
       敌：气势1，攻击 → 你 85→68
回合3  你：术（灵力不足）→ 只能普攻 → 敌 210→180
       敌：想遁走，锁灵阵生效 → 失败
回合4  你：器·嗑药（回灵）→ 灵力 +40
       敌：气势2，攻击 → 你 68→46
回合5  你：术·惊雷引 → 敌 180→110
       敌：气势3，杀招 → 你 46→18
回合6  你：遁 → 成功脱离
【收尾】重伤逃脱，损失 200 灵石

→ 玩家感受："要不是那张符和那个阵，第三回合就死了。"
```

## 十、落地顺序

| 步 | 做什么 | 改动量 | 为什么 |
|---|---|---|---|
| **1** | 坊市卖出 + 价格链重标 | 小 | 不改玩法，先让现有东西能变现 |
| **2** | 宗门任务产材料 + 交成品换贡献 | 小 | 四艺有了学/料/卖三条通路 |
| **3** | 战斗选项合并 10→6 + 胜算档 | 小 | 纯 UI，手感提升最明显 |
| **4** | 制符 + 符进战斗 | 中 | 链条最短，战斗里立刻有用 |
| **5** | 炼丹 + 月度收支表 | 中 | 补经济发动机 |
| **6** | 战斗阶段化 | 大 | 改状态机 |
| **7** | 阵法 + 敌人行为 | 大 | 依赖阶段化 |
| **8** | 家族产业 + 族老立场 | 中 | 让家族从提款机变产业 |
| **9** | 炼器 | 中 | 依赖法宝栏 |

**第 1 步是验证点**：卖东西能让炼气期活下去，后面才有意义；卖完还是穷，说明该调支出端而不是加系统。

## 十一、几条"不做"的原则

1. **不做职业**——没有丹修/器修，只有"会炼丹的人"。
2. **不做互斥**——四艺可以全学，约束是时间不是门槛。
3. **不把"战前准备"留在回合内**——它必须是真的战前。
4. **不让制作免费**——占月是唯一但最有效的平衡手段。
5. **不要修掉 `族规 noTrade`**——它与赚钱的冲突是设计，不是 bug。
