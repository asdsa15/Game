> 配套检查：`tools/check_time.py`

---

## 一、一条规则

> **需要投入身体、时间、心力去做的事，占一旬。
> 只是「决定」「挑选」「查看」的事，不占时间。**

这条规则的作用不是限制玩家，是让每一件事都有价格。
价格一出现，取舍才出现——而取舍是策略的最小单位。

## 三、新加动作时怎么判

问三个问题，按顺序：

1. **它产出什么？**（修为／材料／好感／贡献／情报）
   → 有产出 → 占旬
2. **它是不是另一个动作的中间步骤？**
   → 是 → 免费（否则一次行动收两次费）
3. **它有没有别的成本？**（每月次数上限、冷却、稀有资源）
   → 有 → 可以免费

答不上来，就**默认占旬**。宁可多收，不可漏收——漏收等于又开了一个免费外挂。

## 四、自动守卫

`tools/check_time.py` 会扫全部 `ACT` 方法：

- 有 `advanceXun()` / `advanceMonth()` → 通过
- 没有，但在这个文档的分档表里 → 通过
- 都没有 → **报错**，提示「新增动作未分类」

跑法：

```bash
python tools/check_time.py
```

它读的是本文档里的动作名——所以**加动作时，要么让代码占旬，要么把它写进上面两张表**。
两个都不做，检查就会红。

## 五、还没做的

1. **固定开销**。现在做事有成本，但不做事没有惩罚。下一轮要做
   宗门月课、家族口粮、庙宇香火——让「闲」也要付钱。
2. **旬的叙事**。现在旬只是计量单位。真正的旬该有自己的事：
   上旬的集市、中旬的讲经、下旬的庙会。
3. **`XUN_PER_MONTH` 的手感**。一个月三件事，系统不少，可能偏紧。
   改成 6 只需要动这一个常量，修为会自动按 `/6` 折算，全月打坐的量不变。
