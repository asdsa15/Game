## 一、先说结论

你这个判断是对的——**现在这游戏"能玩"，但"没味道"**。

我扫了一遍代码，问题比"对话少"更具体：

| 项 | 实测 | 问题 |
|---|---|---|
| 开场文本 `SCRIPTS` | **126 字**（5 个开场，每个约 25 字） | 开局一句话就进创角 |
| 随机事件 `EVENTS` | **46 字**（只有事件名，**没有描述**） | 事件发生只有"信众 +20" |
| 奇遇 `ENCOUNTERS` | 745 字（12 个，平均 60 字） | 尚可，但偏短 |
| NPC `NPC_POOL` | 331 字（有外貌/性情，**没有台词**） | 见下 |
| 场景 `scene()` | **固定 8 句**（四季各 1 + 神道 2 + 洞天 1） | **一年到头就这 4 句** |
| 仪式 `RITUALS` | 73 字 | 仪式本该是文本重头 |

最刺眼的是 NPC：

```js
// do_ia：论道／送礼／邀约 三个选项，点完就这一句
logLine(`与${n.name}相处，好感 +${d}`, '');
```

**你和顾清玄"论道"了一整个月，游戏只告诉你"好感 +4"。一句台词都没有。**

而数据里明明已经有 `look`（温润剑修，青衫缓带）、`inner`（守正到几近固执）、`likes`、`taboo`——**素材都在，就是没有把它说出来**。

## 二、两本书分别能给什么

### 2.1 玄鉴：给"叙述腔"

《玄鉴仙族》593 万字，它的文本特色不是诗词，而是**用白话写古意**：

- 四字短语密集："立祠堂，开族府，读书出仕，习武将兵"
- 家常话里带沧桑："李家耕荒两百多年了，娘移不得爹动不得"
- 术语古朴且成体系：玄景灵誓、仙基、神通、嫡系、旁支、族老

**它最值得学的是"把制度写成人话"**。比如族规不是规则条文，而是一句"违誓者玄景破碎，一身修为如同流水一般倾泻而出"。

### 2.2 蛊真人：给"可读的典籍"

《蛊真人》里有一部贯穿全书的《人祖传》，原文对它的描述是：

> "《人祖传》是蛊道第一经典。**初读起来是故事，其实寓意深刻**，更记载着上古秘闻，里头有各种各样的蛊。有些蛊，直接描述……而有些蛊，则含蓄地点出来，描写得很隐晦。**需要读者深入地挖掘和细细地研究**。"

**这一段话就是最好的"游戏内典籍"设计说明。**

它给的不是"读一遍加属性"，而是：**同一本书，不同境界读出不同东西**。

### 2.3 怎么分工

| 用在哪 | 学谁 | 为什么 |
|---|---|---|
| 家族/宗门/日常 | 玄鉴 | 它写的就是家族里过日子 |
| 秘境/道书/抉择 | 蛊真人 | 它写的是"世界很冷，你得想清楚" |
| 神道/民俗/庙规 | 俗主 | "河神不吃昨年祭"这种规矩感 |
| 道门/符箓 | 白骨大圣 | "一纸黄符天师受箓" |

## 三、要补的六个文本模块

### 3.1 NPC 台词（最缺，优先级最高）

**现状**：0 句台词。`do_ia` 只加好感数字。

**目标**：每个 NPC 至少 15 句台词，按**好感阶段**与**情境**组织。

#### 三层结构

```
① 初见     — 一段 3~5 句的相遇文本（用现成的 look + inner 扩写）
② 阶段台词 — 好感 0/20/40/70/100 各有 2~3 句
③ 情境台词 — 受伤 / 你突破 / 分别 / 生辰 / 并肩作战
```

#### 样例（顾清玄，剑修）

**初见**

> 他站在演武场边，青衫被风掀起来一角。你走近时，他没有回头，只把剑往鞘里送了半寸。
> "你的气不稳。"他说，"急着筑基的人，多半死在筑基前一夜。"

**阶段台词**

| 好感 | 台词 |
|---|---|
| 0~20（陌生） | "道友。"——他点头，目光已经回到剑上。 |
| 20~40（点头） | "你这口气，比我上回见时纯了些。" |
| 40~70（相熟） | "我这一式练了七年。你若有兴趣，我拆开给你看。" |
| 70~100（知己） | "若有一日我剑断了，你替我把这半截埋在青云峰上。" |

**情境台词**

> 【你突破时】他站在门外，没进来，只说了句"恭喜"，把一壶酒放在门槛上就走了。
> 【你受伤时】"谁伤的？"他问得很平，手已经按在剑上。

#### 论道要有内容

现在"论道"是空转。改成**真的一问一答**：

```
顾清玄："你说，剑是快的好，还是稳的好？"
[A] "快。慢了就来不及。"        → 他摇头："来不及的，本就不该出手。"
[B] "稳。稳到最后才出手。"      → 他看了你一眼："这话，像我师父说的。"
[C] "看你怕什么。"              → 他愣住，很久才笑："……这倒没想过。"
```

**三个选项没有"正确答案"**，但会影响他对你的看法（好感 +2 / +5 / +8，且后续台词不同）。

**这才是"对话"**——不是加数值，是**让玩家觉得对面有个人**。

### 3.2 场景描写（`scene()` 从 8 句扩到 200+）

**现状**：一年只有 4 句（春夏秋冬各一）。玩家每月看到的都是"春。后山灵气略活"。

**改法**：按 **地点 × 季节 × 状态** 组合：

| 维度 | 取值 | 条数 |
|---|---|---|
| 地点 | 洞府 / 坊市 / 山野 / 宗门 / 庙宇 / 洞天 | 6 |
| 季节 | 春夏秋冬 | 4 |
| 状态 | 常 / 受伤 / 闭关出关 / 有人来访 | 4 |

6×4×4 = 96 条，够用一年不重复。再加 20 条特殊（突破后、仇家上门前、大旱、妖潮）。

**样例（洞府 · 冬 · 常）**

> 霜封了洞口。你吐纳时呼出的气在半空凝成白雾，久久不散。柴烧完了，你懒得去砍——反正修士不怕冷，只是有点寂寞。

**样例（宗门 · 秋 · 有人来访）**

> 丹房的炉火刚熄，门外有人咳嗽了一声。是隔壁峰的师兄，手里拎着两尾灵鱼，说"顺路"。

### 3.3 道书典籍（《人祖传》模式，最出彩）

这是我最想推荐的一块。设计如下：

**一部道书可反复读，每次读出的不同。**

| 读第几次 | 需要 | 得到 |
|---|---|---|
| 第 1 次 | 无 | **故事**（阅历 +1，无实质收益） |
| 第 2 次 | 悟性 ≥10 | **技法**（解锁一个配方/招式） |
| 第 3 次 | 悟性 ≥14 或道心 ≥15 | **秘闻**（地图线索、某段因果） |
| 第 4 次 | 特定境界 | **真意**（永久 +2% 相关加成） |

**样例（《玄景残卷》）**

> **第一读**：讲一个少年在雪地里追一只白鹿，追了三年，最后发现鹿是他自己的影子。——你不明所以，只觉得心里空了一下。
>
> **第二读**（悟性 ≥10）：你忽然注意到，故事里少年每次歇脚的地方，都有一株同样的草。你照着找了，那是**补气草**。——解锁：补气草采集点。
>
> **第三读**（悟性 ≥14）：那句"鹿是他自己的影子"，原来说的不是鹿。你想起《玄景灵誓》里"誓由心动"四个字。——悟得：道心 +2。
>
> **第四读**（筑基）：你终于看懂最后一页的批注——那是另一个人的字，写着"我追到了"。——线索：某处洞府。

**为什么这个设计好**：它把"悟性"这个属性变成了玩家能感知的东西。现在悟性只是个数，读了书才知道"哦，我悟性不够，读不出第二层"。

### 3.4 诗词歌诀（用于境界、功法、地名）

不用多，**用在刀刃上**：

| 用在哪 | 数量 | 样例（改写） |
|---|---|---|
| 突破成功 | 6 句（每境一句） | 「一朝雷动九霄开，此身原在玉京台」 |
| 功法残页题诗 | 20 句 | 「剑在匣中鸣三十年，无人知是血磨成」 |
| 地名题咏 | 12 句 | 「青岳不言，雪落其上，千年如一日」 |
| 结局 | 8 句 | 「问道者不问归途」 |

**风格参照**：玄鉴的"今日暂且展翼去，明朝登仙笞凤凰"——**要有仙气，但不能酸**。半文半白、对仗即可，不用严格格律。

### 3.5 事件叙事（`EVENTS` 从 46 字扩到 800+）

**现状**：事件只有名字，发生时直接给数值。

```js
{ id: 'drought', name: '大旱', kind: 'risk' },   // 就这些
```

**改成**：

```js
{ id: 'drought', name: '大旱', kind: 'risk',
  text: '三个月没下雨。田里的裂口能塞进一个拳头。有人跪在庙门外，从早上跪到日头偏西，一句话也不说。',
  after: '你看着他们走，忽然想起自己也曾这样求过谁。',
  log: '大旱。求雨的人挤满了庙门。' }
```

**每个事件 2~3 句**，12 个事件约 800~1,000 字。

**这一改的收益**：玩家不再是"收到一个 -25% 的惩罚"，而是"看见一群人跪在门外"。

### 3.6 结局文本（每个 3~5 句）

现在 `ENDINGS` 表有 12 个结局，但可能只有标题。

**样例（坐化）**

> 你在蒲团上坐了很久。久到山下的村子换了三代人，久到没人再记得这座洞府住过谁。
> 最后那口气散的时候，你其实还想再看一眼春天。
> ——道号清微，享年四百二十岁，无弟子，无道侣。

## 六、字数预算

| 模块 | 现在 | 目标 | 增量 |
|---|---|---|---|
| NPC 台词 | 0 | 8 个 NPC × 15 句 ≈ 6,000 字 | +6,000 |
| 场景描写 | 8 句 ≈ 300 字 | 116 条 ≈ 8,000 字 | +7,700 |
| 道书典籍 | 0 | 6 部 × 4 层 ≈ 5,000 字 | +5,000 |
| 诗词歌诀 | 0 | 46 句 ≈ 1,500 字 | +1,500 |
| 事件叙事 | 46 字 | 12 事件 ≈ 1,200 字 | +1,150 |
| 结局文本 | 少量 | 12 结局 ≈ 1,500 字 | +1,500 |
| 开场 | 126 字 | 5 个 × 300 字 ≈ 1,500 字 | +1,400 |
| **合计** | **约 500 字** | **约 25,000 字** | **+24,500** |

**25,000 字是什么概念**：约等于一部中篇小说的三分之一，但它是**分散在几百个触发点里的碎片**——写起来比写小说容易，因为每段都短。

## 七、落地顺序

| 步 | 做什么 | 工作量 | 为什么先做 |
|---|---|---|---|
| **1** | **NPC 台词**（先做 2 个 NPC 完整版） | 1 天 | 玩家最容易感到"这游戏活了" |
| **2** | **场景描写**（96 条组合） | 1~2 天 | 每月都看到，复利最高 |
| **3** | **事件叙事**（12 个补描述） | 半天 | 成本最低，收益立现 |
| **4** | **道书典籍**（先做 1 部完整 4 层） | 1 天 | 验证"多读多得"这个机制好不好玩 |
| **5** | 诗词歌诀（按需插） | 半天 | 增味 |
| **6** | 结局文本 | 半天 | 通关时才有用，可后置 |

**第 1 步只做 2 个 NPC**，不要一次写 8 个——先看玩家对"论道有一问一答"的反应，再决定要不要铺开。

## 八、一句话总结

现在这游戏像一本**写得不错的规则书**：数值清楚、系统完整、逻辑自洽。

但它还不是一个**世界**。

世界是靠这些撑起来的：

> 顾清玄站在门外没进来，只说了句"恭喜"，把一壶酒放在门槛上就走了。

**这一句的信息量，比"好感 +6"多一百倍。**
