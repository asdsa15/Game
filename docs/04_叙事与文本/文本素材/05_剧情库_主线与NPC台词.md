# 剧情素材库 · 主线剧情与 NPC 台词（古言重订版）

> 主线供 `mainlineFor` / 境界推进事件取用；台词供 `NPC_POOL` 扩充取用。
> **风格约束（重订）**：主线叙事用文言短章；NPC 对白用半文言——话是人说的话，但字字收敛，无现代词，无破折号。
> NPC 结构对齐既有字段：`look` / `inner` / `likes` / `taboo` / `meet` / `stages` / `ctx` / `ask`。
> 论道之则：**三选项无正解**，各见其人，各结其缘。

## 第一部分 · 主线剧情（仙道五幕）

### 第一幕 · 入世（胎息 → 练气）

**题旨：自"能修"至"在修"。**

- 引子：得第一枚灵石之日，石在手心是凉的；纳入袖中，袖口是暖的。修行，自这一凉一暖始。
- 事一 **初入坊市**：以灵石易物，摊主找零二枚碎石。知不足，未敢言。散修第一课，咽下去。
- 事二 **六轮初成**：玄景轮成之夜，八十一缕灵气数了三遍。非不放心，舍不得睡。
- 事三 **练气一层**：初采气成。闻自己呼吸，压过风声。风，不与计较。
- 幕终之择：
  - [甲] 入宗门：换一个名分，从此柴米有人管。
  - [乙] 为散修：守自己的柴米，从此柴米管你。

### 第二幕 · 立基（筑基 · 道途四印）

**题旨：以"想修行"为"修行"。**

- 冲突：六轮兵解，以旧我铸新我。而旧我，未必肯。
- 事一 **兵解之夜**：六轮散时，闻每一轮碎裂之音高皆不同。最高那一声，是十九岁那年的心跳。
- 事二 **四印之路**：印不在秘境，在事中——修桥者得桥印，守夜者得灯印，偿债者得信印，赴死者得渡印。（暗线：桥印详《九寰天书》四读）
- 事三 **仙基落成**：基成之刻，无异象。俯视其手，仍是那双手。只是，再不会抖了。
- 幕终之择：
  - [甲] 天基执念：赌那"位"之雏形。代价：此后，输不得。
  - [乙] 玄基安稳：修行即过日子，过日子即修行。

### 第三幕 · 问心（紫府三关）

**题旨：三关非三堵墙，乃三问。**

- 事一 **升阳关**：基入升阳，见自己初杀生之日。看清，是入门券。
- 事二 **蒙昧关**：破关之夜，关外有人呼我名。声是我声。不应——应则困于关中。
- 事三 **幻想关**：渡无尽幻想。最长一场是"当年若未修行"。在其中活完一世，自己走出来——门，没有锁。
- 幕终之转：紫府圆满之日，于藏经阁顶层得无名书一册。开卷皆空白；以神识视之，字迹浮现——是我手笔。笔迹，是十年后的。

### 第四幕 · 果位（金丹 · 三十位）

**题旨：位非天授，乃人所让。**

- 事一 **金性煅成**：煅金七日。第七日，炉膛内一声轻"成了"。非我言，非炉言，丹自言。
- 事二 **法仪七日**：设法仪引果位，仪不可断。第七日暴雨，护道人以身蔽香案之半。
- 事三 **三十取一**：三十位，各有其主过。我登彼位，座犹温——前一位主人，三日之前，方才陨落。
- 幕终之择：
  - [甲] 居位守序：自此为"体制"之一环，管天下人求不求得着。
  - [乙] 让位出走：让位于身后候补之人。修为散三成，路宽三倍。

### 第五幕 · 长生（道胎 · 锚定）

**题旨：以己心代天心之后，长生非不死，乃被记。**

- 事一 **道胎落成**：以己心代天心之刻，重写"我"字。笔画未变，读音变了。
- 事二 **四锚之立**：物、人、事、仪四锚，缺一则散。物者，我所留；人者，我所教；事者，我所结之善缘；仪者，我所守之规矩。
- 事三 **百世之问**：上古十境之线索，指一处无名之地。行前，先修好洞府的窗。非为自居。
- 终章（接 `ENDINGS`）：坐化、登仙、逍遥、道化，四途皆通。判定不改，文本各备一版（见诗词库结局篇）。

### 神道线简纲（八柱）

- 一柱立庙："首炷香，出自一个不信的人。"——立庙先立门槛，不立神通。
- 二柱聚香："香火是称过的债。"——愿大愿小，肩上称。
- 三柱显灵："首度显圣，择一个最小的愿应之。"——神通是信用，非火力。
- 五柱开府："阴司之籍发下之日，头一件公务，是邻村走失的一条狗。"
- 八柱真君："真君非官。是这一方水土应允你：你守它，它认你。"
- 全线暗键 **祀部**：朝廷管神，神管人，人管香火。谁最后管谁都可，莫管到庙里来。

## 第二部分 · NPC 台词（五人）

### NPC 一 · 沈青蘅（丹殿执事）

```js
{ id:'shen_qh', name:'沈青蘅', gender:'女', role:'丹殿执事', age:126,
  look:'素袍袖口，尽是旧药渍。指甲缝里，常年一点朱砂红',
  likes:['火候稳者','不催丹者','新茶'], taboo:'催丹，添火',
  inner:'所废之丹，多于所成之丹。她记得每一炉废丹的价钱，故不许人浪费她的火',
  realm:3 }
```

**初见（meet）**

1. 丹房内，其人未回头："炉在右，炭在左。立定，勿动——火候不可分心。"
2. "彼三炉，休碰。皆有名字，资历比你老。"
3. 递药与彼，逐一翻检，拈出两根："晒的时候心不在，药性便心不在。"

**阶段（stages）**

| 好感 | 台词 |
|---|---|
| 0~20 | "论道请往他处。丹房，只谈丹。" |
| 20~40 | "此月所废之丹，数目报我。非罚你——欲知你废于何处。" |
| 40~70 | "新茶带了么。带了便坐。炉尚有半个时辰，此半个时辰，教你观火。" |
| 70~100 | "此炉若成，分你一枚。莫谢我——谢你上月替我守的那一夜火。" |

**情境（ctx）**

- 【你破境】自丹房探头："破境后三日，忌大荤，忌大喜。大喜，也莫入丹房——火候会分心。"
- 【你受伤】"伤药在我处。胜坊市之药，亦贵于坊市——记账上。"
- 【你赠茶】"搁炉边。茶要温火，人要长情。"（未抬头。然闻得她笑了一声）
- 【炼丹失败】"废丹莫弃。碎的是学费，未碎的是路费。"

**论道（ask）**

> q：「一炉丹，火候九分，欠一分。等，抑或不等？」

- [甲]「等。丹如种，急不得。」→ 颔首："答对了。九分之丹，候一日则圆满，催一时则炉渣。"（fav +6）
- [乙]「不等。九分亦成丹。」→ "务实。"收丹，"成丹归你，名莫挂我丹房。"（fav +2）
- [丙]「看此丹欲付何人。」→ 其人平生初次正眼视我："……你悟得比炉快。"（fav +8。后续钩：托我一炉"予故人之丹"）

- [丙]「传之先，教人收刀。」→ 愣良久："……我师，未教过此手。"（fav +8。后续：果自琢磨出一式收刀，名曰「回头」）

## 第三部分 · 恩义钩子剧情（对接 `HOOKS`）

> 明钩，欠者必偿；暗钩，受者必认。每钩带"期"与"不偿之果"。

1. **一饭之恩**（明钩 · 三年）
   他人予我一碗粥。三年之内当偿——偿的不止粥，是"彼落难那年，我路过其门"。
   不偿之果：debuff【欠食】。打坐偶得，其机渐稀。

2. **半页经**（暗钩 · 无期）
   传法之时，彼只授半页。暗记：余下半页，须待"用着的那一日"忆起。
   触发：某场死战，忽然忆起那半页。而彼，已不在了。

3. **代守门者**（暗钩 · 因果）
   曾推"残符石门"者（奇遇其一）。三年后守门事至：一新人将推门，我恰过其侧。
   择：[甲] 代之推（承因果）／ [乙] 拦之（结善缘）／ [丙] 过而不管（业力 +3）。

4. **断剑旧主**（明钩 · 五年）
   曾收断剑者（奇遇其二）。五年后，旧主之后人来寻。不索剑，索"一个交代"。

5. **井底手温**（暗钩 · 永续）
   "井中月"择[甲]者。此钩无期。然每逢月圆，井水诸事，辄偏向于我。

6. **双向人情账**（明钩 · 立结）
   "官道截杀"择[丙]者。两头各开一账。任何一笔被讨还，另一笔同时结清——双向人情账之最小闭环。

7. **前世一命**（暗钩 · 跨世 · 新增）
   《渡厄三则》四读者。页尾一行："读至此者，前世曾救我一命。"
   此钩不落今世。百世书翻页之后，某一世的某一日，有一个陌生人，无声替我挡了一件事。
