# 剧情素材库 · 主线剧情与 NPC 台词

> 主线供 `mainlineFor` / 境界推进事件取用；NPC 台词供 `NPC_POOL` 扩展取用。
> NPC 结构完全对齐现有字段：`look` / `inner` / `likes` / `taboo` / `meet` / `stages`（好感阶段）/ `ctx`（情境）/ `ask`（论道一问一答）。
> 论道原则：**三个选项没有"正确答案"**，但影响好感与后续台词。

## 第一部分 · 主线剧情（仙道五幕）

### 幕一 · 入世（胎息 → 练气）

**主题：从"能修"到"在修"。**

- 开篇钩子：你拿到第一枚灵石时，它在你手心是凉的；放进袖子，袖口是暖的。修行从这一暖一凉开始。
- 推进事件：
  1. **初入坊市**：第一次用灵石换东西，摊主找你两枚碎的，你没敢说不够——散修的第一课是咽下去。
  2. **六轮初成**：玄景轮成的那夜，你把八十一缕灵气数了三遍。不是不放心，是舍不得睡。
  3. **练气一层**：第一次采气成功，你听见自己的呼吸压过了风声。风没意见。
- 幕终抉择（A/B 分支）：
  - A：加入宗门，换一个"名分"，从此有人管你的柴米。
  - B：做散修，守着自己的柴米，从此柴米管你。

### 幕二 · 立基（筑基 · 道途四印）

**主题：把"想修行"变成"修行"。**

- 核心冲突：六轮兵解是拿过去的自己换未来的自己——但过去的自己不一定愿意。
- 推进事件：
  1. **兵解之夜**：六轮散时，你听见每一轮碎裂的音高都不同。最高的那一声，是你十九岁那年的心跳。
  2. **四印之路**：印不在秘境里，在事情里——（对接道书素材「印·桥」暗线：修桥者得桥印，守夜者得灯印，偿债者得信印，赴死者得渡印）。
  3. **仙基落成**：仙基成的那一刻没有异象。你低头看了看手，还是那双手，只是再也不会抖了。
- 幕终抉择：
  - A：天基执念——去赌那个"位"的雏形，代价是从此不能输。
  - B：玄基安稳——从此修行是过日子，过日子也是修行。

### 幕三 · 问心（紫府三关）

**主题：紫府三关不是三道墙，是三次自问。**

- 推进事件：
  1. **升阳关**：仙基入升阳时，你看见自己第一次杀生的那天。看清楚，是过关的门票。
  2. **蒙昧关**：破蒙昧那夜，有人在外面喊你的名字。声音是你自己的。你没应——应了就困在关里。
  3. **幻想关**：渡无尽幻想，最长的一场幻想是"如果你当年没修行"。你在里面活完了，然后自己走出来——门没锁。
- 幕终转折：紫府圆满那日，你在藏经阁顶层发现一本没有名字的书，翻开全是空白——直到你用神识去看，才浮出自己的字迹。**是你写的，笔迹是十年后的。**

### 幕四 · 果位（金丹 · 三十位）

**主题：位不是天给的，是人让出来的。**

- 推进事件：
  1. **金性煅成**：煅金那炉用了七日，第七日炉膛里传来一声很轻的"成了"。不是你说，也不是炉说——是丹说的。
  2. **法仪七日**：设法仪引来果位，法仪不可断。第七日下暴雨，护道人用身子替你挡了半边香案。
  3. **三十取一**：三十个位，都有人坐过。你坐上去那个位，位是温的——上一个坐它的人，三天前刚刚陨落。
- 幕终抉择：
  - A：坐位守序——从此你是"体制"的一部分，管的是别人求不求得着。
  - B：让位出走——把位让给排在身后的那个人。修为散三成，路宽了三倍。

### 幕五 · 长生（道胎 · 锚定）

**主题：以己心代天心之后，长生不是不死，是被记住。**

- 推进事件：
  1. **道胎落成**：以己心代天心那刻，你把"我"字重写了一遍——笔画没变，读音变了。
  2. **锚之四物**：物·人·事·仪四锚，缺一即散。物是你留下的东西，人是你教过的人，事是你结过的善缘，仪是你守过的规矩。
  3. **百世之问**：上古十境的线索指向一处无名之地。去之前，你把洞府的窗修好了——不是为你。
- 终章（对接 `ENDINGS`）：
  - 坐化 / 登仙 / 逍遥 / 道化，四途皆通，判定不改，文本各备一版（见诗词库·结局备选诗）。

### 神道线简纲（八柱）

- 一柱立庙："第一炷香来自一个不信的人。" ——立庙先立门槛，不立神通。
- 三柱显灵："第一次显圣，挑一个最小的愿望应验。" ——神通是信用，不是火力。
- 五柱开府："阴司的编制发下来那天，你发现自己管的第一件公事是隔壁村的狗丢了。"
- 八柱真君："真君不是官，是这一方水土答应你：你守它，它认你。"
- 全线暗键：**祀部**——朝廷管神，神管人，人管香火。谁最后管谁都行，别管到庙里来。

## 第二部分 · NPC 台词（完整 4 人）

### NPC 一 · 沈青蘅（丹修 · 炼丹殿）

```js
{ id:'shen_qh', name:'沈青蘅', gender:'女', role:'丹殿执事', age:126,
  look:'素色道袍袖口全是旧药渍，指甲缝里常年一点朱砂红',
  likes:['火候稳的人','不催丹的人','新茶'], taboo:'催丹与添火',
  inner:'炼废的丹比炼成的多。她记得每一炉废丹的价钱，所以从不许人浪费她的火',
  realm:3 }
```

**初见（meet）**

1. 丹房里她头也不回："炉子在右边，炭在左边，站着别动——火候不能分心。"
2. "别碰那三只炉。它们有名字，比你资历老。"
3. 她把你递来的药材翻了一遍，挑出两根："晒的时候心不在，药性就心不在。"

**阶段台词（stages）**

| 好感 | 台词 |
|---|---|
| 0~20 | "论道去别处。丹房只谈丹。" |
| 20~40 | "你这月废的丹，数目报我。不是罚你——是要知道你废在哪一步。" |
| 40~70 | "新茶带了吗？……带了就坐下。炉还有半个时辰，这半个时辰，我教你看火。" |
| 70~100 | "我这一炉成了，分你一枚。别谢我——谢你上个月替我守了一夜火。" |

**情境台词（ctx）**

- 【你突破时】她从丹房探出头来："突破后三日忌大荤忌大喜。……大喜也别来丹房，火会分心。"
- 【你受伤时】"伤药在我这，比坊市的好，比坊市的贵——记账上。"
- 【你送新茶】"放炉边。茶要温火，人要长情。"（她没抬头，但你听见她笑了一下）
- 【炼丹失败时】"废丹别扔。碎的那部分是学费，没碎的那部分是路费。"

**论道（ask）**

> q：「一炉丹，火候到了九分，还差一分，等还是不等？」

- A「等。丹如种，急不得。」→ 她点头："答对了。九分的丹，等一天是圆满，催一时是炉渣。"（fav +6）
- B「不等。九分也是成丹。」→ "实用。"她把丹收了，"成丹归你，名声别挂我丹房。"（fav +2）
- C「看这一炉丹要给谁。」→ 她第一次正眼看你："……你悟得比炉快。"（fav +8，解锁后续：她托你炼一炉"给某个故人的丹"）

### NPC 二 · 裴照（魔门叛出的刀修）

```js
{ id:'pei_zhao', name:'裴照', gender:'男', role:'叛刀客', age:88,
  look:'左眉一道旧疤到鬓角，刀鞘缠布，布换过很多次，刀没换过',
  likes:['痛快话','不问来路的人','脆枣'], taboo:'提"师门"两个字',
  inner:'魔门教他刀，没教他回头。回头是他在人间市集看杀猪时学会的——猪都知道挣一下',
  realm:4 }
```

**初见（meet）**

1. 官道旁的破亭里，他磨刀不看人："坐可以，说话不行。刀听声。"
2. "你身上有宗门的香火气。……不是骂你。就是闻得出来。"
3. 他把脆枣核吐进路沟："修行的人吃枣吐核吗？"他自己先答，"我吐。"

**阶段台词（stages）**

| 好感 | 台词 |
|---|---|
| 0~20 | "让路。"（两个字，用完了本月的客气） |
| 20~40 | "你的剑比人慢半拍。改不改？不改也行，死的时候快些。" |
| 40~70 | "我这刀上三条人命，都是该杀的——该不该，我判的。你要觉得我判错了，来讨。" |
| 70~100 | "哪天我死在刀下，把我埋在杀猪巷口。我要听着那声儿走。" |

**情境台词（ctx）**

- 【你突破时】他把一枚碎枣核弹进你洞府："贺礼。没毒。就是枣核。"
- 【你受伤时】"谁的刀？"他问完没等你答，已经起身了。
- 【并肩作战时】"你左我右。别学我抢中路——我抢惯了，你抢了要挨骂。"
- 【你送脆枣】他吃得很慢，吐核很响："……下回，多带一捧。"

**论道（ask）**

> q：「魔门的刀法，一刀一命。这刀该不该传？」

- A「该传。刀无罪。」→ "刀无罪，刀客有。"他收刀，"但传出去的每一刀，都算我教唆。……传吧，挑个心硬的。"（fav +6）
- B「不该传。一命换一命，太贵。」→ "贵？你宗门的丹，哪一炉不是命换的？"（fav +1）
- C「传之前，先教会收刀。」→ 他愣了很久："……我师父没教过这手。"（fav +8，解锁后续：他真琢磨出一式"收刀"，取名「回头」）

### NPC 三 · 老庙祝（神道线 · 村土地庙）

```js
{ id:'lao_mz', name:'佚名', role:'村土地庙庙祝', age:71,
  look:'洗得发白的青布袍，袖口磨出了毛边，腰间挂一串旧钥匙',
  likes:['香灰干净','孩子','修好的门槛'], taboo:'问他为什么信',
  inner:'他不是信神，他是信"有人管"——庙里有神，村里有主，人就不慌',
  realm:1 }
```

**初见（meet）**

1. 他正在扫庙前的雪，扫帚很旧："进来吧，踩过的雪扫不净，踩踏点。"
2. "香自己上。神不挑香，挑的是手干净。"
3. "求什么？……哦，你修仙的。仙不用求我，我倒要求仙——别把庙前这条路修飞了。"

**阶段台词（stages）**

| 好感 | 台词 |
|---|---|
| 0~20 | "香火钱随意。这庙三百岁，见过的修士比你见的庙多。" |
| 20~40 | "你上回踩坏的那块砖，我补了。补砖的泥里掺了香灰——神不计较，砖要计较。" |
| 40~70 | "你帮村里挡过那回妖潮，孩子们给你立了个小木牌，就插在庙门口。别嫌小，木头比石头香。" |
| 70~100 | "我死了以后，庙祝的钥匙给你。你嫌累就转给别人——钥匙不怕换人，怕没人接。" |

**情境台词（ctx）**

- 【你突破时】"突破是喜事。喜事上庙，添三炷香——不为你，为村里看看你气色。"
- 【大旱时】"今年这个旱，跪了也没用。你别应求雨的愿——应了，旱就是你的债。"
- 【你护庙时】"修士护庙，图什么？"他不等答案，"图什么都是好图。庙里不查这个。"

**论道（ask）**

> q：「神要是不灵了，庙里的人怎么办？」

- A「换一个灵的。」→ "换神像容易。人心换不过来——他们跪的从来不是神，是那年那炷香。"（fav +6）
- B「神灵不灵，人自己过。」→ "话是这么讲。"他扫着香灰，"讲这话的人，后来都回庙里来了。"（fav +4）
- C「那我就别让神不灵。」→ 他把扫帚放下了，很郑重地朝你拱了拱手。（fav +8，解锁：他偷偷告诉你村志里记的"前一位土地"去向）

- B「人的错。写错的人心里有岔。」→ "岔路里也有风景。你这话，我可以少收两文。"（fav +5）
- C「错不是错，是路标。」→ 他合上书，第一次沉默了很久："……这本，送你。摊上二十本里，我等这个答案等了四十年。"（fav +8，解锁隐藏功法线索「错字诀」）

## 第三部分 · 恩义与钩子剧情（对接 `HOOKS`）

> 明钩：欠了要还；暗钩：受了要认。每条钩子带"到期"与"不还的后果"。

1. **一饭之恩（明钩 · 三年期）**
   他人给你一碗粥。三年内要还——还粥不值钱，还"在他落难那年路过他门口"。
   不还后果：debuff【欠食】，打坐偶得概率下降。

2. **半页经（暗钩 · 无期）**
   传法时对方只教你半页。暗记：余下半页他要你"在用到的那天想起来"。
   到期触发：某场死战中，你忽然记起那半页——他早已不在了。

3. **代守门者（暗钩 · 因果型）**
   推过"残符石门"（奇遇①）者。三年后守门事件：一个新人要推门，你恰好路过。
   选项：A 替他推（承因果）/ B 拦住他（结善缘）/ C 走开（业力 +3）。

4. **断剑的旧主（明钩 · 五年期）**
   收过断剑（奇遇②）者。五年后旧主后代寻来，不索剑，索"一个交代"。

5. **井底的手温（暗钩 · 特殊）**
   "井中月"（奇遇⑥）选 A 者。此钩永不"到期"，但每逢月圆，井水事件随机偏向你。

6. **人情账的两清（明钩 · 立即）**
   "官道截杀"（奇遇⑭）选 C 者。两头的人情各开一账，任何一笔被讨还时，另一笔同步结算——**双向人情账**机制的最小闭环示例。
