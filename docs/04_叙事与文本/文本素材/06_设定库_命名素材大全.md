# 设定素材库 · 命名大全（古言增补版）

> 供数据表扩充、随机生成取用。命名之则：
> 功法 **二字实 + 一字式**（诀、功、经、典、法、章、卷）；神通依 `SHENTONG` 三字古雅之体；
> 地名避"仙、圣"之堆砌，用**物 + 姿态**；人名避生僻，道号避"真人"扎堆。
> 本版新增：匾额、楹联、尊号谥法、古语短语四类。

## 二、神通名（三字古雅之体）

> 命法：动词 + 名物，或名物 + 名物。成对者（日月、雨云、山地）可作稀有条目。

- **命类**：乞火书、借山契、问渡帖、驻云笺、赎岁单、留春册、断潮令、点灯疏
- **术类**：折枝问、隔水唱、空阶雨、断弦指、扫叶手、添香诀、抱瓮观
- **身类**：负雪行、踏苔步、振衣立、披蓑式、枕石功、听松身
- **目类**：照胆镜、窥垣眼、数星目、认香鼻、辨骨瞳
- **成对**：郁仪文 / 结璘章（日月）；唤雨帖 / 停云笺（雨云）；开山手 / 补地足（山地）

- 上：入门先忘来时路　下：参拜且看脚下阶　横批：**从零起修**
- 上：一灵不昧来此世　下：百劫不改是初心　横批：**道在足下**
- 上：门外红尘三丈软　下：门内青灯一寸凉　横批：**各取所求**

## 十六、古语短语（新增）

> 四字制度语，供誓词、族规、门规、契约取用。学《玄鉴仙族》"玄景灵誓"之体。

- **誓词类**：玄景为鉴（违誓者，玄景破碎）、以气为凭（气散则誓散）、指灵为誓、香火为证
- **族规类**：嫡承其基、旁支其劳、祠堂议罪、族运共担
- **门规类**：外门修力、内门修心、真传承法、叛门誓裂
- **契约类**：一诺千金、债不隔世、两讫不相欠、恩义两清
- **果报类**：因果自负、账不隔年、利随岁涨、今日不结利滚三分
