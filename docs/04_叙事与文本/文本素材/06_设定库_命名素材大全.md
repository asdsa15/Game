# 设定素材库 · 命名大全

> 供数据表扩充、随机生成器取用。命名原则：
> 功法 **二字实 + 一字式**（诀/功/经/典/法/章/卷）；神通学 `SHENTONG` 的三字古雅风（晦涩但成对）；
> 地名避"仙""圣"堆砌，用**物 + 姿态**；人名避生僻字，道号避"真人"扎堆。

## 二、神通名（三字古雅风，对齐 `SHENTONG`）

> 命名法：动词 + 名物，或名物 + 名物；成对出现（如「郁仪文 / 结璘章」为日月对）。

- **命类**：乞火书、借山契、问渡帖、驻云笺、赎岁单、留春册、断潮令、点灯疏
- **术类**：折枝问、隔水唱、空阶雨、断弦指、扫叶手、添香诀、抱瓮观
- **身类**：负雪行、踏苔步、振衣立、披蓑式、枕石功、听松身
- **目类**：照胆镜、窥垣眼、数星目、认香鼻、辨骨瞳
- **成对（可做稀有条目）**：
  - 「郁仪文」配「结璘章」（日/月）
  - 「唤雨帖」配「停云笺」（雨/云）
  - 「开山手」配「补地足」（山/地）
