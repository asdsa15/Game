## 二、NPC_POOL.ask（论道对白，重点）

> 人物说话须「像他自己」：剑修简、商贾利、魔者冷。保留原情绪走向与 `fav` 因果。

### 顾清玄（剑修，简而正）

| 位置 | 原文 | 文言改写 |
|---|---|---|
| `ask.q` | 你说，剑是快的好，还是稳的好？ | 汝道，剑宜快乎，宜稳乎 |
| 选项A | 「快。慢了就来不及。」 | 「快。迟则不及」 |
| A.reply | 他摇头：「来不及的，本就不该出手。」 | 摇头：「既来不及，本不该出手」 |
| 选项B | 「稳。稳到最后才出手。」 | 「稳。俟其隙而后发」 |
| B.reply | 他看了你一眼：「这话，像我师父说的。」 | 视汝一眼：「此语类吾师所言」 |
| 选项C | 「看你怕什么。」 | 「视君所惧者何」 |
| C.reply | 他愣住，很久才笑：「……这倒没想过。」 | 愕然，良久乃笑：「……此未尝思及」 |

### 云栖（坊市老板娘，利而巧）

| 位置 | 原文 | 文言改写 |
|---|---|---|
| `ask.q` | 你说，这世上是人情重，还是灵石重？ | 汝道，人情重乎，灵石重乎 |
| 选项A | 「灵石。人情最不值钱。」 | 「灵石。人情至贱」 |
| A.reply | 她笑出声：「痛快。我就喜欢跟痛快人做买卖。」 | 失笑：「痛快。吾喜与痛快人交易」 |
| 选项B | 「人情。钱花完了还能再挣。」 | 「人情。财散而复聚」 |
| B.reply | 她拨算珠的手停了一下：「……你这人，做不成大生意。」 | 拨珠之手微顿：「……君非为巨贾之材」 |
| 选项C | 「你问这个，是想听真话还是好话？」 | 「问此，欲闻真言，抑或甘言」 |
| C.reply | 她盯了你很久，忽然把账本合上：「真话。就这一次。」 | 注视良久，忽合账册：「真言。止此一回」 |

> 其余十位 NPC 的 `ask` 按同一口径处理：问句去「你说/么」，答句去「了/就」，保留人物口吻。落地时逐人对照字段替换，`fav` 数值不动。
