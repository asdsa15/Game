## 〇、修订说明

### 0.1 第一版的三条假设全部推翻（依据实测）

初稿曾按"清淡水墨淡彩 + 线宽均匀 + 抠图透明"设计图标。**实测已落地的 33 张后，这三条全部推翻**：

| 初稿假设 | 实测真相 | 结论 |
|---|---|---|
| 青金淡彩、晕染为主 | **重墨线勾勒 + 石青石绿重设色**，矿物颜料感 | 图标应沿用重墨重彩，不是清淡 |
| 线宽均匀（图标要"实"） | 线条**有提按变化**，干笔皴擦 | 均匀线反而会脱离体系 |
| 抠图透明 PNG | 大面积**计白当黑**（留白即云雾光） | **不抠图**，保留宣纸底，反而更统一 |

**风格基准不靠想象，靠实测。** 下面 §一 的每条都有图可对照。

### 0.2 第二版：按真实数据修正（2026-11-18 19:20）

1. **源图是 `.jpg` 不是 `.png`。** 出图工具按扩展名落盘，实际产出 `.jpg`；而 `compress_art.py` 原先写死只找 `*.png`，会把 83 张全判成"无源图"并静默跳过（不报错、不失败，只是没图）。已改为按 `.png → .jpg → .jpeg → .webp` 顺序取第一个存在的源文件。

## 一、实测风格基准（权威，不可再改）

从 `art/scenes/` 的 33 张里提取，四张代表图：`zhou_qingyue.jpg`（山水）、`map.jpg`（平面构图）、`end_shizun.jpg`（衬底+群像）、`market.jpg`（人群）。

| # | 特征 | 实测表现 | 图标怎么继承 |
|---|---|---|---|
| **1** | **笔法** | 重墨线勾勒轮廓，线条偏粗且**有提按变化**，配干笔皴擦 | 图标用同样粗细的墨线，但**提按减弱**（24px 下细节会糊成墨团） |
| **2** | **设色** | **石青 + 石绿**为主，花青过渡，赭石点染——典型青绿山水 | 图标配色限定在 **石青/石绿/赭石/墨**四色内 |
| **3** | **底与留白** | 米白宣纸底（`#FAF6EE` 量级），**大面积计白当黑**：留白即云、即雾、即光 | 图标**保留宣纸底，不抠图**（见 §2.3） |
| **4** | **人物** | 群像**剪影化、背影为主**，不画正脸；只有主角给清晰形象 | 图标里**不出现人脸**，人物类一律背影或剪影 |
| **5** | **云** | 画成**如意云头的轮廓线**，有线描感 | 图标可以用同样的云头线做点缀 |
| **6** | **光** | 柔和漫射；晨昏用**大面积留白 + 暖光晕**表达 | 图标最多一处暖光晕，不做全局高光 |
| **7** | **构图** | 主体明确、饱满，留白是有意的结构而非空缺 | 图标主体占画布 **70%~78%**，四周留安全边 |

**一句话基准**：**这是一套"重墨重彩的青绿山水"。图标就是它缩小之后的器物白描，用同一套墨色与矿物颜料。**

## 二、样式定死

### 2.1 三条铁律

| # | 铁律 | 理由 |
|---|---|---|
| **1** | **纵向轴（等级/品阶）只用色板，不画图标** | 等级是纵向轴，玩家已习惯看色块。再给纵向轴画图标＝两套视觉语言打架 |
| **2** | **横向类目（元素/物件/动作）用图标** | 色板一维，图标二维。色板答不了"这是把剑还是这瓶丹" |
| **3** | **图标不画成缩小版的风景插画** | 24px 下识别度只靠轮廓与剪影，细节全是噪点 |

### 2.2 与场景插画的差异（同一套颜料，不同画法）

| | 场景插画（33 张，已落地） | 图标（本期） |
|---|---|---|
| 画种 | 青绿山水，重设色 | **器物白描**，同一套墨色与矿物颜料 |
| 墨线 | 有提按，干笔皴擦 | 略细、提按减弱（24px 可读优先） |
| 设色 | 石青石绿 + 花青 + 赭石 | **同四色，但面积 ≤ 50%**（图标要的是形，不是彩） |
| 底 | 米白宣纸 | **同为米白宣纸**（这是不用抠图的前提） |
| 留白 | 计白当黑成结构 | 同样可用留白，但**主体轮廓必须完整** |
| 画幅 | 16:9 / 21:9 | **1:1** |
| 人物 | 群像背影 | **只出现背影/剪影，绝不出现正脸** |
| 交付 | 1320×570 JPEG q80 | **256×256 JPEG q82** |

### 2.3 不抠图：宣纸底 + `mix-blend-mode: multiply`

这是本方案最重要的一处简化，直接砍掉一整个高风险环节。

- 图标底色就是宣纸米白（`#FAF6EE` 量级），与面板底 `--panel:#FFFEFB` 极为接近
- 用 `mix-blend-mode: multiply` 叠加 → 纸色自然融合，图标像**贴在纸上**，而不是"浮在纸上"
- 备选：`border-radius: 4px` + 1px 浅边，用于确实需要边界感的场合

**收益**：
1. 不需要 `connector__matrix__remove_image_background`，少一个失败点、少一道抠图质量验收
2. 交付格式与场景图统一为 **JPEG**，`mobile/build.py` 的 `art_data_script()` 只需扩一个目录扫描
3. 不会出现抠图把白瓷丹瓶、雪、玉一起抠掉的经典事故

### 2.4 图标 prompt 骨架（铁律，逐字一致）

```
以图1为器物画法基准、以图2为山水笔墨基准：只沿用两图的墨线笔法、矿物设色与宣纸底调，不沿用两图的具体画面内容、构图与人物形象。
主体：<器物意象描述>。
中国水墨淡彩器物图标，青绿山水设色风格：厚重墨线勾勒轮廓（线条略细于山水画，提按不明显），石青石绿为主调、赭石点染、墨色压边，设色面积不超过画面一半，米白宣纸底色，主体居中占画面约四分之三，正方形构图，无人物面部，无文字、无印章、无水印、无背景场景、无投影、无 UI 元素。
```

**参考图取自已落地的真实场景图**（`market.jpg` + `zhou_qingyue.jpg`），不是概念样张——这样图标与现有 33 张插画天然同源，不靠文字描述去"猜"风格。

| 资产 | 挂载点 | 实现 |

- `wxcs3-icons.js` 缺失 → `iconKey()` 返回 null，`iconRow` 退化为 `optRow`
- `wxcs3-icons.js` 缺失 → `build.py` 跳过该标签，界面仍可正常跑
