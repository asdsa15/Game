## 二、破境：从一行字变成一个时刻

### 2.1 成功

```
破境 · 筑基

        铸基那一夜没有风。你听见体内有什么东西落定。

              筑基·初期　六轮兵解
──────────────────────────────────
境界        筑基·初期
寿元上限    +200 年
气血灵力    尽复

还有一件事要办。
        [ A 前行   六轮兵解 ]
```

- 诗**按境界分档**，每档三句，随机取一句（旧版每境只有一句，二周目会发现"怎么还是这句"）
- 副标题写清**这一步在设定里叫什么**：六轮兵解 / 三关俱过 / 金性已凝 / 气海翻涌
- 变化清单只列真正变了的：寿元 +200、气血尽复
- 按钮文字随下一步变：要铸仙基时写「六轮兵解」，否则写「继续」

### 2.2 失败

```
破境未成 · 筑基·中期

        你没有输给天。你输给自己多想了那半息。

                此关未过
──────────────────────────────────
气血        −29
修为        跌回七成
道心        动摇 · 需静养

再来一次，未必还是这个样子。
        [ A 前行   默坐良久 ]
```

失败比成功更需要说清楚——玩家得知道**输在哪、代价是什么、还能不能再来**。

### 2.3 小阶突破

不弹窗（练气要破九次，每次弹会烦死人），但纪事里给一句：

```
破境：晋 练气·七层。
· 一层一层皆是骨，走到第九层，骨便成了梯。
```

| 机缘 | 诗 |

| 洞天传音 | 空处有人诵我名，念到三遍我亦念。 |

渲染效果（手机宽度实测）：

```
机缘 · 叩门的旧识

        夜叩门者带血腥，
        只求一宿，不言明日。

夜里有人敲门，是个许久不见的旧识，一身血腥气，说只求躲一宿。
```

**诗在上、正文在下**：诗给气氛，正文给信息。只在第一个逗号断行，多逗号不会碎成三行。

## 四、成就：108 条题眼诗

### 4.1 做法

每条成就加 `poem` 字段，`txt` 保留为释义：

```js
{ id: 'dao_start', cat: '道', tier: 'wen', name: '灵初', cond: '踏入胎息',
  poem: '气海无声初起浪，凡人至此始知身。',
  txt: '气海里第一次响起水声。你以为那是水，其实是命。',
  test: s => !!s.started }
```

**为什么不全把 txt 改成诗**：现有 txt 是精心写的叙事（"六轮兵解的那一刻很疼。疼完之后，气海里多了一块东西，砸不碎。"），改成诗反而降级。所以做成两层——**诗负责记住，txt 负责懂**。

### 4.2 分级展示

| 档 | 展示方式 | 理由 |
|---|---|---|
| 传闻 / 载录 / 立传 | 右下角 toast（带一句诗） | 一局几十条，全弹窗会把节奏砸碎 |
| **入典 / 天书** | **诗窗**（诗大字 + 释义小字） | 一生只有十几条，值得停一下 |

toast 现在长这样：

```
功过格 · 载录
九层不坠
九层走尽无一跌，散修至此已称能。
入道 6 年 · 36 岁
```

功过格列表里，诗在名字下面，释义再小一号：

```
九层不坠                      载录
九层走尽无一跌，散修至此已称能。
九层走完，你没有跌回任何一层。这在散修里已经算一件小事了。
```

## 五、顺手修掉的两个真 bug

### 5.1 打坐永远不遇事（这次最值的一个）

```js
ACT.do_rest = (n) => {
  closeModal();
  for (...) advanceMonth(1);   // ← advanceMonth 只结算，不掷事件
  logLine('静养 1 月…');
  render();                    // ← 没有 maybeEvent()
};
```

`advanceMonth` 末尾只调 `afterMonthTally / tickHooks / checkAch`，**不调 `maybeEvent`**。而「打坐采气」是玩家最高频的动作。

**结果：越勤快的玩家越没事发生。** 奇遇与传法只在破境、交任务、战斗后才可能触发。

修：`do_rest` 末尾补 `maybeEvent()`。实测从"90 次打坐零事件"变成"4 个月内遇到传法与奇遇各一次"。

### 5.2 传法抢在破境诗窗之前

`do_xbreak` 成功后原本直接调 `maybeTransmitNow()`，它不看有没有诗窗，直接把「传法·残碑问法」顶上去——玩家破境后看到的是别人的残碑，不是自己的境界。

修：破境时设 `S.holdEvent = true`，
- `maybeEvent()` 开头检查，直接返回
- `maybeTransmitNow()` 调用处加 `&& !S.holdEvent`
- 诗窗「继续」走 `do;afterbreak`，末尾统一放行：`if (S.holdEvent) { S.holdEvent = false; maybeEvent(); }`

顺带解决了另一件事：破境后要弹**仙基 → 道印 → 神通**三个面板，旧版挤在一屏里互相顶掉。现在排队，一个看完再下一个。

## 七、风格取自哪里

| 来源 | 取了什么 | 例子 |
|---|---|---|
| 《玄鉴仙族》 | 术语成体系、白话写古意 | 「三十位上添一名」「纳音有名我有位」 |
| 《蛊真人》 | 格言体、冷、不解释 | 「刀未曾出鞘，也是一种活法。」 |
| 《俗主》 | 民俗忌讳腔、供桌与香火的具体 | 「供桌半个冷馒头，仍有人跪念我名。」 |
| 《苟在初圣魔门》 | 位格与代价的算计感 | 「新箓认了我，旧箓却认出我少了什么。」 |
| 《白骨大圣》 | 道门器物细节 | 「守炉不敢眨眼」→ 改成「初开一炉，火候只差一口呼吸。」 |

**避免的写法**：不用"心中一凛""不由得一愣""宛如天神下凡"这类；不解释情绪（写"手是稳的"，不写"他很冷静"）；每句尽量带一个**具体物**（冷馒头、伞骨、香灰、蒲团、槌子）。
