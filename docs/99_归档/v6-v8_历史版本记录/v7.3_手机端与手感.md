## 二、手机端：七处真改动

### 1. 首屏资源条（最大的一处）

原来气血 / 灵力 / 灵石 / 寿元在页面**最底部**（约 1900px 处），手机上每次都要滚两屏才知道自己还剩多少血、多少钱。

现在在境界条下面加一行 `.vitals`：

```
气血 72/100   灵力 38/100   灵石 320   寿元 98 年
```

- 只在 `≤880px` 显示，桌面三栏已有状态列，不重复。
- 神道第四项换成「信众」；香火本来就在境界条里。
- 气血低于 33%、寿元少于 20 年时数字转朱色。

### 2. 战斗六键：说明不再被省略号吃掉

原来手机上 `.note` 被限成 `5.2em` + `ellipsis`，实际显示是：

```
攻 72% …    术 招式1 …    器 符 2 张 …    谋 观察 / 交涉…
```

玩家看不到"约 20% 伤害""有丹可服"，等于六键里有三个是盲的。

现在改成两行：标题一行、说明一行右对齐，允许换行。实测高度只多约 10px，三行六键仍在一屏（战斗页总高 637px < 844px）。

### 3. 战况日志

战斗时看不到纪事，打完才知道刚才发生了什么。现在六键下面接最近四条战况（新的在下），带颜色，最多 7em 高。顺带把底部那块空白填了。

### 4. 点遮罩关弹窗

长列表（庙市、四艺、功过格）要滚到底才能按"关闭"。现在点弹窗外的遮罩即可关闭；`noClose` 的抉择弹窗（破柱/破境）带 `data-noclose`，不会被误关。

同时 `body.modal-open{overflow:hidden}`，弹窗开着时底页不跟着滚；`scrollbar-gutter:stable` 防桌面滚动条消失时横向抖一下。

### 5. 指令坞 5 列

15 个入口原来 4 列 4 行，现在 5 列 3 行（`≤560px`），少一行约 55px。副标题在 9px 下仍能看出"练气/青岳/3 件"。

### 6. 可点区域与 iOS 缩放

- 顶部「系统」按钮 29px → 40px；弹窗页签 38px；chip 36px。探针复测：**主界面已无 <36px 的 `[data-act]` 元素**。
- 自由输入 13.5px → **16px**（iOS 在 <16px 的输入框聚焦会自动放大整页）；创角姓名/年龄/相貌同样处理。
- toast 底部加 `env(safe-area-inset-bottom)`，不被 iPhone 横条压住。

### 7. 两处"看着不对"的小事

- 创角主修三选一在窄屏变通栏后，「神道」被挤成竖排（神 / 道 两行）。给 `.chip b` 加 `flex:0 0 auto; white-space:nowrap`。
- 功过格未达成的成就名是 `#9C958A`，在米色纸上对比度太低，390 宽截图里几乎看不见。改 `#6F675C`；手机端把「——」放回名称同一行，不再白占一行高度。

## 三、桌面端：顺手修的三处

1. **主栏字母顺序**：原来疗伤是 E，却排在 C/D 前面（A B E C D），键盘直选会跳。现在 A B C D E 与显示一致。
2. **快捷键按线路走**：旧 `KEYMAP` 把 `c` 写死成「外出历练」、`d` 写死成「参悟功法」，神道按下去是错的。改成 `mainKeyAction()`：神道 c=显圣、d=传教；`b` 在未满时给「闭关快进」而不是「破境」。数字 1~5 同。
3. **主线为空不再占一条横栏**：`主线 · ——` 只在真有主线时渲染。

## 五、手机端最容易被忽略的一个坑：PWA 永远停在旧版

`sw.js` 原本是：

```js
const CACHE = 'wdcs-v6.2.1';          // 从 v6.2 起没改过
// fetch：所有请求 cache-first
```

后果：**只要装过一次 PWA，之后所有更新都不会生效**——缓存里永远是那一版 index.html。桌面双击 dist 不受影响，所以一直没被发现。

改法：

1. 页面（`request.mode === 'navigate'` 或 HTML）改**网络优先**，断网才回缓存；
2. 图标等静态资源仍缓存优先（离线可玩）；
3. `build.py` 把 `__BUILD__` 替换成当次 `index.html` 的 md5 前 8 位，内容一变缓存名就变，`activate` 自动清旧缓存。

验证：`dist/sw.js` 的 `CACHE` 已是当次构建指纹（`wdcs-xxxxxxxx`），文件中不再有 `__BUILD__` 残留。
