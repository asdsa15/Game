## 三、四个可借鉴的框架模式

### 3.1 Verb＋Card：动作要有「输入」

Cultist Simulator 的核心不是选项，是**把东西放进动词里**：
「研习」这个动词，放一本书进去 → 产出理解；放一张人卡进去 → 产出关系。
同一动词，放不同的卡，结果完全不同。

**本项目现状**：意图引擎里，玩家输入「采药」，系统自己决定采到什么。
玩家没有「放什么进去」的自由。

**可借**：给意图加**对象槽**。比如「用××去××」：
- 采药 × 洞府后院 / 后山 / 妖兽巢边（风险不同）
- 送礼 × 灵石 / 丹药 / 自己做的符（好感不同）
- 炼丹 × 蓝幽草 / 妖丹（成品不同）

这一步能把「不同行为不同结果」从 30 类扩到 30×N。

### 3.2 QBN 的「状态节俭」：我们的变量太多了

Fallen London 的公开设计原则叫 **quality parsimony**：状态变量越少越好，
这样加内容时作者脑子里装得下，也不会出现「A 涨了但没人读」。

对照本项目：

| | 本项目 | Fallen London |
|---|---|---|
| 状态字段 | **92** | 精简 |
| 内容单元 | **45 个动作 / 22 条事件** | **2000+ storylet** |

比例是**反的**：我们用 92 个变量撑 45 个动作，它用很少的变量撑 2000 段内容。
后果就是「死字段」——`enemySect` `daoyinOk` `jinxing` 都是这么来的。

**可借**：以后加内容前先问一句「这个新字段，谁会读？」
答不上来就别加，用现有的字段组合表达。

### 3.3 属性分档出文本：文本量的乘法器

《活侠传》有四个正交属性：**性情／处世／道德／修养**，每个五档。
同一段剧情，因为属性组合不同，台词、选项、NPC 反应全都不一样。
120 万字里有很大一部分是这么乘出来的，不是硬写出来的。

**本项目现状**：只有 `道心/悟性/资质/机缘/神识/身法` 六个数字，且只进公式，不进文本。

**可借**：把 2~3 个轴做成**分档**，让意图结果按档位换写法。
比如「道德」高 → 邪道意图会出现劝阻式文本；「性情」偏刚 → 交涉类意图成功率与文本都变。

这是在不写 10 倍文本的前提下把阅读量做上去的唯一办法。

### 3.4 天命盘：随机，但可以「尽人事」

《活侠传》的判定是**骰点 + 属性补正**，玩家看得见补正项，也可以花「天命点」重骰。
它不是纯随机，也不是纯数值——是「你把能做的做完，剩下的交给天」。

**本项目现状**：破境已经是「准备 + 掷骰」，方向对了。
但**展示**不够：玩家看不到「我做了哪些准备、各自值多少」，只看得到一个百分比。

**可借**：破境面板把每一项准备的贡献列出（已做了一半），
再给一个「逆天改命」的口子（消耗稀有资源重骰一次），让不甘心的人有处使力。

## 四、本项目缺口（有代码证据）

| 缺口 | 证据 | 严重度 |
|---|---|---|
| 修为是唯一进度条 | 除修为外，没有任何东西能推进境界 | 高 |
| 内容单元太少 | 45 个动作 / 22 条事件 / 30 类意图 | 高 |
| 状态变量过多 | 94 字段；死字段本轮已清零（`enemySect`/`daoyinOk`/`jinxing`/`lastVerse` 全部接上或用于显示） | 中高 |
| 属性不进文本 | 六个 stats 只在公式里出现 | 中高 |
| 师徒/弟子缺失 | 「弟子」只出现在职位名与一句文案 | 中高 |
| 御兽缺失 | `grep 御兽/灵宠` = 0 | 中 |
| 地点差异弱 | `PLACES` 只有 `lingqi` 一个有效字段 | 中 |
| 名声消费端弱 | 只影响传教倍率、交涉、一个结局 | 中 |
| 心境不存在 | `grep 心境` = 1（说明文字） | 中 |
| 时间无压力 | 寿元 120~700 年，而升境只需 1.5~42 年 | 中 |

## 五、优先级建议（结合本轮已做的）

**已做**：破境准备（3.4 的一半）、业力→心魔、恶名→仇家（3.1 的后果侧）。

**建议接下来**：

1. **对象槽（3.1）**——把意图从「玩家说要做什么」升级成「玩家说要拿什么做什么」。
   一次改动，30 类意图的实际结果数量翻数倍，且不需要新字段。

2. **属性分档出文本（3.3）**——先做两个轴（道德／性情），各三档，
   接到意图结果的选词与邪道/善行的可用性上。它同时解决「文本量」和「属性没用」两个问题。

3. **瓶颈**——修为满之后要满足一个「悟」的条件。
   把道书、悟道、闲事、NPC 论道四套系统接进主线。

4. **师徒**——救活宗门线、人锚、两条归档成就、家族后辈。

5. **清理**——`SHIXIU`／`RENCAI` 要么补完，要么删表。
