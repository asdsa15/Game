## 一、先说后端

**没有后端。** 本轮改的全是本机单文件游戏（`wxcs3-game.js` / `wxcs3-data.js` + HTML/CSS + 移动端构建产物），没有服务器、没有数据库、没有网络接口，存档仍然只写浏览器 `localStorage`。

之所以如此，是方案前提已定：**单人玩、云存档可有可无**。以此为前提，《后端方案评审与对标改进_20261117.md》约六成内容降档，PocketBase / 多端冲突检测 / LLM 独立进程 / 世界暂停全部划为"可无限期推迟的选读材料"（rev2 §八.3）。所以"四批做完就有后端"这个预期不成立——**四批做完只是玩法纵深补齐，后端仍是另一条独立线，且当前被主动后置**。

真要做后端，最小可用形态是：一份存档同步接口（PocketBase 单表 + 设备令牌）、一个读档校验（版本号 + 迁移函数复用 `applyState`）。这两件都不在 P0 批次 1~4 的范围内。

## 六、两条踩坑记录（留给以后）

1. **`test_econ.js` 会把纯函数单独抠出来跑**（`grab('monthXianghuo')`）。所以纯函数里不能调用 `bodyDef()` 这类同文件辅助函数——抠出来时不存在，直接 `ReferenceError`。处置：`monthXiuwei` / `monthXianghuo` 里改为就地 `D.BODIES.filter(...)`。
2. **`applyState` 结尾是 `S = out`**，会替换内部引用。测试脚手架原先是 `const S = G.S`，读档后所有断言读的都是旧对象（表现为"读档没生效"）。处置：改 `let S = G.S`，读档后 `S = G.S` 重取。
