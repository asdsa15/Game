## 二、钩子注册数组（M2 新机制，扩展协作的核心）

M1 的乘区注册表解决了「多方改同一数值」，但 M2 撞上另一类冲突：
**单个函数槽位会被后加载者整个覆盖**（beast 的 `EXT.fightRows` 曾把 benming 的法技按钮顶掉）。
所以 M2 起凡是「多方都要发言」的位置一律用注册数组，`game.js` 薄缝只负责遍历：

| 数组 | 语义 | 返回 |
|---|---|---|
| `EXT.preFightRowsHooks` | 战前准备页追加选项 | HTML 串 |
| `EXT.fightInfoHooks` | 战斗我方面板追加状态行 | HTML 串 |
| `EXT.fightRowsHooks` | 战斗回合按钮追加 | optRow HTML 串数组 |
| `EXT.combatActHooks` | `do;cbt:ext:*` 动作认领 | `{dmg,note}` / `'stop'` / null |
| `EXT.foeHooks` | 敌方回合拦截（在扣玩家血**之前**） | true＝已结算 |
| `EXT.onMonthHooks` | 月结追加（game.js 侧挂 `phase !== 'play'` 熔断） | — |

数组下标即文件名前缀序：本命 0、灵兽 1，测试据此直接点数断言。

## 三、本命法器关键实现点

1. **加持翻倍不新开乘区**：认主后 game.js `artBonus(kind)` 里把这一件的自身 bonus 再加一遍
   （`EXT.benmingArtBonus(kind)`，仅该件且须佩挂）——避开与乘区注册表相互放大。
2. **法技按槽位变形**：atk→器灵出鞘（16% 敌上限）、body→器灵护体（30% 卸力）、
   hit→器灵照影（看破）、move→器灵疾影（10% 伤+15% 卸力）；耗灵力 12、器损 +6。
3. **器损有后果**：≥80 法技按不住、须花 30 石 + 一旬重开炉；月结 ≥80 每月扣 5% 气血上限；
   共命以上出鞘挡击器损 +18，器失落（卖出/失窃后 arts 里没这件）契断并倒血三成。
4. **合道与道痕联动**：合道后按命格给共鸣（一剑→剑伤 ×1.10、丹火→行功 ×1.05、其余→行功 ×1.05），
   并使物锚之「物」不再误期（`EXT.benmingAnchorStable()`，`tickAnchors` 跳过 'wu'）。
5. **进阶要行为**：祭炼熟练满 100 + 境界门槛（共命筑基、合道金丹），进阶替换而非叠加。
6. **时间口径**：祭炼 15 石一旬、修器 30 石一旬；认主/进阶/改名不占（血点睛一瞬），
   已登记入 `行动预算_分档表.md`（本命分档）。

## 四、灵兽关键实现点

1. **独立气血不进战力数字**：`combatDeploy` 按妖力算兽血（30+气血系数×25×妖力倍率），
   只在 `fightInfoHooks` 里画血条；兽令三式走 `do;cbt:ext:*` 与主线共用结算尾巴。
2. **听令看亲密两轴**：攻/护听令率 = 0.55 + 护主档位×0.5（野 10%→契 70%）；
   野档每场首回合掷反噬（被自家兽咬 6% 气血）；调教涨妖力却跌亲密——两轴换着养。
3. **护主是真挡刀**：v8.1 原逻辑把「兽挡刀」写在扣玩家血之后（挡了个寂寞），
   本轮把该块整体搬进 `EXT.foeHooks` 并落在扣血之前，一次修一旧账。
4. **饿了会走**：喂养记账 `S.beastFedMonth = S.turn`；月结算饥饿月数，亲密随饥饿下滑，
   饿过两月按 `0.20+0.15×饥饿` 掷叛逃——外物的忠诚是养出来的，不是抽出来的。
5. **封兽官（神道）**：香火 30 敕牒、月俸香火 10（走 `EXT.fixedCosts2()` 第二条月账缝），
   在职显圣 ×1.10、每月亲昵 +1；仙道封不得。
6. **坞位冲突修复**：v8.1 神器已占「器」键，本命坞位改用「命」；GROUP 表补 `命/兽 → 修炼`。

## 五、过程里揪出的两个真 bug

1. **`renderCombat` 里 `const o = []` 被 concat 赋值**：M2 薄缝 `o = o.concat(扩展行)` 对 const
   赋值，浏览器一进战斗就 `TypeError: Assignment to constant variable`。改 `let`。
   Node 测试没抓到是因为测试只直调扩展函数、没走完整 `render()` 渲染战斗页。
2. **旧挡刀顺序 bug（v8.1 遗留）**：见上，四-3。
