## 一、为什么推倒重来

v1 把炼器、炼丹、制符、阵法当成**四个功能模块**来设计——每个模块一套流程、一套配方、一套数值。

问题在于：**玩家不会因为"多了四个功能"而觉得好玩，只会因为"换了一种活法"而想再玩一遍。**

四艺真正的价值不是"能做东西"，而是**四种不同的谋生方式**：

- 丹修每个月在做什么？采药、开炉、卖丹。
- 剑修每个月在做什么？接悬赏、找人打架、护道。
- 阵修每个月在做什么？布阵、收租、等仇家上门。

**如果这四件事在游戏里长得一样（都是"点一下、涨一点、等一月"），那做八个功能也没用。**

所以这一版换了个顺序：

> 先定**玩家怎么活**（路线），再把四艺塞进对应的活法里（工具）。

## 二、八条路线总览

| # | 路线 | 一句话 | 月循环 | 变强靠 | 主要收入 | 战斗风格 | 短板 |
|---|---|---|---|---|---|---|---|
| 1 | **剑修** | 一剑破万法 | 历练/挑战/磨剑 | 剑意层数 | 悬赏·护道 | 高爆发、先手 | 不会经营，穷 |
| 2 | **体修** | 肉身即法宝 | 淬体/服药/挨打 | 肉身境界 | 打手·镇场 | 抗揍、反伤 | 慢、耗资源 |
| 3 | **丹修** | 一炉丹换一条命 | 采药/炼丹/卖丹 | 丹药品阶 | **卖丹（刚需）** | 嗑药续航 | 正面弱，怕偷袭 |
| 4 | **器修** | 器成则道成 | 寻材/炼器/温养 | 本命法宝 | **卖器（高单价）** | 靠法宝词条 | 前期极慢 |
| 5 | **符修** | 一符定生死 | 制符/卖符/囤货 | 符箓种类 | **卖符（周转快）** | 一次性爆发 | 消耗品，不持久 |
| 6 | **阵修** | 我的地盘我做主 | 布阵/收租/接单 | 阵法品阶 | **阵法收租** | 主场无敌 | 离阵即弱 |
| 7 | **御兽** | 我不用动手 | 捕兽/养兽/驯化 | 兽的品阶 | 卖兽·租兽 | 群殴 | 兽死则弱 |
| 8 | **魔修** | 快，但回不了头 | 掠夺/血祭/吞修 | 业力转化 | 抢（最快） | 越杀越强 | 人人是敌 |
| — | **神道**（已有） | 有人记得你就不死 | 坐庙/显圣/传教 | 香火柱位 | 香火钱 | 权柄 | 已实装 |

**这八条不是"职业"，是"月循环"**——玩家每个月点的那几下不一样，游戏就活了。

## 三、路线详解

### 3.1 剑修 —— 最纯粹的杀伐

| 项 | 内容 |
|---|---|
| **核心循环** | 磨剑（涨剑意）→ 找对手（历练/挑战/悬赏）→ 赢了得剑意与名声 |
| **关键资源** | **剑意**（独立于修为，只能靠实战涨） |
| **变强路径** | 剑意 1~9 层，每层 +8% 剑系伤害，满层解锁"一剑"（一次性大伤，代价是剑意清零） |
| **战斗特色** | 先手判定极高（遁速 ×1.5），第一击伤害 ×1.3 |
| **短板** | 完全不会经营。**剑修是最穷的路线**，必须靠卖命换钱 |
| **与四艺的关系** | 只买不卖：买器修的剑、符修的护身符 |
| **小说依据** | 《玄鉴》"剑修最盛，也最穷"；《我师兄》里剑修多为打手 |

**为什么先做它**：现有 `SKILLS` 里已有剑系招式（剑气纵横、白骨飞剑），`剑灵体` 体质也在——**剑修几乎是现成的**，只需补"剑意"这一个计数器。

### 3.2 体修 —— 用钱堆出来的硬度

| 项 | 内容 |
|---|---|
| **核心循环** | 淬体（耗药材/灵液）→ 肉身境界提升 → 更能挨打 |
| **关键资源** | **肉身境界**（皮/肉/筋/骨/髓，五层） |
| **变强路径** | 每层 +气血上限、+减伤；髓层可硬抗高一境一击 |
| **短板** | **极度耗钱**。淬体材料消耗是炼丹的 2 倍 |
| **与四艺的关系** | 大量买丹修的淬体液、器修的护具 |
| **小说依据** | 《白骨大圣》"肉身极限的练体强者天生压制神道高手" |

**设计要点**：体修是**经济的最大消耗方**，它的存在让丹修和器修有生意。没有体修，丹药卖给谁？

### 3.3 丹修 —— 全世界的药罐子

| 项 | 内容 |
|---|---|
| **核心循环** | 采药/买药 → 开炉（三次火候）→ 出丹 → 自用或卖 |
| **关键资源** | **丹方**（配方本身就是资产，可抄可偷可传） |
| **变强路径** | 可炼品阶 ↑、成丹率 ↑、能炼"自己吃"的修炼丹 |
| **收入** | **卖丹**。丹药是所有路线的刚需，所以丹修**永远不缺买家** |
| **战斗特色** | 靠丹药续航：战斗中嗑药不占回合（其他路线嗑药占一回合） |
| **短板** | 正面战斗最弱；丹房被砸＝破产 |
| **与四艺的关系** | 四艺之一，与符修共用"火候判定"骨架 |
| **小说依据** | 《我师兄》"一炉备九份料""炸炉污元神"；《白骨大圣》"药铺是暴利行业" |

**丹修的经济地位**：它是**整个经济循环的发动机**——所有路线都要吃丹，所以丹修永远有现金流。

### 3.4 器修 —— 三年不开张，开张吃三年

| 项 | 内容 |
|---|---|
| **核心循环** | 寻材（买/挖/抢）→ 炼器（器胚→刻阵→淬炼）→ 卖或自用 |
| **关键资源** | **本命法宝**（只有一件，可温养升级，与性命相连） |
| **变强路径** | 本命法宝品阶 ↑；法宝碎则修为受损 |
| **收入** | 卖法宝。**单笔金额最高**，但一年做不出几件 |
| **战斗特色** | 靠法宝词条组合（减伤/遁速/克制），打法最花 |
| **短板** | 前期极慢。第一件本命法宝可能要攒三年 |
| **与四艺的关系** | 四艺之一；**器修与阵修天然互补**（阵盘是器修的活） |
| **小说依据** | 《玄鉴》法器出现 1,595 次，是全书最高频的物品词 |

### 3.5 符修 —— 现金流之王

| 项 | 内容 |
|---|---|
| **核心循环** | 买符纸符墨 → 画符 → 卖符 / 囤符 |
| **关键资源** | **符笔**（决定品相上限）+ **符墨**（决定属性） |
| **变强路径** | 能画的符种 ↑；同种符可画"叠符"（一次触发多张） |
| **收入** | **卖符，周转最快**。一张符从画到卖只要几天 |
| **战斗特色** | 一次性爆发：一回合甩三张符，打出越阶伤害 |
| **短板** | 打完就没了；符纸断供就废 |
| **与四艺的关系** | 四艺之一，**链条最短**（两种材料 + 一次判定） |
| **小说依据** | 《玄鉴》符箓 665 次，"符笔"是可交易商品；《白骨大圣》"一纸黄符天师受箓" |

### 3.6 阵修 —— 越后期越强

| 项 | 内容 |
|---|---|
| **核心循环** | 布阵（材料组合）→ 收租/防守/围杀 → 攒阵材再布更大的阵 |
| **关键资源** | **阵盘**（材料组合而成，不可复制） |
| **变强路径** | 阵法品阶 ↑、阵法数量 ↑、可布的"势"范围 ↑ |
| **收入** | **收租**：给别人布聚灵阵，每月抽成。**躺着赚钱** |
| **战斗特色** | 在自家阵中战力 ×1.5~2.0；离阵则最弱 |
| **短板** | 前期投入巨大；**阵被破则血本无归** |
| **与四艺的关系** | 四艺之一；阵法是唯一"资产型"四艺（其他三个是消耗型） |
| **小说依据** | 《我师兄》阵法 772 次，"集齐五行宝珠制作五行轮杀阵的阵盘" |

**阵修的经济学**：它是**唯一能"躺赚"的路线**，但前提是先有阵。这形成一个"前期苦、后期爽"的曲线，很适合长期存档。

### 3.7 御兽 —— 一个人打不过，就带一群

| 项 | 内容 |
|---|---|
| **核心循环** | 捕兽（需符/阵辅助）→ 养兽（喂灵石/妖丹）→ 驯化 → 出战或卖 |
| **关键资源** | 兽的**品阶与亲密度** |
| **变强路径** | 兽栏数量 ↑、兽品阶 ↑ |
| **收入** | 卖兽（幼兽价高）、租兽（护院）、寻物（嗅觉类） |
| **战斗特色** | 多打一；兽可替死 |
| **短板** | 养兽极耗灵石；兽死则元气大伤 |
| **与四艺的关系** | 与符修/阵修强联动（捕兽需符，圈养需阵） |
| **小说依据** | 《魔门》"外门四殿：炼宝、炼丹、**御兽**、合欢"；现有代码已有 `S.yaoshou` 字段与"妖物认你"事件 |

### 3.8 魔修 —— 不是路线，是加速器

| 项 | 内容 |
|---|---|
| **定位** | **跨路线的捷径**：任何路线都能"入魔"，换取 3 倍速 |
| **核心循环** | 掠夺/血祭/吞修 → 修为暴涨 → 业力累积 → 被追杀 |
| **代价** | 每 100 业力，寿元 −5%；正道见之必剿；无法进入洞天（无箓即邪魔） |
| **与四艺的关系** | 魔修可"血炼"法器丹药（威力 +50%，但业力 +） |

**设计要点**：魔修**不做成第九条路线**，做成"所有路线都能拧的一个阀门"。这样玩家在卡关时会考虑"要不要入魔"——这是最有张力的抉择。

## 四、路线不是职业：切换与兼修

### 4.1 规则

| 项 | 规则 |
|---|---|
| **主修** | 1 条，月循环按主修算，100% 效率 |
| **兼修** | 1 条，效率 50%（可以做，但慢一倍） |
| **切换** | 散功 30%（与现有"仙→神转修"一致），道心 −1 |
| **不可兼修的组合** | 剑修 × 丹修（心不静）、体修 × 符修（手不稳）——**故意留冲突，制造取舍** |

### 4.2 为什么要限制

如果什么都能兼，玩家最后会变成"全能战士"，路线设计就白做了。

**冲突组合是设计的一部分**：剑修不能炼丹，是因为"剑心通明"与"文火慢炼"是两种心性。这个理由要写进游戏文本里，让玩家觉得"合理"而不是"被限制"。

### 4.3 兼修的真实收益

兼修不是"多一个技能"，而是**解决自己的短板**：

- 剑修兼炼丹 → 打不动了就嗑药，但丹药只有一半效果
- 丹修兼炼器 → 给自己做一口好炉
- 阵修兼制符 → 阵法有了攻击手段

## 五、经济：路线即收入

### 5.1 一张图看懂钱怎么转

```
        ┌──────────── 灵石 ────────────┐
        │                              │
    ┌───▼───┐   买丹     ┌────────┐    │
    │ 剑修  │──────────▶│        │    │
    │ 体修  │   买器     │  丹修  │    │
    │ 御兽  │   买符     │  器修  │    │
    └───┬───┘            │  符修  │    │
        │                │  阵修  │    │
        │  卖命换钱       └───┬────┘    │
        │                    │         │
        └──── 悬赏/护道 ──────┘ 卖货 ───┘
```

**核心逻辑**：
- **艺修（丹/器/符/阵）生产，战修（剑/体/御兽）消费**
- 战修靠"卖命"挣钱，再把钱花在艺修身上
- 艺修靠"卖货"挣钱，再买材料

**这个循环一旦转起来，"没有赚钱手段"的问题就自动消失了**——因为每条路线都有自己的现金流。

### 5.2 各路线收入曲线

| 路线 | 前期 | 中期 | 后期 | 特点 |
|---|---|---|---|---|
| 剑修 | 低（没人雇） | 中（悬赏） | 高（护道/镇场） | 线性上升 |
| 体修 | 中（打手） | 中 | 低（被替代） | 平台期 |
| 丹修 | 中（卖低阶丹） | 高 | 极高（稀缺丹） | 稳定上升 |
| 器修 | 极低 | 中 | 极高（本命法宝） | J 型曲线 |
| 符修 | 中 | 中高 | 高 | **最平稳** |
| 阵修 | 负（一直投入） | 低 | 极高（收租） | 深 U 型 |
| 御兽 | 低 | 中 | 高 | 慢热 |
| 魔修 | 极高 | 高 | 崩（被围剿） | 抛物线 |

**这张表是路线设计的核心**：它保证了"选哪条路"是一个真实的策略决定，而不是"哪条更强"。

### 5.3 四档变现渠道（沿用 v1）

| 渠道 | 收购价 | 门槛 | 代价 |
|---|---|---|---|
| 宗门收购 | 市价 × 70% | 需宗门身份 | 稳定、量大 |
| 坊市摆摊 | × 100% | 摊位费 | 每月限件数 |
| 拍卖会 | × 120~180% | 三年一次 | 抽成 10%，可能流拍 |
| 黑市 | × 140% | 无 | 业力 +，被盯上 |

### 5.4 价格链（这一条必须改，否则一切白搭）

**现状是倒挂的**：材料中位 660 > 丹药中位 480。

```
成品基准售价 = 材料成本 × 2.2
```

（推导：品相期望 0.877 × 成功率 0.85 ≈ 0.745，1/0.745 ≈ 1.34，再留 25% 毛利与波动空间）

| 成品 | 材料成本 | 建议售价 | 现价 |
|---|---|---|---|
| 回春丹 | 80 | **180** | 50 |
| 生肌续骨丹 | 150 | **340** | 140 |
| 火符 | 50 | **110** | 无 |
| 器胚·青叶舟 | 400 | **880** | 400 |

### 5.5 一条硬约束

**制作必须占用一个月。**

否则玩家会无限刷制作，经济立刻崩。让"炼一炉丹"与"打坐一月"互斥——这条约束比任何数值平衡都重要。

## 六、四艺在新框架里的位置

| | v1 的说法 | v2 的说法 |
|---|---|---|
| 四艺是什么 | 四个功能模块 | **四条路线的核心循环** |
| 为什么做 | 玩家能做东西 | 玩家有四种活法 |
| 数值怎么定 | 按功能配 | 按**收入曲线**配（见 5.2） |
| 失败怎么处理 | 扣材料 | 影响**当月收入**（丹修炸炉＝这个月白干） |
| 与其他系统 | 并列 | 四艺是**经济的生产端**，战修是消费端 |

**具体到实现，v1 的流程设计全部保留**：

- 统一的"选配方 → 备料 → 三次火候判定 → 品相五档 → 处置"骨架
- 品相倍率 0 / 0.7 / 1.0 / 1.6 / 3.0
- 炼丹"一把梭"、炼器"慢慢磨"、制符"薄利多销"、阵法"资产型"

**变的只是定位**：它们不再并列展示，而是**挂在对应路线下面**——玩家选丹修才会看到炼丹面板。

这样界面上也清爽：一个丹修玩家的主界面只有"采药/开炉/卖丹"三个动作，而不是八艺全开。

## 七、与现有系统的接口

| 现有系统 | 路线怎么接 |
|---|---|
| **境界（六境/八柱）** | 路线是"怎么修"，境界是"修到哪"。两者独立 |
| **宗门（v6.3 已有）** | 魔门四殿正好对应：炼宝殿→器修、炼丹殿→丹修、御兽殿→御兽；可再加"符箓殿""阵法殿" |
| **家族（v6.3 已有）** | 家族有"传承路线"，世代出丹修/剑修，影响族人天赋 |
| **道统（玄鉴）** | 道统决定路线倾向：坎水→水系丹道、离火→器修 |
| **剑意/肉身/符种等新资源** | 各路线一条独立进度条，不影响修为 |
| **战斗** | 路线决定战斗选项：剑修多"剑招"、符修多"甩符"、阵修多"布阵" |

## 八、落地顺序

**不是四条一起做，而是一条一条验证。**

| 步 | 做什么 | 为什么 | 工作量 |
|---|---|---|---|
| **1** | **坊市卖出 + 价格链重标** | 有产出必须先有出口，否则做完也白做 | 1 天 |
| **2** | **符修**（制符 + 卖符闭环） | 链条最短、失败代价最小，**用它验证经济能不能转** | 1~2 天 |
| **3** | **剑修**（补剑意计数器） | 现有招式已是剑修底子，几乎零成本 | 半天 |
| **4** | **丹修**（三次火候） | 玩法最成熟，且是经济发动机 | 2~3 天 |
| **5** | **体修**（淬体消耗） | 让丹修有稳定买家 | 1 天 |
| **6** | **器修 + 阵修** | 依赖法宝栏与洞府，最后做 | 3~4 天 |
| **7** | 御兽 | 依赖兽栏与符阵，可延后 | 2~3 天 |

**第 2 步是关键验证点**：如果符修能跑通"买料→制作→卖出→再买料"的循环，说明经济成立，后面照着复制即可。如果跑不通（比如玩家还是没钱），问题一定在价格链，不在系统本身。

## 十、一句话总结

v1 想的是"给游戏加四个功能"，v2 想的是"**给玩家四种活法**"。

八条路线里，四条靠手艺吃饭（丹器符阵），三条靠本事吃饭（剑体兽），一条靠不要命吃饭（魔）。

**玩家选哪条，决定了他每个月点哪几下——这才是文字游戏里"玩法"的全部。**

而"没有赚钱手段"这个问题，本质上不是缺一个卖东西的按钮，是**缺"我靠什么活着"这件事**。路线做出来，钱自然就有了来路。
