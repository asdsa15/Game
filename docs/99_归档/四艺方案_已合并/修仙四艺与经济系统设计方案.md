## 一、现状诊断

### 1.1 四艺：数据齐了，流程没有

| 项 | 现状 |
|---|---|
| 材料表 `MATERIAL_EXT` | ✅ 12 条（60~1,500 灵石，中位 660） |
| 丹药表 `PILL_EXT` | ✅ 19 条（30~12,000，中位 480） |
| 法宝表 `ARTIFACT_EXT` | ✅ 12 条（90~8,600，中位 1,200） |
| **炼丹** | ❌ 全代码出现 **1 次**（文案） |
| **炼器** | ❌ 全代码出现 **1 次**（文案） |
| **制符** | ❌ **0 次** |
| **阵法** | ❌ **0 次** |

结论：**原料与成品都备好了，缺的是"把它们连起来的那道工序"。**

### 1.2 经济：只能买，不能卖

`SHOP` 是把 `PILL_EXT / ARTIFACT_EXT / MATERIAL_EXT` 拼出来的**单向货架**：

```js
const SHOP = PILL_EXT.map(x => ({cat:'pill', ...x}))
  .concat(ARTIFACT_EXT.map(...))
  .concat(MATERIAL_EXT.map(...));
```

全项目搜不到 `sell` / `卖出` / `回收` —— **没有任何变现出口**。

### 1.3 灵石收入：9 条，全是被动

| 途径 | 性质 |
|---|---|
| 宗门年俸（`pay * 12`） | 定期，看身份 |
| 灵田/矿脉（`stoneAcc`） | 定期，看资产 |
| 野外拾取（+30） | 随机 |
| 宗门任务（贡献 × 0.3） | 半主动，量小 |
| 打劫/偷盗/奇遇（+200~1,500） | 随机，有业力代价 |
| 打工供奉（`w.salary`） | 定期，量小 |

**没有一条是"靠自己的手艺持续赚钱"**。玩家的钱只能靠等、靠运气、靠抢。

### 1.4 致命问题：价格倒挂

```
材料中位 660   >   丹药中位 480
```

**材料比它做出来的成品还贵。** 就算今天把炼丹做出来，玩家也是做一次亏一次。

这不是数值微调能解决的——**整条价格链需要按"成本→成品"重新标定**（见第四节）。

## 二、参考小说给了什么

先说结论：**这六本书对"怎么做东西"的描写，比我预想的更实用**——它们大多不是写"炼成了什么神丹"，而是写"这一炉为什么废了"。

### 2.1 一炉要多备几份材料

> "不然也不可能**第一炉就能走到成丹这一步，节省了自己准备的其他八份材料**！"
> ——《我师兄实在太稳健了》

即：**一次成功是意外，正常是失败多次**。这给了"备料"这个概念存在的理由。

### 2.2 炸炉会反噬

> "志气满满地开炉炼丹，结果丹要成的最后一刻……**炸炉了**……自那之后，**一股邪气污了贫道元神**"
> ——《我师兄实在太稳健了》

失败不是"扣材料"这么轻，而是**有身体代价**。这条能让"炼高阶丹药"变成需要谨慎的事。

### 2.3 阵盘是材料的组合

> "有琴玄雅送的那只土灵珠……**今后搞来其他四种品质相同的宝珠，可以制作『五行轮杀阵』的阵盘**"
> ——《我师兄实在太稳健了》

即：**阵盘 = 一组特定材料的组合**，而不是"用灵石买一张图纸"。这让阵法天然接上了你的材料系统。

### 2.4 坊市可以议价，也可以以物易物

> "不知阁下这份火中煞气**作价几何**？"
> "**七十灵石**，最好能**以物作抵**。"
> "**有些贵了**，不知道友看上了我这店中何物？"
> ——《玄鉴仙族》

这三句把交易写全了：**报价 → 还价 → 折价换物**。而且"一块灵石掰扯成两半用"的底层窘迫感，正是现在游戏缺的。

### 2.5 宗门的完整经济链（这条最值得抄）

> "宗门只下派弟子管理到城……**利用丹药与法器来迫使世家种植原材料和大量供养低修为人力**，再**年年收割世家的优秀弟子**充实宗门，这几乎都是修行界公认的好法门"
> ——《玄鉴仙族》

这是一个闭环：

```
宗门 ──卖丹药/法器──▶ 世家 ──种原料、养人力──▶ 宗门 ──收优秀弟子──▶ 宗门
```

游戏里可以直接做成：**玩家在产业链的某一环上讨生活**。

### 2.6 材料年份决定上限

> "**百年火候的药材，就是普通的富贾也吃不起**"
> "这药材**火候越足，药性越大**"
> ——《白骨大圣》

同一种药材分年份/品级，直接对应"同一配方出不同品相的丹"。

### 2.7 九品对应境界

> "功法分为**九品**，一品最次，九品最好，**法诀丹药法器则与境界相对应**"
> ——《玄鉴仙族》

四艺等级与境界挂钩，不是纯熟练度堆叠。

### 2.8 拍卖不一定盛行

> "拍卖并不盛行。一个重要的原因，就是**亲情至高的价值观**……拍卖的商品一旦价格高了一些，许多竞争者就会自动退出"
> ——《蛊真人》

这条是**反面提醒**：拍卖会不必做成主要渠道，做成"偶尔开一次、有门槛"的稀罕事更符合世界观。

## 三、四艺系统设计

### 3.1 统一框架（四艺共用一套骨架，避免四套代码）

所有四艺都走同一个流程，只在参数上不同：

```
① 选配方（丹方/器方/符方/阵方）
      ↓ 检查：材料够不够、技艺等级够不够、状态够不够
② 备料（消耗材料，可多备几份以提高总成功率）
      ↓
③ 操作（3 次判定机会，每次是一个小选择）
      ↓
④ 成器判定（品相五档）
      ↓
⑤ 处置（收下 / 分解回料 / 卖掉）
```

**四要素**（决定成功率）：

| 要素 | 来源 | 影响 |
|---|---|---|
| 材料 | 品质（凡/灵/宝/仙） | 品相上限 |
| 器具 | 丹炉/器鼎/符笔/阵盘 | 基础成功率 |
| 技艺 | 该艺等级 1~9 | 成功率、可做阶数 |
| 状态 | 灵力、神识、伤势 | 成功率修正 |

**品相五档**（所有四艺共用）：

| 品相 | 售价倍率 | 说明 |
|---|---|---|
| 废 | 0 | 材料全损（可回收 20% 残料） |
| 下品 | ×0.7 | 能用，效果打折 |
| 中品 | ×1.0 | 标准 |
| 上品 | ×1.6 | 效果 +20%，售价溢价 |
| 极品 | ×3.0 | 效果 +50%，有额外词条 |

### 3.2 炼丹

**流程**：备料 → 起火 → **三次火候判定** → 成丹

**火候判定**（核心玩法，不是纯随机）：

每一轮给出三个选择，各有代价：

| 选择 | 成功率修正 | 品相修正 | 风险 |
|---|---|---|---|
| 文火慢炼 | +15% | +0 | 耗时（多耗 1 月） |
| 武火猛攻 | −10% | +1 档 | 炸炉概率 ×2 |
| 稳守中火 | 0 | 0 | 无 |

三轮里累计的修正决定最终结果。**贪品相就要担炸炉**——这就是"稳健流"的乐趣。

**炸炉**：失败且判定落在"炸炉"区间时触发

- 材料全损
- 气血 −20%、元神受损（道心 −1，持续 3 月）
- 丹房损坏（需修理，花灵石）

**成丹数**：中品以上 1~2 枚；极品 1 枚 + 丹方心得（永久 +1% 该丹成功率）

### 3.3 炼器

**流程**：器胚 → 刻阵 → 淬炼

与炼丹的差别在于**可逆性**：

| 阶段 | 失败后果 |
|---|---|
| 器胚 | 材料损毁（回收 30%） |
| 刻阵 | **可重刻**（消耗灵石，不毁器胚） |
| 淬炼 | 品相下降，但不会归零 |

所以炼器的体验是"**慢慢磨**"，炼丹是"**一把梭**"。这是两种不同的手感，值得保留。

**产出的法宝带词条**：从词条池随机 1~3 条（减伤/遁速/灵力上限/克制某系），词条数由品相决定。

### 3.4 制符

**三件套**：符纸 + 符墨 + 符笔

| 材料 | 作用 | 消耗 |
|---|---|---|
| 符纸 | 承载 | 每次 1 张 |
| 符墨 | 定属性（火符用朱砂、水符用青墨） | 每次 1 份 |
| 符笔 | 决定上限（凡笔最高中品，灵笔可出极品） | 不消耗，会磨损 |

**特点**：制符是**一次性消耗品**，所以它是四艺里**现金流最快**的一条——做出来就能卖，卖出去就能再做。

> 如果你只想先做一门四艺来解决"没钱"，**建议先做制符**：链条最短、周转最快、失败代价最小。

**符的种类**：

| 类型 | 效果 | 战斗中的用法 |
|---|---|---|
| 攻击符 | 一次性伤害（相当于一次免费大招） | 战斗选项 |
| 防御符 | 抵挡一次攻击 | 战前准备（已有这个入口） |
| 遁符 | 必逃 | 战斗选项 |
| 增益符 | 下三回合伤害 +30% | 战前准备 |

### 3.5 阵法

**阵盘 = 材料组合**（沿用《我师兄》的设定）：

| 阵 | 所需材料 | 效果 |
|---|---|---|
| 聚灵阵 | 4 份同系灵材 | 洞府灵气 +1 档 |
| 迷踪阵 | 3 份幻属材料 + 1 阵旗 | 洞府不被窥探 |
| 五行轮杀阵 | 五行各 1 份（品质需相同） | 洞府防御，可伤来犯者 |
| 锁灵阵 | 2 份禁锢类 + 阵盘 | 战斗中限制敌人遁走 |

**特点**：阵法是**资产**而非消耗品。布下之后持续生效，但需要**灵石维持**（每月扣），断了就失效。

这条正好接上你已有的"洞府/庙宇"系统。

## 四、经济系统重构

### 4.1 先修价格链（不改这个，四艺做了也白做）

**现状**：材料 660 → 丹药 480，做一次亏 180。

**目标**：让"买材料→做成→卖出去"有 15%~25% 的毛利，且考虑失败损耗。

**定价公式**：

```
成品基准售价 = 材料成本 × 2.2
```

为什么是 2.2：期望品相倍率约 0.88（见下表），加上失败率，1 / 0.88 / 0.85 ≈ 1.34，再留 25% 毛利和一些波动空间。

**品相概率（技艺 1 级）与期望**：

| 品相 | 概率 | 倍率 | 贡献 |
|---|---|---|---|
| 废 | 15% | 0 | 0 |
| 下品 | 35% | 0.7 | 0.245 |
| 中品 | 35% | 1.0 | 0.350 |
| 上品 | 12% | 1.6 | 0.192 |
| 极品 | 3% | 3.0 | 0.090 |
| **期望** | | | **0.877** |

**具体对照表**（可直接写进 data.js）：

| 成品 | 材料成本 | 新售价 | 单次期望收益 | 备注 |
|---|---|---|---|---|
| 回春丹 | 补气草 60 + 辅料 20 = 80 | **180** | 约 +40 | 现价 50，严重倒挂 |
| 生肌续骨丹 | 合神花 90 + 辅料 60 = 150 | **340** | 约 +80 | 现价 140 |
| 玉华灵水 | 玉华宝鱼汁 220 + 辅料 80 = 300 | **660** | 约 +150 | 中阶主力 |
| 火符（一次性） | 符纸 20 + 朱砂 30 = 50 | **110** | 约 +25 | 周转最快 |
| 器胚·青叶舟 | 材料 400 | **880** | 约 +200 | 现价 400 |

> 注意：**这会让现有物价整体上浮**。如果你不想动现有售价，另一条路是把材料价格砍半（60→30），但那样"采药卖钱"就没意义了。我倾向提成品价——因为它同时给了"采药"和"制作"两条活路。

### 4.2 三条主动收入线

| 线 | 怎么做 | 收益 | 风险 |
|---|---|---|---|
| **手艺变现** | 做好东西 → 坊市摆摊/接单 | 稳定，随技艺提升 | 低 |
| **材料倒卖** | 低买高卖，看行情 | 中 | 压货、行情判断错 |
| **宗门供奉** | 定期向宗门供货，换贡献+灵石 | 稳定但价低（七折） | 需完成配额 |

配合"摆摊"这件事，可以做成**每回合结算**：摆摊期间每月自动卖出 N 件，玩家只需补货——这就是"经营"的感觉。

### 4.3 变现渠道（四档，各有代价）

| 渠道 | 收购价 | 门槛 | 代价 |
|---|---|---|---|
| **宗门收购** | 市价 × 70% | 需宗门身份 | 稳定、无风险、量大 |
| **坊市摆摊** | 市价 × 100% | 需摊位费 | 每月只卖固定件数 |
| **拍卖会** | 市价 × 120~180% | 每 3 年一次，需入场资格 | 抽成 10%；可能流拍 |
| **黑市** | 市价 × 140% | 无 | 业力 +，被正道盯上 |

对应《玄鉴》里的"坊市议价"和《蛊真人》里"拍卖不盛行"——所以拍卖做**稀罕事**，不做主要渠道。

### 4.4 行情波动（让倒卖有意义）

每月小幅波动 ±10%，特殊事件放大：

| 事件 | 影响 |
|---|---|
| 大旱 | 药材 +40%，回春类丹药 +30% |
| 妖潮 | 法器 +50%，符箓 +30% |
| 宗门大比 | 丹药/符箓 +25% |
| 战乱 | 所有战斗物资 +40% |

**这直接接上了你已有的 `EVENTS` 表**——事件不只是惩罚，还会改变物价，玩家可以"看天吃饭"。

### 4.5 成本结构（重要，避免四艺变成印钞机）

| 成本项 | 占比 | 说明 |
|---|---|---|
| 材料 | 45% | 主要成本 |
| 辅料/器具损耗 | 10% | 符笔磨损、丹炉维修 |
| 时间 | — | 每次制作耗 1 月（与打坐竞争） |
| 失败损耗 | 15% | 期望值 |
| 净利 | **约 20%** | |

**关键约束：制作要占用"月"**。否则玩家会无限刷制作，经济立刻崩。让"做一个月的丹"和"打坐一个月"成为互斥选择，经济才立得住。

## 七、建议的实施顺序

**分四步，每步都能独立玩到东西**：

| 步 | 内容 | 为什么排这里 |
|---|---|---|
| **1** | **制符**（最短链条） | 材料 2 种、流程 1 步、失败无重罚。**先让玩家赚到第一笔手艺钱** |
| **2** | **坊市卖出 + 行情** | 有了产出必须有出口，否则做了也没用 |
| **3** | **炼丹**（三档火候） | 玩法最成熟，但要先有"卖"的通道 |
| **4** | **炼器 + 阵法** | 依赖法宝栏与洞府，可以后做 |

**先做制符的理由**：它只需要"符纸+朱砂"两种材料、一次判定，就能完成"材料→成品→卖出"的完整闭环。**用一个最小系统验证经济是否成立**，再往上堆炼丹和炼器，比四个一起做大稳得多。

---

## 八、一句话总结

四艺不是"再加四个功能"，而是**给灵石装一个入口**——现在玩家的钱只有"等、捡、抢"三种来路，没有一种是自己挣的。

而这三个来源里，**"挣"是最能让玩家对世界产生归属感的**：你会记得自己第一次炼成一炉丹、第一次摆摊卖光、第一次靠手艺买下那本玄阶功法。

这也是《我师兄》整本书的底色——**主角不是最能打的，是最会过日子的。**
