## 一、结论：能，而且现有结构几乎是为它准备的

我先把 v6.3 里宗门与家族的实际实现拉出来看了一遍，结论是——**不用新增系统，只要把已有的接口接上四艺**。

| 已有 | 位置 | 与四艺的关系 |
|---|---|---|
| 宗门四殿：炼宝／炼丹／御兽／合欢 | `D.SECT.halls` | **炼宝殿＝炼器、炼丹殿＝炼丹**，本来就是四艺的学堂 |
| 宗门任务：采药／守炉／巡山／猎妖／镇守 | `D.SECT.tasks` | **采药＝材料来源**、**守炉＝炼丹练习**，任务名都对上了 |
| 宗门藏经阁分层：`wai/nei/zhen` | `D.SECT.ranks[].lvl` | 现在是功法/招式，**加一层"技艺书"即可** |
| 家族祠堂 5 级：家祠→族府→宗祠→世家 | `D.CLAN.hallRanks` | 每级带 `pop` 与 `gongfa` 品阶，**可扩成"技艺传承"** |
| 家族每月产出：`stonePerPop: 0.35` | `D.CLAN.income` | 现在是凭空产灵石，**可改成产材料/做工** |
| **族规 `noTrade`：不得经商牟利** | `D.CLAN.rules` | ⚠️ **这条已经在管你卖东西了** |

最后一条值得单独说：

> `{ id: 'noTrade', name: '不得经商牟利', eff: '坊市大额交易，族运 −100' }`

**这条规则现在就在代码里。** 也就是说，一个立了"不得经商"族规的家族子弟，卖丹药是要掉族运的。

这不是 bug，这是**最好的联动入口**——它把"四艺赚钱"和"家族身份"直接顶到了一起。

## 二、宗门：给你学、给你料、给你卖、给你台阶

### 2.1 四殿即学堂（几乎不用改）

| 殿 | 对应 | 现状 | 改动 |
|---|---|---|---|
| 炼宝殿 | **炼器** | ✅ 已有 | 入殿即得《基础炼器》技艺书 |
| 炼丹殿 | **炼丹** | ✅ 已有 | 同上 |
| 御兽殿 | 御兽 | ✅ 已有 | 与四艺弱相关（捕兽需符/阵） |
| 合欢殿 | — | ✅ 已有 | 无关 |
| — | **制符** | ❌ 缺 | 新增「符箓殿」或并入藏经阁「杂学」 |
| — | **阵法** | ❌ 缺 | 新增「阵法殿」或并入「炼宝殿·阵科」 |

**最省事的做法**：不新增殿，在**藏经阁加「技艺」分类**，四艺书按宗门等级解锁：

| 身份 | 可学的技艺书 |
|---|---|
| 记名弟子 | 黄阶技艺书（一~三品配方） |
| 外门弟子 | 玄阶 |
| 内门弟子 | 玄阶 + 地阶（部分） |
| **真传** | 地阶 + 天阶 |

这正好复用现有的 `lvl: ['wai','nei','zhen']` 分层，**一行数据都不用加结构**。

### 2.2 任务即材料与练习

现有 5 个任务，其中两个天然与四艺相关：

| 任务 | 现在 | 改成 |
|---|---|---|
| **采药**（30 贡献） | 只给贡献 | 给贡献 + **2~4 份随机药材**（按境界） |
| **守炉**（60 贡献） | 只给贡献 | 给贡献 + **炼丹熟练度 +5**（若已学炼丹） |
| 巡山（90） | 贡献 + 风险 | 加：掉落**妖兽材料**（炼器/制符原料） |
| 猎妖（200） | 贡献 + 风险 | 加：**妖兽内丹**（炼丹主材，稀有） |
| 镇守（400） | 贡献 + 风险 | 加：**阵材**（守阵时接触） |

**这一改，宗门任务从"刷贡献"变成了"进货"**——玩家会主动挑"哪个任务给我缺的材料"。

### 2.3 交成品换贡献（新增，很关键）

现有任务全是"出力气"，没有"出手艺"。加一类：

| 交付 | 贡献 | 说明 |
|---|---|---|
| 交 3 枚回春丹 | 90 | 宗门常年收，价略高于市价（按贡献折算） |
| 交 5 张火符 | 120 | 战备物资 |
| 交 1 件玄阶法宝 | 600 | 器修的最大单 |
| 交 1 座聚灵阵盘 | 400 | 阵修专属 |

**为什么这条重要**：它给了四艺一个**稳定、无风险、不需要摆摊**的出口。不想做生意的玩家，做完直接交宗门，换贡献升身份——**"手艺"直接变成"地位"**。

### 2.4 技艺等级进晋升条件

现在晋升只看贡献（`need: 500 / 2000 / 8000 / 30000`）。建议改成**贡献 + 技艺**双条件：

| 晋升 | 贡献 | 新增条件 |
|---|---|---|
| 外门弟子 | 500 | — |
| 内门弟子 | 2,000 | **任一技艺 ≥ 三品** |
| 真传 | 8,000 | **任一技艺 ≥ 五品** 或 战力达标 |
| 长老 | 30,000 | **任一技艺 ≥ 七品** 或 一峰之功 |

这一条的妙处：**它让"手艺人"也能往上爬**。原来只有能打的才能升，现在会炼丹的也能当长老——这才符合"宗门需要炼丹师"的常识。

### 2.5 藏经阁加"技艺"页签

现有 `ACT.openSectLib` 分功法/招式两栏，加第三栏「技艺」：

```
藏经阁（贡献 1,240）
├─ 功法   《聚气诀》黄 120 贡献（已习）
├─ 招式   惊雷引 地 600 贡献
└─ 技艺   《青囊丹经》黄 300 贡献   ← 新增
         《符箓初解》黄 250 贡献
         《阵道入门》玄 800 贡献（需内门）
```

## 三、家族：给你传承、产能、销路，也给你规矩

### 3.1 祠堂传承：从"能传功法"扩成"能传技艺"

现有 `hallRanks[].gongfa`（huang/xuan/di/tian）决定可传功法品阶。加一个平行字段：

| 祠堂等级 | 可传功法 | **可传技艺（新增）** |
|---|---|---|
| 家祠 | 黄 | 黄阶技艺书 |
| 族府 | 玄 | 玄阶 |
| 宗祠 | 地 | 地阶 |
| 世家 | 天 | **天阶 + 祖传独门配方** |

**"祖传配方"是家族最独特的东西**：同一味丹，别人做是中品，你家做能出上品（+1 品相）。这是花钱买不到的。

### 3.2 族人从"产灵石"变成"做工"

现在是：

```js
income: { stonePerPop: 0.35, luckPerPop: 0.02 }   // 族人凭空产灵石
```

改成**有产出的产业**：

| 族人分配 | 产出 | 说明 |
|---|---|---|
| 种药（灵田） | 每月 2~6 份药材 | 按祠堂等级与人口 |
| 帮工（作坊） | 制作时产量 +1、成功率 +5% | 需指定，抽成 20% |
| 跑商 | 灵石（比现在略低） | 保守选项 |
| 修行 | 族运 | 出人才的长期投资 |

**这一改，"家族"从"每月发钱的提款机"变成了"要经营的产业"**——玩家得决定族人是去种药还是去跑商。

### 3.3 族老立场影响经营（现有数据，几乎没被用）

`D.CLAN.elders` 已有三位：守旧（稳）、进取（扩张）、贪利（灵石）。

建议让他们的立场**直接影响四艺经营**：

| 族老 | 对"开作坊"的态度 | 效果 |
|---|---|---|
| 守旧族老 | 反对（"与商贾为伍，辱没门风"） | 族运 −100，但族人忠诚 + |
| 进取族老 | 支持扩张 | 作坊产能 +20% |
| 贪利族老 | 支持，但要抽成 | 抽成从 20% → 35%，族运 + |

**玩家要在"赚钱"和"族运"之间选边**——这比单纯点"升级祠堂"有意思得多。

### 3.4 族规 `noTrade`：现成的冲突点

前面提到的这条，是整套联动里最有戏的：

> `不得经商牟利：坊市大额交易，族运 −100`

**它把玩家逼到一个岔路口**：

| 选择 | 后果 |
|---|---|
| 遵守族规，只交宗门 | 族运稳，但赚得少（宗门价 70%） |
| 偷偷摆摊 | 灵石多，但被发现族运 −100 |
| 改族规 | 需要族老会过半，可能引发族内分裂 |
| 脱离家族 | 失去族产与传承，换自由 |

**这才是"手段"与"身份"的真实关系**：你有一门手艺，但你所在的位置决定了你能不能用它换钱。

### 3.5 族运的新用途：作坊规模上限

现在族运（`luck`）只是个数。建议让它成为**产能上限**：

| 族运 | 可开作坊数 |
|---|---|
| 100 | 1 间 |
| 400 | 2 间 |
| 1,200 | 3 间 |
| 3,600 | 5 间 |

作坊越多，月产越高，但要维持族运——形成一个"扩张—维护"的循环。

## 四、双身份博弈（最有意思的部分）

玩家可以同时是**家族子弟 + 宗门弟子**，而这两边会打架：

### 4.1 三种典型冲突

| 冲突 | 场景 | 抉择 |
|---|---|---|
| **任务撞车** | 宗门派你守炉，家族要你回乡祭祖 | 选一边，另一边好感/贡献掉 |
| **技术外流** | 宗门要你的祖传丹方，家族不让外传 | 交＝宗门重赏 + 族运暴跌；不交＝宗门疑你 |
| **生意之争** | 家族的丹药与宗门自产的同款竞争 | 帮家族卖＝宗门查你；帮宗门＝族老骂你 |

### 4.2 身份的隐性收益

| 身份 | 收益 | 代价 |
|---|---|---|
| 家族子弟 | 祖传配方、免费材料、族运护身 | 受族规约束、要服族役 |
| 宗门弟子 | 技艺书、稳定收购、晋升通道 | 要上供、要听调、技艺可能被"充公" |
| **两边都是** | 材料便宜 + 销路稳定 | **夹在中间，两边都防你** |

**这条设计能让"出身"真正影响玩法**，而不只是开局时选一个名字。

## 五、完整经济闭环

```
        ┌────────────── 家族 ──────────────┐
        │  灵田（族人种药）  →  药材         │
        │  作坊（族人帮工）  →  产量/成功率   │
        │  祠堂（传承）      →  技艺书/祖传方 │
        └───────────────┬──────────────────┘
                        │ 材料 / 加成（抽成 20%）
                        ▼
        ┌───────────────────────────────────┐
        │           你（四艺：手段）          │
        │   炼丹 / 炼器 / 制符 / 阵法         │
        └───────┬───────────────────┬───────┘
                │ 成品              │ 成品
                ▼                   ▼
        ┌───────────────┐   ┌───────────────┐
        │ 宗门（贡献）   │   │ 坊市（灵石）   │
        │ 价 70%，稳定   │   │ 价 100%，要摊 │
        │ 可换身份/技艺  │   │ 受族规约束     │
        └───────┬───────┘   └───────┬───────┘
                │                   │
                └────── 灵石/地位 ───┘
```

**四条边都通向已有系统**：家族（产业）、宗门（贡献/藏经阁）、坊市（买卖）、玩家（四艺）。

## 六、数值样例

### 6.1 交成品换贡献的换算

以回春丹（新售价 180）为例：

| 渠道 | 收益 |
|---|---|
| 坊市卖 | 180 灵石 |
| 宗门交 | 90 贡献（≈ 90 灵石价值，但能升身份） |
| 家族收 | 144 灵石（八折，但不用出门） |

**三个价格差不大，区别在"换成什么"**——灵石、地位、还是人情。这就是有意义的选择。

### 6.2 家族作坊产出（族府级，800 人口）

| 分配 | 月产 |
|---|---|
| 全员种药 | 药材 ×12 |
| 全员帮工 | 制作产量 +2/次，成功率 +10% |
| 全员跑商 | 灵石 ×280 |
| 混编（各 1/3） | 药材 ×4 + 灵石 ×90 + 成功率 +3% |

### 6.3 宗门任务的"含金量"

| 任务 | 贡献 | 材料（新增） | 折合灵石 |
|---|---|---|---|
| 采药 | 30 | 药材 ×3（约 180） | **约 210** |
| 守炉 | 60 | 炼丹熟练度 +5 | 约 120 |
| 猎妖 | 200 | 妖丹 ×1（约 400） | **约 600** |

**采药从"30 贡献"变成"约 210 灵石价值"**——这才值得跑一趟。

## 七、落地顺序

联动不必一次做全。按"改动小、收益大"排：

| 步 | 做什么 | 改动量 | 为什么先做 |
|---|---|---|---|
| **1** | 宗门任务加材料产出（采药给药、猎妖给丹） | 小 | 一行数据 + 一次随机，立刻让任务有吸引力 |
| **2** | 交成品换贡献（4 条交付项） | 小 | 给四艺一个稳定出口，不用等坊市 |
| **3** | 藏经阁加「技艺」页签 | 中 | 复用现有分层，是四艺的"学"入口 |
| **4** | 家族族人分配（种药/帮工/跑商） | 中 | 把"提款机"变成"产业" |
| **5** | 技艺等级进晋升条件 | 小 | 一行判断，但改变"谁能往上爬" |
| **6** | 族老立场影响经营 + 族规冲突 | 中 | 让家族真正有"人味" |
| **7** | 双身份冲突事件 | 大 | 需要事件系统支持，最后做 |

**第 1、2 步合起来只要一两天，但能立刻让"宗门"和"四艺"互相有用**——先做这个验证手感。

## 八、一个提醒

`族规 noTrade` 与"卖货赚钱"的冲突，**不要当成 bug 修掉**。

它是这套设计里最珍贵的东西：玩家有一门手艺，但家族规矩不让他用这门手艺换钱。这时候他才真的要思考——

> "我是继续当这个家族的子弟，还是带着手艺走？"

**一个游戏能不能让人记住，往往不取决于它有多少系统，而取决于它有没有让你为难过。**
