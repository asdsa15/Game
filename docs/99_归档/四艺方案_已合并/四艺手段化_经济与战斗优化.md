# 四艺手段化 · 经济与战斗优化

日期：2026-11-08
定位：**修正稿**。此前「八条修炼路线」的方向作废——四艺是**修士的手段**，不是身份。
状态：方案稿，未修改任何代码

## 一、先把方向纠正

### 1.1 错在哪

我上一版把炼丹、炼器、制符、阵法做成了「丹修／器修／符修／阵修」四条路线，还各自配了月循环和收入曲线。

这是把 **"工具"当成了"职业"**。

在修仙世界里，一个筑基修士白天炼丹、晚上打坐、遇到仇家贴张符就跑——**他不会自称"丹修"**。四艺是他的活命手段，随时可以学、可以弃、可以几样都会。

做成路线会带来三个副作用：

1. **身份锁死**：玩家选了"剑修"就不能炼丹，这不符合"手段"的直觉
2. **系统翻倍**：八条路线要八套循环，维护成本极高
3. **削弱自由**：这个游戏的灵魂就是"高自由"，路线等于给自由上锁

### 1.2 正确的定位

```
境界（修到哪）  ─┐
道统（走哪条）  ─┼─ 都是"你是谁"
四艺（会什么）  ─┘   ← 但四艺是"你会什么手艺"，不是"你是什么人"
```

四艺应该和**悟性、神识、遁速**一样，是**能力**，不是身份：

| 维度 | 是什么 | 会不会限制你 |
|---|---|---|
| 境界 | 修为高度 | 不可跳，但人人都会往上走 |
| 道统 | 法脉归属 | 选了就定了，改要代价 |
| **四艺** | **手艺，可学可弃可兼修** | **不限制，谁都能学，学几样都行** |

**唯一的限制应该是"你会不会"和"你精不精"，不是"你能不能"。**

## 二、四艺作为手段

### 2.1 怎么学

| 项 | 规则 |
|---|---|
| **入门** | 需要一本技艺书（`《青囊丹经》`之类），坊市有卖黄阶，宗门/家族有高阶 |
| **门槛** | 悟性 ≥ 8（炼丹/阵法）、神识 ≥ 8（制符）、资质 ≥ 8（炼器） |
| **学费** | 学一本 200~2,000 灵石（按品阶） |
| **耗时** | 学会 1 月 |
| **不限** | **四艺可以全学**，没有互斥。但每艺的等级独立，练一样就要占一个月 |

**关键设计**：学不限制，但**练要占时间**。一个人一个月只能做一件事——这才是真正的约束。

### 2.2 等级：九品（沿用《玄鉴》"功法分九品"）

| 品 | 熟练度 | 能做什么 | 境界门槛 |
|---|---|---|---|
| 一~三品 | 0~300 | 黄阶配方 | 练气 |
| 四~六品 | 300~1,200 | 玄阶配方 | 筑基 |
| 七~八品 | 1,200~3,000 | 地阶配方 | 紫府 |
| 九品 | 3,000+ | 天阶配方 | 金丹 |

> 境界门槛是"能不能碰高阶材料"，不是"能不能学"。低境界也能学九品技艺，但做不出高阶货——因为材料和灵力都不够。

### 2.3 四艺各自的价值（三条线：自用 / 外卖 / 战斗）

| 艺 | 自用价值 | 外卖价值 | 战斗价值 |
|---|---|---|---|
| **炼丹** | 省下买药钱（长期最大开支） | 中高，需求刚性 | 嗑药不占回合（熟练度高时） |
| **炼器** | 省下买法宝钱（一次性大额） | 高，单笔最贵 | 法宝词条更强、可自修 |
| **制符** | 战斗爆发（越阶手段） | 中，周转最快 | 一次性大伤害/保命 |
| **阵法** | 洞府防御、聚灵（修炼加速） | 低（多是服务费） | 战场布置，改变胜负 |

**三条线同时成立**，所以四艺对任何玩家都有用：

- 不爱做生意的：自用，省钱
- 想赚钱的：外卖
- 爱打架的：战斗手段

**"省钱也是赚钱"** —— 这一条很重要，它解决了"不想当商人但也不想穷"的玩家。

### 2.4 材料从哪来

| 来源 | 说明 | 成本 |
|---|---|---|
| **采集** | 外出历练时采药/挖矿/猎兽（已有 `explore`） | 时间 + 风险 |
| **收购** | 坊市直接买 | 灵石 |
| **战利品** | 杀人夺宝、妖兽掉落 | 业力 |
| **自产** | 灵田种药（洞府设施） | 前期投入 |

四条来源都要有，否则玩家会被"买不到材料"卡死。

### 2.5 时间成本（最重要的一条约束）

**每次制作占 1 个月**，与"打坐采气"互斥。

这条比任何数值平衡都关键：如果制作不占时间，玩家会无限刷，经济立刻崩；占了时间，玩家就必须在"修炼"和"赚钱"之间做选择——**这才是修仙者真实的困境**。

## 三、经济系统

### 3.1 现状：三个断点

| 断点 | 事实 | 后果 |
|---|---|---|
| **① 没有出口** | `SHOP` 只有买，全项目搜不到 `sell` | 做出来的东西卖不掉 |
| **② 价格倒挂** | 材料中位 660 > 丹药中位 480 | 做一次亏一次 |
| **③ 收入全被动** | 9 条收入全是年俸/拾取/事件/打劫 | 没有"靠自己挣"的路径 |

### 3.2 目标循环

```
        ┌─────────────────────────────────────┐
        │                                     │
   灵石 ──▶ 材料 ──▶ 四艺（占1月）──▶ 成品 ──┤
        ▲                              │      │
        │                              ├─▶ 自用（省下的=赚的）
        │                              └─▶ 卖出 ──▶ 灵石（+20%）
        │                                     │
        └────────── 修为进度 ─────────────────┘
                （制作占月，修炼变慢 = 机会成本）
```

**这个循环有三个特征**：

1. **有正反馈**：卖出去 > 买材料，净赚约 20%
2. **有机会成本**：制作占月，修炼变慢
3. **有两条出路**：自用（省钱）或外卖（赚钱）

### 3.3 价格链（必须先改，否则一切白搭）

**公式**：

```
成品基准售价 = 材料成本 × 2.2
```

推导：品相期望 0.877 × 成功率 0.85 ≈ 0.745 → 1 / 0.745 ≈ 1.34 → 再留 25% 毛利与波动。

**对照表**（可直接写进 data.js）：

| 成品 | 材料成本 | 建议售价 | 现价 | 差额 |
|---|---|---|---|---|
| 回春丹 | 80 | **180** | 50 | +130 |
| 生肌续骨丹 | 150 | **340** | 140 | +200 |
| 玉华灵水 | 300 | **660** | — | 新增 |
| 火符（3 张/炉） | 50 | **110**/张 | — | 新增 |
| 器胚·青叶舟 | 400 | **880** | 400 | +480 |

> 注意：这会让成品价整体上浮。如果你不想大改，另一条路是**把材料价格砍半**——但那样"采药卖钱"就没意义了。我倾向提成品价，因为它同时给"采药"和"制作"两条活路。

### 3.4 五类收入（由被动转主动）

| 类型 | 具体 | 性质 | 量级（炼气期） |
|---|---|---|---|
| **手艺** | 卖丹药/符箓/法宝 | **主动，可复制** | 每月 100~400 |
| **采集** | 采药卖原料 | 主动，低门槛 | 每次 30~120 |
| **悬赏** | 宗门/坊市任务 | 半主动，需战力 | 每单 80~300 |
| **供奉** | 宗门年俸、家族月例 | 被动，看身份 | 每年 200~2,000 |
| **倒卖** | 低买高卖 | 主动，看行情 | 浮动 |

**设计目标**：让"手艺"成为炼气期最主要的现金流——因为这时候战力低，悬赏接不了，只能靠手艺。

### 3.5 四类支出（制造压力）

只有收入没有支出，钱会通胀。必须让玩家"永远缺钱"：

| 支出 | 频率 | 量级 | 说明 |
|---|---|---|---|
| **修炼消耗** | 每月 | 10~50 | 丹药、灵材（不嗑药修炼慢一半） |
| **洞府维持** | 每月 | 30~100 | 租金/禁制/聚灵阵灵石 |
| **器具维修** | 每 6 月 | 100~500 | 丹炉裂、符笔秃、阵盘损 |
| **人情往来** | 事件 | 50~500 | 送礼、随礼、还人情 |

**这四项加起来，炼气期每月固定支出约 60~150 灵石**。而收入只有 100~400，**稍有闪失就入不敷出**——这正是修真的真实状态。

### 3.6 月度收支表（关键的 UX 设计）

每月结算时，在左栏「纪事」顶部加一块：

```
┌─ 本月收支 ─────────────────┐
│ 卖出 回春丹 ×3      +540   │
│ 购 补气草 ×4        −240   │
│ 洞府维持            −40    │
│ 修炼用丹            −50    │
├────────────────────────────┤
│ 净入 +210   余 1,340       │
└────────────────────────────┘
```

**为什么这个很重要**：现在玩家不知道自己为什么穷。有了这张表，他会主动想"我该多炼点丹"——**经济系统就从"数值"变成了"目标"**。

### 3.7 行情波动（让倒卖有空间）

每月 ±10% 随机波动，事件放大：

| 事件 | 影响 |
|---|---|
| 大旱 | 药材 +40%、回春类 +30% |
| 妖潮 | 法器 +50%、符箓 +30% |
| 宗门大比 | 丹药/符箓 +25% |
| 战乱 | 战斗物资 +40% |

**这直接接上你已有的 `EVENTS` 表**——事件不再只是惩罚，还会改变物价，玩家可以"看天吃饭"。

## 四、战斗逻辑优化

### 4.1 现状诊断（v6.3 实测）

先说好的：**战斗已经比我预期完整**——双栏布局、相克、法宝加成、神通装配、同源共鸣、符箓 preBuff 都有了。

但有五个结构性问题：

| # | 问题 | 证据 | 后果 |
|---|---|---|---|
| **1** | **10 个选项，决策过载** | `renderCombat` 里 10 个 `optRow` | 手机上挤成一片，玩家每次都要重读 |
| **2** | **"战前准备"放在回合里** | 战斗中随时可点 `act:openPreFight` | **"战前"这个概念不存在了**，等于无限补给 |
| **3** | **两个"施法"入口** | 选项 2「选招式」、选项 3「本命」 | 玩家分不清该点哪个 |
| **4** | **敌人只会打你** | `foeTurn` 里只有扣血一条逻辑 | 战斗没有变化，也没有"对手也在想办法"的感觉 |
| **5** | **阵法完全缺席** | 全项目 `阵法` 出现 0 次 | 四艺只进来三样 |

另外两个小的：

- **观察/防御/说话收益太低**：玩家算过账就不会用，等于三个废按钮
- **没有回合压力**：可以"防御 → 嗑药 → 防御"无限拖，只要不被秒就不会输

### 4.2 阶段化：把一场战斗拆成四段

```
① 遭遇 ──▶ ② 战前 ──▶ ③ 交手 ──▶ ④ 收尾
  情报      布阵/贴符    3~6 回合     追击/放走/搜身
  打不打    换法宝/嗑药
```

**这一段是本次优化的核心**：现在所有事都挤在"回合"里，"战前准备"变成了"回合内补给"。拆开之后：

| 阶段 | 玩家做什么 | 关键点 |
|---|---|---|
| **① 遭遇** | 看敌情（境界/战力/胜算档），选择：打 / 谈 / 走 | 给出**明确的三选一**，而不是直接开打 |
| **② 战前** | 布阵（若有阵盘）、贴符、换法宝、嗑药 | **只能做一次，且只能在这一段做** |
| **③ 交手** | 每回合 6 个动作 | 阵/符/器/丹在这里生效 |
| **④ 收尾** | 追杀 / 放走 / 搜身 / 疗伤 | 杀人有业力，放走有人情，搜身有收益 |

**收益**：
- "战前准备"终于名副其实
- 遭遇阶段给了"不打"的选项，符合"残酷修仙"（打不过就跑是常态）
- 收尾阶段让"杀不杀"成为一个有分量的选择

### 4.3 选项精简：10 → 6

| 现 | 新 | 说明 |
|---|---|---|
| 1 攻击 | **攻** | 合并普通/全力（长按或二级选） |
| 2 选招式 + 3 本命 | **术** | 合并为一个入口，进去选招式 |
| 5 防御 + 法宝 | **御** | 防御/激发法宝 |
| 8 战前准备 + 9 用丹 | **器** | 符/阵/丹/宝，二级菜单 |
| 6 遁走 | **遁** | 保留 |
| 7 观察 + 0 说话 | **谋** | 观察/交涉/虚张声势 |

六个刚好是手机一屏两列三行。

**为什么合并"观察"和"说话"**：两者都是"不打，用别的办法"，归到「谋」里更清楚，也不会让玩家觉得"这两个按钮是摆设"。

### 4.4 四艺在战斗里怎么用（这是"手段"的体现）

| 艺 | 战斗中的位置 | 效果 | 消耗 |
|---|---|---|---|
| **符** | 「器」→ 贴符 | 一次性爆发（伤害/必中/减伤/遁走） | 消耗 1 张 |
| **阵** | **只能在②战前** | 改变战场：限制敌遁、我方增伤、每回合削敌 | 消耗阵盘耐久 |
| **器** | 「御」→ 激发 / 被动 | 主动激发一次法宝特效 | 灵力 |
| **丹** | 「器」→ 嗑药 | 回血/回灵/临时加成 | 消耗 1 颗 |

**关键**：四艺在战斗里都是"消耗品"，不是"技能"。这让"会不会做"变成"舍不舍得用"——

> 一个自己会制符的人，打起来敢甩三张；不会制符的人，买来的符要省着用。

**这就是"手段"和"身份"的区别**：不是你能不能用，是你用得起用不起。

### 4.5 判定统一：把 R 和位格合成一个"胜算档"

现在玩家看到 `R=0.42` 和"高你半境"，不知道哪个算数。

**建议合并成一个五档**：

| 档 | 条件 | 表现 |
|---|---|---|
| **碾压** | 战力 ≥ 敌 ×3 且位格不低 | 一击定胜负 |
| **压制** | 战力 ≥ 敌 ×1.5 | 你占优，2~3 回合可胜 |
| **相持** | 0.8 ~ 1.5 | 看手段与运气 |
| **下风** | 0.4 ~ 0.8 | 能逃就逃，硬拼重伤 |
| **绝境** | < 0.4 或位格低一大境 | 全力也伤不到，只能靠外物 |

并且**在面板上明确写"什么能改变这一档"**：

```
胜算：下风（0.42）
  → 用「五雷符」可提到 相持
  → 布「锁灵阵」可断其遁走
```

**这一句提示就是"手段"存在的意义**——它告诉玩家"你学的手艺现在有用了"。

### 4.6 敌人也要"动"

现在 `foeTurn` 只有一条逻辑：扣血。改成按性格选行为：

| 敌人类型 | 行为倾向 |
|---|---|
| **莽夫** | 全力攻击，不防御 |
| **老练** | 血量低于 30% 会防御/嗑药 |
| **滑头** | 血量低于 50% 尝试遁走 |
| **邪修** | 会用人质/毒/血祭（特殊手段） |
| **高阶** | 会用符/阵/法宝，跟你一样 |

**这一条能让战斗从"打木桩"变成"对局"**。玩家会发现"那个邪修要跑了，得先断他退路"——这时候阵法的价值就出来了。

### 4.7 回合压力：不能无限拖

每 3 回合，敌方"气势"+1：

| 气势 | 效果 |
|---|---|
| 1 | 伤害 +10% |
| 2 | 伤害 +20%，我方遁速判定 −10 |
| 3 | 伤害 +35%，触发"杀招"（一次大招） |

**为什么需要这个**：现在可以"防御→嗑药→防御"无限循环，只要不被秒就不会输。有了气势，拖延本身变成风险——**逼玩家在"稳"和"险"之间做选择**。

### 4.8 一场战斗的样例（数值）

```
【遭遇】游方邪修 · 紫府·一关 · 战力 420
胜算：下风（R=0.23）
  → 用「五雷符」可提到 相持
  → 布「锁灵阵」可断其遁走
[A 战] [B 谈] [C 走]

【战前】选了 B？→ 直接进入交谈判定
选了 A → 战前准备：
  布锁灵阵（消耗阵盘 1 耐久）
  贴五雷符（消耗 1 张，下回合必中+雷伤）
  嗑回灵丹（+40 灵力）
[开打]

【交手】
回合1  你：术·惊雷引（-40 灵力，必中，×1.75）→ 敌血 400→330
       敌：普通攻击 → 你血 100→85
回合2  你：器·贴符（五雷符，雷伤 +120）→ 敌血 330→210
       敌：气势1，攻击 → 你血 85→68
回合3  你：术·惊雷引（灵力不足）→ 只能普攻 → 敌血 210→180
       敌：想遁走，但锁灵阵生效 → 遁走失败
回合4  你：器·嗑药（回灵丹）→ 灵力 +40
       敌：气势2，攻击 → 你血 68→46
回合5  你：术·惊雷引（-40）→ 敌血 180→110
       敌：气势3，杀招 → 你血 46→18
回合6  你：遁（阵已断其退路？不，阵是限制敌人，你自己可走）→ 成功脱离
【收尾】重伤逃脱，损失 200 灵石（掉落）
```

**这场打完，玩家的感受应该是**："要不是那张符和那个阵，我第三回合就死了。"——这就是四艺作为手段的价值。

## 五、与现有系统的接口

| 现有 | 怎么接 |
|---|---|
| **境界** | 决定能碰什么品阶的材料（不是能不能学） |
| **道统** | 决定四艺的"系"（火系道统炼丹更擅长火属丹） |
| **宗门** | 提供技艺书与材料渠道，四殿（炼宝/炼丹/御兽/合欢）是"在哪学" |
| **家族** | 家族传承某几门技艺，族人学得快 |
| **洞府** | 丹房/器坊/符室/阵台，设施等级决定成功率 |
| **战斗** | 四艺在②战前与③交手两个阶段介入 |
| **存档** | 新增 `S.craft = {dan:0, qi:0, fu:0, zhen:0}`（熟练度）、`S.recipes = []`（已学配方） |

## 六、落地顺序

**不要四个一起做**。按"能不能立刻验证经济"排序：

| 步 | 做什么 | 为什么 | 工作量 |
|---|---|---|---|
| **1** | **坊市卖出 + 价格链重标** | 不改玩法，只让现有东西能变现。**先验证"钱能不能活"** | 1 天 |
| **2** | **战斗选项合并（10→6）+ 胜算档** | 纯 UI 与文案，立刻改善手感 | 1 天 |
| **3** | **制符 + 符进战斗** | 链条最短（2 材料 1 判定），且战斗里立刻有用 | 1~2 天 |
| **4** | **炼丹 + 月度收支表** | 补经济发动机，收支表让玩家看懂钱去哪了 | 2 天 |
| **5** | **战斗阶段化（遭遇/战前/交手/收尾）** | 结构改动，要改状态机，放后面 | 2 天 |
| **6** | **阵法 + 敌人行为** | 依赖阶段化，最后做 | 2~3 天 |
| **7** | 炼器 | 依赖法宝栏，可延后 | 2 天 |

**第 1 步是关键验证点**：如果"卖东西"能让玩家在炼气期活下去，后面的制作系统才有意义；如果卖完还是穷，说明支出端要调（洞府维持太贵或丹药太贵）。

**第 2 步几乎零风险**：只改 `renderCombat` 的选项和文案，不碰数值逻辑，但玩家感受提升最明显。

### 7.1 制符（第一个做的四艺）

## 八、一句话总结

上一版我把四艺做成了"职业"，那是错的。

**四艺应该是修士手里的四件工具**：会炼丹的人不必是丹修，会布阵的人也不耽误他练剑。

它们解决的不是"我想成为什么"，而是**"我这个月靠什么活下去"**——而这恰好是这个游戏最缺的东西：现在玩家的钱只有等、捡、抢，没有一种是自己挣的。

至于战斗，它不缺系统，缺的是**"你学的手艺在这里派得上用场"**的那种感觉。把"战前准备"真正放到战前、让符和阵真的能改变胜负，这种感觉就出来了。
